1. 裁定原则（v2 继承并补充）
======================================================================

1. scope-statement 是唯一边界；35 项既定裁定不再讨论。
2. v4.0 是全新命名空间；A 类之外的 v3.21 名字一律不进入 v4.0 代码，不做兼容层。
3. 每个名有且只有一个归属模块；同名不得跨模块重复冻结。
4. 名字必须可机械检查：保留字规则 + 新禁名表进 check-naming；依赖矩阵进
   check-dependencies。
5. 逻辑层零引擎：constants ~ director 不得值引用 React / PixiJS / Web Audio /
   Tauri / Node fs；presentation 是唯一允许引用 React/Pixi/WebAudio 的层；
   app 是唯一允许引用 Tauri 的组合根。
6. “服务端不留”指不运营任何 Neurou 服务端；不禁止客户端直连用户自有第三方
   API（CloudProvider / 天气 API）。这类直连必须由 app/adapters 实现，逻辑层
   只依赖注入端口。
7. 双图分工：EventGraph 是世界内动作蓝图；EventTreeDAG 是项目级世界编排。
8. 层判定与随机必须区分“编辑预览”与“运行时”：预览可复现，运行时真随机。

3. 七项未决事项裁定（v2 更新）

3.1 账号概念 → 无账号，单机 StudioProfile
- 没有账号、登录、认证、云端身份；不引入 AccountProfile。
- StudioProfile：本机唯一创作者身份，仅存显示名、界面语言、默认导出目录；
  不参与权限、归属、里程碑、账本判定。
- 落地：应用数据目录 studio-profile.json；一个安装 = 一个 profile。

3.2 事件树数据 → 项目目录 + event-tree.json
项目即目录：
  <Project>/
    project.json
    event-tree.json
    worlds/<worldId>/world.json
    worlds/<worldId>/ledger.ndjson
    worlds/<worldId>/ledger.head.json
    worlds/<worldId>/charts/<chartId>.json
    media/manifest.json
    media/<assetId>.<ext>
    drafts/
- event-tree.json 只存 DAG：nodes[]（nodeId、worldId、entryAnchor、画布坐标）、
  edges[]、rootNodeId；节点不内嵌世界。
- 原子写：临时文件 + fsync + rename；JSON 文档保留一代 .bak。
- SQLite 列 D 类（节点规模上千再评估）。

3.3 20 维账本载体 → 每世界 append-only NDJSON + head
- ledger.ndjson：一行一条 NarrativeEvent，只追加。
- ledger.head.json：schemaVersion / eventCount / lastEventId / positionSum /
  checksum。
- 接口：LedgerStore（唯一写入口 appendNarrativeEvent）、LedgerReader、
  LedgerCheckpoint（周期性摘要，不是全量快照）。
- 废止旧七项壳：WorldState*、LedgerSnapshot、LedgerHydration、租约/锁/journal
  全部 C 类。
- 损坏策略：head 与末行不一致 → 拒绝加载并给只读诊断，不自动截断、不静默重建。
- 写者纪律：全工程只有 director 可调用 appendNarrativeEvent；LedgerStore 不暴露
  update/delete。

3.4 导演身份 → 单 profile，不做多 profile
- 只有 StudioProfile 单例；多 profile 列 D 类。
- 不以 profileId 进入任何数据 schema；项目目录本身是隔离单位。

- WorldKind 名字保留。

- Secondary：新增值（A 类，无继承标注）；其余世界。
- Shore：废止值，进 C 类；不是 Secondary 的重命名源（P2）。

3.6 ChartSourceData → v2，支持动态图层
- schemaVersion = 2；外壳保留 chartId / provenance / layers[] / notes[]。
- 音符字段：timeMs / durationMs / chartLayerIndex / gridCellId? / chartKeyId? /
  chartPadKind。
- Hold：durationMs；第 2 层用 HoldGridLine；第 1/3+ 层用 SpaceHoldOverflow。
- 不做 v1 兼容：parseChartSourceData 只接受 v2；旧文件拒绝并给明确诊断；

4. 三处硬冲突修正（本轮必须项）
======================================================================

4.1 PerceptionMode.Rain 保留（P3 撤回）
- PerceptionMode = Normal / Triggered / Rain；Rain 是独立第三态视觉模式。
- PerceptionMode.Rain 是模式状态；RainModeState 是该模式的天气/视觉运行态
  （active、intensity、degradedReason、lastResolvedAt、source）。
- Rain 由玩家 IP 地天气驱动，不由蓝图触发；下雨不可蓝图触发，实拍雨景可作为
  蓝图事件剪辑（NarrativeAction / DynamicAction）触发，但不改变 PerceptionMode。
- Rain 强度：RainIntensity = Light / Moderate / Heavy。
- Rain 视觉：低饱和 + logo 发光（NoteLogoGlow，使周围雨丝清晰可见）+ 色调由
  视频谱面决定（RainTintSource）；logo 可见；视差框可见（主要用于非谱面场景）。
- 天气 API 失败时降级：RainModeState.degradedReason 记录
  LocationUnavailable / WeatherUnavailable / NetworkUnavailable；PerceptionMode
  仍保持 Rain，仅有效视觉降为 Normal，不回写为 Normal；不改变玩家当前感知模式
  选择；网络恢复后自动重试，成功回到 Rain。

4.2 CloudProvider 保留（P26 撤回）
- CloudProvider 进 A 类；客户端直连用户自填 API Key，不改变“服务端不留”。
- 边界：
  - 不运营 Neurou 服务端；无账号、无 Relay、无认证服务。
  - 请求只发往用户配置的第三方 LLM endpoint。
  - API Key 由 app/adapters 存 OS 钥匙串；不写项目文件、账本、日志。
  - CloudProvider 通过注入的 AIHttpPort（B 类）发请求；ai 模块保持纯逻辑。
  - 失败时按 FallbackChain 降级到 LocalProvider / TemplateProvider。
  - AI 输出只作建议，不得直接写账本；账本仍只由 director 追加。
- AIProviderMode = Local / Cloud；AIProviderSettings 保存 mode / endpoint / model /
  keyRef / timeout / fallback。

4.3 真随机：编辑预览种子可复现，运行时真随机
- RandomPreviewMode = Seeded / Live；RandomSeed 为种子类型。
- 编辑预览：Seeded；同种子 + 同输入 + 同时间轴 → 同结果。
- 运行时试玩：Live；使用 OS CSPRNG，不可复现。
- RandomAction 读取 RandomPreviewMode；预览传种子，运行时不传。
- 已写入账本的结果在重放/读取时不重算；随机只影响当场生成。
- AC4-21 / AC4-22 / AC4-41 按此修订。

5. 用户澄清 A / B / C 落地
======================================================================

5.1 澄清 A：动态图层与分层判定
1. 层数不固定；ChartLayerIndex 从 1 开始。
2. 第 1 层 = TopMost：空格全屏判定；固定，不可删除。
3. 第 2 层 = 8 格网格判定；固定，不可删除。
4. 第 3 层及更高层 = 全屏判定（任意区域点击）；可增删。
5. 每层分值 = max(1, floor(上一层 × 0.5))；基准分由 ChartLayerScoring 配置。
   示例（TopMost=800）：800 → 400 → 200 → 100 → 50 → 25 → 12 → 6 → 3 → 1 → 1…
6. AddChartLayer：在末尾追加全屏层；RemoveChartLayer：只允许删除第 3 层及以上的
   空层；删除后高层索引下移、分值重算；第 1/2 层不可删。
7. 同一音符只属于一个 ChartLayerIndex；禁止跨层 Hold。
8. GridLayer 不再作为独立层名：8 格的行由 GridRow（Top / Bottom）表达；
   TopMost 由 ChartLayerIndex=1 表达。GridLayer 退场（见 C.0）。
9. ChartPadKind 与 ChartLayerIndex 解耦（方案 A）：Layer 1 用 TopMost；Layer 2
   可同时有 Heavy / Light，共用 8 格判定；Layer 3+ 用 Light；分值只由
   ChartLayerIndex 决定，不由 ChartPadKind 决定。
10. 新增 A：ChartLayer / ChartLayerIndex / ChartLayerScoring /
    FullScreenJudgementLayer / AddChartLayer / RemoveChartLayer。

5.2 澄清 B：真随机
1. 编辑预览：RandomPreviewMode.Seeded + RandomSeed；随机放置、AI 关键帧生成、
   随机动作均使用该种子。
2. 运行时试玩：RandomPreviewMode.Live；真随机，不可复现。
3. 新增 A：RandomSeed / RandomPreviewMode。
4. AC4-22 修订；AC4-41 新增。

5.3 澄清 C：Rain 模式
1. 独立第三态：Normal / Triggered / Rain。
2. 状态跟随玩家 IP 地天气（第三方 IP 定位 + 天气 API）。
3. 强度：Light / Moderate / Heavy。
4. 视觉：低饱和 + logo 发光 + 色调由视频谱面决定；logo 可见；视差框可见
   （视差框主要用于非谱面场景）。
5. 下雨不可蓝图触发；实拍雨景可作为蓝图事件剪辑触发。
6. 降级：IP 定位失败 / 天气 API 失败 / 网络不可用 → RainModeState.degradedReason
   记录原因；有效视觉降为 Normal；不改变玩家当前感知模式选择；恢复网络后自动
   重试，成功回到 Rain；失败保持 Normal。
7. 新增 A：RainIntensity / RainModeState / LocationResolver / WeatherResolver /
   RainVisualConfig / NoteLogoGlow / RainTintSource。
8. 新增 AC：AC4-36 ~ 39。

13. 细节裁定 6.1 / 6.2（已闭合，本轮无待确认）
======================================================================

13.1 层分值整数化（6.1）
- 公式：score(1) = base；score(n) = max(1, floor(score(n-1) × 0.5))。
- 向下取整 + 最低保护值 1；不允许 0 或负数。
- 示例（base=800）：800 → 400 → 200 → 100 → 50 → 25 → 12 → 6 → 3 → 1 → 1…
- 实现位置：ChartLayerScoring；增删层后重算；整数分值进入 ChartScore。
- 基准 base 不冻结（示例 800 仅说明）；候选常量 CHART_LAYER_BASE_SCORE 进 B。

13.2 Rain 降级（6.2）
- 触发：IP 定位失败 / 天气 API 失败 / 网络不可用。
- 记录：RainModeState.degradedReason = LocationUnavailable / WeatherUnavailable /
  NetworkUnavailable。
- 行为：PerceptionMode 仍为 Rain；仅有效视觉降为 Normal（不回写 Normal）；
  不改变玩家当前感知模式选择；只改变 Rain 的视觉呈现。
- 恢复：网络恢复后自动尝试重新获取；成功回到 Rain；失败保持 Normal。
- 视觉实现：presentation 读取 RainModeState（R 边）；逻辑层不读渲染颜色。
