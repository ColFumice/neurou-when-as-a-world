本目录测试当前生产值：T6 `RHYTHM_STRIKE_WINDOW_MS = 100`、`PERFECT_WINDOW_MS = 100`、`GOOD_WINDOW_MS = 200`。`SYNC_TOLERANCE_MS = 30` 与 `HEAD_WINDOW_MS = 1000` 保持不变。

103 项全部通过：B 单线 31 项、C 多线 14 项、网格及旧 T7 28 项、编辑器 v3 18 项、新窗口行为 12 组。汇总见 `logic-regression-summary.json`；每套测试均有对应 `.cjs`、`.log` 与 `*-results.json`。

在工程根目录复现：

```powershell
node quality-review/judgement-window-2026-10-10/adapt-regressions.cjs
node quality-review/judgement-window-2026-10-10/run-logic-regressions.cjs
node quality-review/judgement-window-2026-10-10/verify-prior-evidence.cjs
```

`--summarize` 参数只汇总已有 JSON，不重新执行通过的测试。测试直接加载当前 TypeScript 源码；旧四套回归中采集器及 FrameDriver 集成使用原有事件总线 `cc` stub。新 `window-boundaries.cjs` 仅调用真实纯逻辑公开 API，不使用 `cc` stub。本报告不把纯逻辑执行当成 Cocos 预览或视频同步测量。

## 数值变更的验收

- 实际旧 T7 `ChartPremiere` 与引导线 Tap 演奏均验证 ±100 为 Perfect、±100.001 为 Good、±200 为 Good、±200.001 为 Miss；两侧均覆盖。
- 原 ±75 ms 为 Good 的区域现为 Perfect；原 ±150 ms 与 ±200 ms 为 Miss 的区域现为 Good。旧结果参照明确使用旧的 ±50 / ±120 数值契约，新的结果来自实际当前生产演奏。
- 无输入 Tap 在原截止点之后仍未结算；新 `target + 200` 端点仍可命中，严格超窗才一次性 Miss。引导线的结算时间继续记录截止点，旧 T7 反馈时间继续记录执行帧，未修改既有规则。
- 新重叠窗口仍只消费一个最近 Tap：3000 / 3300 两目标，3160 输入先取 3300；3150 等差先取 3000。跨线及同线同目标仍按 line ID / node ID 决定，数组顺序不改变结果。
- Drag 仍须到达时按住，Hold 仍须完整起点至尾端连续按住；晚 1 ms 或晚 150 ms 的 Down 均不能用新的 Good 窗口补救。Hold 在尾端一次计分，提前松键失败仍等尾端结算。
- T6 ±100 端点有效。首次敲击 75、7 秒终点 7075 时，7000 目标仍属于持续区间，须等最后拍：7100 敲击有效并完成；7100.001 仍未命中则归零，迟到敲击不能补救。重复目标、漏中间拍、离开范围均保留原规则。

## AC-18 同输入透明度验收

实际 `ChartPremiere` 的 `GuideTransparency` 单位仍是 0～100 百分比。用户归一化范围 0～1 按 `t × 100` 映射，未改变生产接口单位。

同一份谱面和完全相同的八条输入，在 `t = 0、0.1、0.25、0.5、0.75、1` 执行混合 Tap / Drag / Hold：均为 Perfect 3、Good 1、Miss 1，反馈序列逐项完全相同，总分依次为 **400、440、500、600、700、800**。每条记录保存相同输入 SHA-256、实际百分比与完成结果，验证计分随透明度单调增加。

测试首次预期表达式 `400 × (1 + 0.1)` 产生 IEEE-754 舍入值 `440.00000000000006`，实计分为 `440`。已仅把该数学期望断言改为 `1e-9` 数值容差；未修改生产计分。原失败诊断保留在 `initial-boundary-harness-results.json` / `.log`。

## 旧测试数值期望的披露

四套旧回归原样复制后的首次执行有六项失败，均因仍使用旧的 Perfect/Good 档位或 `target + 120` 截止点。原始运行记录保存在 `unadapted-regression-summary.json` 与四份 `unadapted-*.log`。

只在本目录副本做 12 处有原因的替换：B 一处截止点及一处复现命令；C 两处不变输入现在属于 Perfect 的期望；网格六处边界、截止点及观察时刻；编辑器两处 v3 边界与最后 Tap 截止观察时刻。每处具体原文、替换与理由见 `regression-adaptations.json`，完整差异见 `regression-adaptations.diff`。

旧目录源码及证据未编辑；四份原始 harness 哈希核验见 `prior-evidence-integrity.json`。生产文件、docs、名库、参照文件及门禁脚本均未由本测试任务修改。
