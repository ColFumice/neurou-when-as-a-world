## 存储 key 与兼容规则

| 用途 | key 公式 | 本轮关系 |
| --- | --- | --- |
| 既有序章完成投影 | `neurou-account-milestone-v1:` + encodeURIComponent(accountId) | 完全保留，不迁移、不覆盖，继续由既有 AccountStartupStorage 使用。 |
| 新首次世界通关投影 | `neurou-account-first-world-cleared-v1:` + encodeURIComponent(accountId) | AccountMilestoneStorage 独立账号隔离。 |
| 既有世界目录 | `neurou-world-folder-v1:` + encodeURIComponent(accountId) | 完全保留，WorldFolderRecord 仍只有目录元数据。 |
| 新世界完整状态 | `neurou-world-state-v1:` + encodeURIComponent(accountId) + `:` + encodeURIComponent(worldId) | WorldStateStorage 独立账号/世界隔离；当前不执行完整保存。 |

key 不视为新业务实体名。账号标识不带首尾空白、长度 1～64；世界状态边界的 worldId 长度 1～128；两者必须可 encodeURIComponent，拒绝非法 UTF-16，避免隔离 key 编码失败。

## DTO 字段与判别值

| 位置 | 字段 / 取值 | 边界 |
| --- | --- | --- |
| AccountMilestoneProjection | schemaVersion=1 / accountId / FirstWorldCleared:boolean | CopyPermission 不落盘；额外字段也拒绝。 |
| AccountMilestoneSnapshot | accountId / FirstWorldCleared / CopyPermission | CopyPermission === FirstWorldCleared，每次由读取面派生。 |
| WorldStateSnapshot 头部 | schemaVersion=1 / accountId / worldId / worldKind / shoreOrigin / revision / capturedAt | worldKind=Primary / Shore；Primary 的 shoreOrigin=null，Shore 的 shoreOrigin=BugShore / FinalShore；revision、capturedAt 为非负安全整数。合法头部自身不证明 Complete。 |
| Incomplete.candidate | 同七个头部字段；未知 worldKind / shoreOrigin / revision 为 Unavailable | Unavailable 是诊断候选取值，不能作为合法 WorldStateSnapshot 字段值。capturedAt 只是诊断时间，不是 FormatTime。 |
| WorldStateCaptureResult.kind | Complete / Incomplete | 已追认读取判别值；当前生产只返回 Incomplete。 |
| WorldForkAvailability | NotImplemented | 已追认，本轮固定值；CopyPermission=true 仍不开放 WorldFork。 |
| WorldStateRestoreResult.kind | Rejected / Restored | 实施契约判别字段；本轮只返回 Rejected，Restored 保留未来契约分支。 |
| WorldStateDiagnostic | section / reason / detail | section 为七项之一或 RuntimeBoundary；诊断不持久化为游戏事实。 |
| WorldStateReader | ownership / worldForkAvailability | 归属和功能读取元数据，不提供人工置 complete / forkReady 的写口。 |

reason 字面量清单：MechanismMissing、ProjectionUndefined、AuthorityUnavailable、IdentityUnavailable、RestoreUnsupported、UnsupportedBoundary、InvalidSnapshot、SchemaUnsupported、IdentityMismatch、ReferenceMismatch、StaleRevision。最后一项是预留诊断理由；本轮没有权威 revision，因此不宣称完整的过期快照比较已经实现。
