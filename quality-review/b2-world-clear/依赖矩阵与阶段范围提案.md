# B2.2c 依赖矩阵与阶段范围提案

日期：2026-10-10（Asia/Shanghai）。对应 VERDICT-238。状态：生产归属已落地，提交 PROTOCOL / Trae 同步阶段范围。docs/spec/stage-1.md 和 scripts/check-dependencies.js 不修改。

**不需要新增模块或扩展任何依赖矩阵单元。** 现行允许边已覆盖原四项与用户授权的最小正式内容生产者，只需 PROTOCOL / Trae 在阶段范围中记录业务归属。

| 承载 | 模块 | 使用的现有允许边 | 边界 |
| --- | --- | --- | --- |
| LedgerPosition 纯派生及向量验证 | ledger | ledger→constants | 权威载体由 director session 持有；ledger 不引用 world/chart/director，LedgerAppend 能力仅 director 消费。 |
| WorldNarrativeContent / SphereCrossing / RouteSignature / WorldClearRecord / WorldClearSession | director | director→constants/ledger/chart | director 校验内容、选择及通关，不导入 cc、浏览器存储或 presentation。 |

禁止新边：ledger→world/chart/director、chart→ledger/director、world→ledger、director→presentation，以及 presentation 对 director 实现的值导入。保持 E5、E8、E9；WorldClearSession 等类型经 IntentPort 转发。

阶段范围同步内容：B2.2c 已实现同源账本读写接线和角色身份索引、World 独立首演分支与正式内容装配、ChartRef 用途兼容、账号通关记录及投影对账；另按用户 PROTOCOL 回复实现制作方手工标注的最小 Primary 叙事交互。它只补穿越/通关所需生产前置，不声明七项完整 payload、完整恢复/hydration 或 WorldFork 可用。

正式内容在 assets/resources 独立存放；世界生产者运行逻辑在 director。内容出版工具位于 quality-review：实际调用既有 MusicEditorSession 与 GuidanceEditorSession 生产 API，编辑器核心不改。旧 T6/T7 仍写原零向量，只扩展 ChartRef.state，不补记录。

账号记录适配器仅从 IntentPort 类型窄口接收 WorldClearRecord / WorldClearProjection / RouteSignature；其严格平台 codec 不值导入 director validator。业务编排由组合根注入 commitRecord/readRecords/now；director 不依赖 localStorage 或 Web Locks。

WorldClearStorage 的账号独占锁是 presentation 平台能力，写入顺序为记录→里程碑投影。WorldFolderBuilder 重新装配时对账；FirstWorldCleared/CopyPermission 与七项 WorldStateSession 核心不改，通关记录不进入世界 snapshot、不随墓碑删除。

验收结果分开记录：最终依赖门禁证明静态边合法，业务/存储契约证明边界行为，实际 Cocos 预览证明正式资源与完整产品链路。该提案不提前声称生产预览通过。
