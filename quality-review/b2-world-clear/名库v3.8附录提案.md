## 字段与分类值提案

- ChartEntry：entryId / worldId / characterId / ChartRef / tier / source；source 固定 DeepTrace / SphereCrossing。
- ChartRef.state：Entry / PremiereCompleted；可选只为旧格式兼容，其他字符串无效。
- 只读引用分类：Entry / PremiereCompleted / Unclassified；Unclassified 不允许写入 ChartRef.state。
- RouteSignature：VectorSchemaVersion=1 / ledgerPosition / classificationVersion=1 / divergenceAxis / narrativeTime。
- WorldClearRecord：schemaVersion=1 / accountId / worldId / worldKind='Primary' / protagonistCharacterId / ChartRef / contentRevision / completionEventId / clearedAt / routeSignature。
- WorldClearProjection：schemaVersion=1 / accountId / records。
- 存储 key 已追认并实施：`neurou-account-world-clears-v1:` + encodeURIComponent(accountId)。独立于序章、FirstWorldCleared 投影、目录或 WorldState key。
- 账号提交锁名：`neurou-world-clear:` + encodeURIComponent(accountId)，生产使用 browser Web Locks 独占模式；无锁能力时拒绝提交。
- WorldNarrativeContent：schemaVersion=1 / contentId / contentRevision / worldKind='Primary' / protagonistCharacterId / EventSpaceCenter / EventDistance / source{author,version,description} / interaction{title,prompt,choices} / worldBossChartSource。
- WorldNarrativeChoice：choiceId / label / meaning / 完整 vector；PlayerIntent 仅携带 choiceId。
- 完成事件 ID：`WORLD_PREMIERE_COMPLETED:<epochMs>:<sequence>`；选择事件 ID：`WORLD_NARRATIVE_CHOICE:<epochMs>:<sequence>`。前者候选的失败重试沿用同一 ID 与路线。

本批 WorldGameplayContext 与内容/持久记录统一显式字符串 `Primary`，由正式内容 parser 验证，避免已有枚举数字顺序泄漏为格式。目录 template 不承担种类判定。
