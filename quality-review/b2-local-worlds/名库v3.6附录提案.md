# 名库 v3.6 附录提案 · 待 PROTOCOL 追认 / Trae 落盘

日期：2026-10-10。依据用户已采纳的 VERDICT-201～210；以下新名称仍为候选，未直接修改 docs/NAMEBOOK.md，也未自动向 Trae 发送消息。

| 候选名称 | 归属 | 定义 |
| --- | --- | --- |
| WorldFolderRecord | director / WorldFolderSession.ts | 目录元数据记录，不是 WorldInstance 或世界存档。readonly worldId/title/description/createdAt/deletedAt/template。 |
| WorldFolderSnapshot | director | schemaVersion=1/accountId/records 的冻结集合快照，仅目录元数据。 |
| WorldFolderIntent | director | 目录意图联合，独立于每帧 PlayerIntent。 |
| WorldFolderPort | director | submitWorldFolderIntent 意图窄口；通过现有 IntentPort 文件仅类型转发。 |
| WorldFolderSession | director | 目录状态决策、严格校验、初次默认项、创建、墓碑及先保存后发布。零 cc。 |
| CreateWorld | WorldFolderIntent 判别成员 | 新建 EmptyWorld 元数据及独立 fresh 最小箱庭入口。 |
| DeleteWorld | WorldFolderIntent 判别成员 | 只新增目录墓碑，不删除账户事实或世界叙事记录。 |
| WorldLocalStorage | presentation | 浏览器按账号隔离的 JSON 目录适配，独立于编辑器草稿和序章事实。 |
| MinimalWorldBuilder | assets/scripts 组合根 | 最小箱庭装配，复用原移动/跳跃与三步帧驱动；无痕、深痕、谱面或媒体绑定。 |
| EmptyWorld | 目录 template 判别值 | 新建世界的最小模板标识，不是 WorldKind 枚举新增值。 |
| submitWorldFolderIntent | WorldFolderPort / Session | 接收目录操作。 |
| getWorldRecord / getSnapshot | WorldFolderSession | 活动条目核验 / 冻结元数据快照读取。 |
| readSnapshot / saveSnapshot | WorldLocalStorage | 读取 JSON / 核对 expected 后保存；持久化成功后上层才推进 expected。 |
| bindEntry | MinimalWorldBuilder | 仅接入展示入口文本；不承载世界状态复制。 |
| refresh / showStatus | WorldFolderView | 从只读面重新绘制 / 显示操作结果。 |
| loadFolderSession | WorldFolderBuilder 私有装配方法 | 重读当前账号存储并注入事务适配。 |

延用已有名称：WorldFolderReader、WorldFolderEntry、InitialWorld、WorldFolderView、WorldFolderBuilder、WorldFork、ChartResourcePath、WorldInstance、WorldKind、Bootstrap、FrameDriver、InputCollector、CameraRig、ProtagonistView。

WorldFork 只延用已冻结词形作为未开放意图，不表示已实现完整分叉。WorldRegistry / DuplicateWorld / CopyPermission / FirstWorldCleared / WorldClearRecord 均未新增实现；其冻结语义保留。

字段：WorldFolderRecord.createdAt 与 deletedAt 为目录纪元毫秒，deletedAt=null 表示活动；template 为 InitialWorld | EmptyWorld。它们不替换 FormatTime、世界 ID 归属或账本事件格式。WorldFolderEntry 仍只投影三个只读字段。

平台 key：`neurou-world-folder-v1:` + encodeURIComponent(accountId)。数据只保存目录元数据，没有坐标、ledger、PuzzleProgress、ChartSnapshot、媒体资源路径或 per-world ChartResourcePath。

DOM 候选标识：create-world、world-create-form、world-title、world-description、confirm-create-world、cancel-create-world、world-delete-confirm、world-delete-title、world-delete-message、confirm-delete-world、cancel-delete-world、refresh-worlds、world-folder-status、minimal-world-info；data-action 取 open-world/delete-world/fork-world。InitialWorld 的 open-initial-world 旧 ID 保留。

完整新增标识机器清单另见 `新增命名清单.json`，含私有成员和局部声明，用于逐项复核，不把这些实现词汇扩大为世界观实体。
