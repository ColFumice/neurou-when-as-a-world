# B2.1 依赖矩阵与阶段范围提案

依据已采纳 VERDICT-208：本轮没有新增 src 模块，没有新增跨模块依赖许可，现有 E1～E9 门禁不放宽。无需矩阵扩展落盘。

| 实现 | 归属 / 依赖 |
| --- | --- |
| WorldFolderSession.ts | director；自身纯逻辑，无 cc、DOM、存储值依赖或 ledger 追加调用。 |
| IntentPort.ts | director；只追加 WorldFolderSession 类型转发，既有 gameplay 代码不变。 |
| WorldLocalStorage.ts / WorldFolderView.ts | presentation；通过 ../director/IntentPort 仅 import type；平台存储由组合根注入会话。 |
| FolderCatalog.ts | presentation；动态只读三字段投影。 |
| MinimalWorldBuilder.ts / WorldFolderBuilder.ts | assets/scripts 组合根；创建并注入逻辑对象和 Cocos 组件，管理运行节点生命周期。 |

presentation 不 new director 会话、不直接更改目录记录；WorldFolderView 只发 CreateWorld/DeleteWorld/WorldFork 意图并读列表。WorldLocalStorage 只是已有平台适配模式的延伸，不具有世界业务决策或账本追加能力。
