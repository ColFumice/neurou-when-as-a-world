## 实现与使用

在 Cocos Creator 3.8.8 中预览现有场景，以本地账号完成既有序章后进入世界文件夹。首次使用该账号目录时出现 InitialWorld；点击“新建世界”，填写名称和可选说明，成功保存后列表增加新项。点击新世界卡片的标题/说明区域进入独立最小箱庭，退出按钮返回并重新读取目录。删除先确认，成功后从活动列表隐藏，但本地记录保留 deletedAt。点击“刷新”可重新读取其他页面已完成的更新。

View 只发 CreateWorld / DeleteWorld / WorldFork 意图，纯 director 的 WorldFolderSession 决定目录变更；presentation 的 WorldLocalStorage 只适配浏览器存储，组合根负责注入并装配运行节点。WorldFolderReader 每次返回新的冻结三字段投影，WorldFolderEntry 仍只含 worldId/title/description。

保存 key 为 `neurou-world-folder-v1:` + encodeURIComponent(accountId)。集合为 schemaVersion=1/accountId/records，每条仅 worldId/title/description/createdAt/deletedAt/template；template 为 InitialWorld 或 EmptyWorld。新 ID 使用浏览器 UUID，并检查活动及墓碑记录。存储成功后才发布快照；失败保留原目录，创建失败保留表单输入。已观察到的过期写入被拒绝并提示刷新，localStorage 的读取与写入不构成跨页原子事务。

InitialWorld 使用原 SceneBuilder 工厂，B1 ChartResourcePath 继续采用全局 Inspector 配置。新增 EmptyWorld 使用既有 Bootstrap / InputCollector / FrameDriver / CameraRig / ProtagonistView；没有痕、深痕、谱面、媒体或叙事写入接线。编辑器目录保持全局顶层入口。

## 新增命名与后续事项

主要候选：WorldFolderRecord、WorldFolderSnapshot、WorldFolderIntent、WorldFolderPort、WorldFolderSession、CreateWorld、DeleteWorld、WorldLocalStorage、MinimalWorldBuilder、EmptyWorld。附录和 AST 清单另列方法、字段、DOM 标识与存储 key。WorldFork 延用冻结名称；EmptyWorld 只是目录 template 值，没有扩展 WorldKind。

本轮没有剩余实现阻断。PROTOCOL 后续需正式追认候选名称，Trae 据附录落盘；无需新增依赖许可。WorldFork 移交 B2.2/B2.3，实施前补齐 FirstWorldCleared、CopyPermission 与完整状态继承接口。WorldRegistry、跨设备、观察者同步、服务和 AccessCode 均保持既定后续阶段。

存储范围是同一浏览器 profile、同一 origin（含端口）、同一本地账号；清除浏览器数据会清除目录元数据。当前预览测试使用独立临时 profile，其路径、partition、worldId 及 SHA-256 以最终 Creator 报告为准。产品本地账号不是新增的在线认证能力。完整世界状态、账本与通关事实的跨会话持久化未在本轮建立；墓碑操作仅保证不触碰这些既有边界。localStorage 不提供跨标签页并发原子事务，当前仅拒绝已观察到的过期快照。
