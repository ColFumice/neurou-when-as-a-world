1.2 源码根决策（待 P-R2-01 批准）

建议：新建 `v4/` 作为 v4.0 唯一源码根；legacy `src/` 保持原样。

理由：
1. `assets/scripts/src` 是指向根 `src/` 的目录联接；任何放入 `src/` 的新代码
   会被 Cocos Creator 3.8.8 当作工程脚本编译，污染旧工程。
2. `v4/` 与 legacy 完全隔离，R3 可在 `v4/app/` 放 Tauri/React 外壳，
   R5 可整体归档或改名。
3. 不移动/删除 legacy `src/`，避免破坏 assets/scripts 组合根与旧门禁。

建议布局：

v4/
  core/
    constants/ ledger/ trace/ world/ timeline/ chart/ character/ studio/
  adapters/node/
  tests/
  tsconfig.json
  tsconfig.test.json
tools/
  lib/
  check-naming-v4.cjs
  check-dependencies-v4.cjs
  check-zero-engine-v4.cjs
  check-ledger-single-writer-v4.cjs
  check-all-v4.cjs

R3 再增加 `v4/app/`（Tauri 2 + React 19）与 `v4/adapters/tauri/`；R2 不建。

1.4 风险点

| # | 风险 | 影响 | 缓解 |
|---|---|---|---|
| R2-R1 | 源码根放入 src/ 被 Cocos 编译 | 旧工程污染 | 使用 v4/（P-R2-01） |
| R2-R2 | R2 测试用 CommonJS 编译，R3 用 ESM/Vite | 工具链分叉 | 源码只用 extensionless import；R2 单独 tsconfig.test；R3 Vite 直接消费 TS |
| R2-R3 | A 类门禁扫描 adapters/tests 时报未注册名 | 门禁误报 | check-naming 只对 v4/core 做 A 归属校验；adapters/tests 只做禁名/零引擎检查（P-R2-03） |
| R2-R4 | LedgerStore 内部 append 可被绕过 | 单写者失守 | 门禁同时检查 appendNarrativeEvent 与 LedgerStore.append 调用点；R4 director 接入（P-R2-10） |
| R2-R5 | 崩溃注入需要测试钩子，可能泄漏为公开 API | A 类污染 | 钩子只放 adapter 构造参数（内联类型），不导出新类型 |
| R2-R6 | Windows fsync / rename 语义 | AC4-03 不稳定 | 只对文件 fsync；同卷 rename；不做目录 fsync；测试在 Windows 实跑 |
| R2-R7 | AC4-02 的 event-tree.json 需要 G 模块 | 占位 schema 漂移 | 固定空占位 `{schemaVersion:1,nodes:[],edges:[],rootNodeId:null}`（P-R2-09） |
| R2-R8 | frame/trigger/eventtree 的 A 名在 stage-4 无模块归属 | 门禁映射缺项 | 暂映射 frame/trigger→W、eventtree→G，仅作门禁映射（P-R2-04） |
| R2-R9 | NarrativeEvent.chartRef 与 L→C 禁止边冲突 | AC4-19 未来阻塞 | R2 不实现 chartRef；P-R2-05 裁定载体 |
| R2-R10 | package.json 改动影响 legacy 门禁 | 旧 verify 失败 | 只追加 v4 scripts/devDeps；R2 结束重跑 legacy verify |

3.3 门禁口径（需 P-R2-03 确认）

1. check-naming 的“A 类名存在”解释为：每个 v4/core 导出名都能在 A 类找到且
   模块一致；不要求 271 项在 R2 全部实现。
2. adapters/tests 不做 A 归属校验，只做禁名与零引擎检查；adapters 实现名不
   进入 A 类。
3. bare Rain 允许作为 PerceptionMode / TraceTier 的枚举成员；其他位置 ERROR。
4. 同名不跨模块：解析 NAMEBOOK 时若同名出现在两个 section，直接 ERROR。
5. check-dependencies 的 P 行“全部逻辑模块 R/I”、X 行“全部”按规则表处理；
   R2 不实现 P/X 之外的新模块。
6. 子域 console / weather / rain-visual / ai-adapter 不在 R2 路径内；门禁表保留。
