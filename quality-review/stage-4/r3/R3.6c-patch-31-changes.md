## 1. 输入行遮挡

不再依靠 padding/mask 猜测，而是消除所有会导致最后一行被裁切的绘制来源：

```css
.project-console .console-output {
  transform: none;
}

.project-console__fisheye {
  padding-bottom: 1em;
}

.project-console__scroll .console-output {
  padding-bottom: 0.6em;
}

.project-console__input {
  background: transparent;
  padding: 0.8em 0 0;
  margin-top: 0.2em;
}
```

- 去掉 `.console-output` 的 `scale/rotateX`，避免视觉溢出；
- Fisheye 容器底部留 1em，SVG filter 的最后一行不会被 clip；
- 日志末尾 0.6em 容纳 descender；
- 输入行透明，不再有遮罩；
- 输入行仍紧接日志流，下方 7 个空行。

## 4. 镜面破裂式错位

故障层新增：

- 全屏锯齿碎片 `::before` / `::after`；
- 每个碎片使用 `clip-path` 多边形；
- `mix-blend-mode: difference`；
- 切片高度 2–11%；
- 位移 ±180px；
- 纵向位移 ±45px；
- `clip-path` 锯齿切片 + 白/黑反色带；
- `filter: contrast(2)`。

```css
.global-glitch__slice {
  clip-path: polygon(0 0, 100% 3%, 98% 44%, 100% 96%, 4% 100%, 0 56%);
  background: linear-gradient(
    90deg,
    transparent,
    rgba(255,255,255,.95) 11%,
    rgba(0,0,0,.92) 38%,
    rgba(255,255,255,.85) 63%,
    rgba(0,0,0,.8) 82%,
    transparent
  );
  mix-blend-mode: difference;
  filter: contrast(2);
}
```

视觉效果是整屏断层、黑白反色切割，而不是简单细线。
