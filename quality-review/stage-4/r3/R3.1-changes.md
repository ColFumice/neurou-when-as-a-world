## 3. 偏离计划的说明

1. `big logo.png` 为 893×896 非正方形，`npx tauri icon` 首次报错；按 CLI 提示加 `--fit contain` 后生成成功。这是唯一必要的命令差异，未改变图标语义（contain 保留完整画面）。
2. 依赖版本按当前可用稳定线锁定：Vite 7.3.7、`@vitejs/plugin-react` 5.2.0、React 19.3.1、Tauri CLI 2.12.3、Tauri API 2.12.4、PixiJS 8.22.0、TypeScript 5.9.3。`package.json` 使用 `^`/`~` 范围，`package-lock.json` 锁定精确版本；未使用 Vite 8（计划基线为 Vite 7，避免额外迁移）。
3. `npm install` 时 npm 11 提示 `esbuild@0.28.2` 的 postinstall 未加入 allowScripts；随后 `vite build` 成功（32 modules），未手工改 npm 配置。该提示属于本机 npm 策略，记录为环境观察，不视为构建失败。
4. `tauri.conf.json` 的 `bundle.active` 设为 `false`：R3.1 只做 dev 窗口验收，不做安装包；R3.5/R4 再开启 bundle。CSP 暂为 `null`，R3.5 媒体预览时再补。
5. `app_info` 的显示名使用 `"雨若 Neurou"`；productName 为 `"雨若"`，identifier 为 `cn.neurou.app`，窗口 1280×800，标题 `"雨若 Neurou"`。以上按 U-R3-02 建议值落盘，**待用户最终确认**。
6. `cargo check` 首次执行包含 crates 下载与全量编译；最终 `Finished dev profile ... in 49.59s`，exit 0。未运行 `npm run tauri dev`（会打开 GUI 并阻塞），留给用户人工确认。
