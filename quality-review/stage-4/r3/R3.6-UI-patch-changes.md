## 1. 实现

### 1.1 全局全屏准星

**位置**：`v4/app/src/components/Crosshair.tsx`（X 层全局注入，挂载于 `App.tsx`）。

选 X 而不是 P 的原因：P 的 A 类名单没有 `Crosshair`，直接 export 会触发 check-naming；本轮按“X 层全局注入”的授权执行，R3.5c 若裁定 D-1=B，可整体迁入 P。

**结构**：

- 根节点 `position: fixed; top:0; left:0; width:0; height:0; z-index:99999; pointer-events:none`。
- 横线：`left:-100vw; width:200vw; height:1px`；竖线：`top:-100vh; height:200vh; width:1px`。2× viewport 保证指针在任意位置时线都覆盖整屏；根节点只做 `translate3d(x,y,0)`。
- 中心十字：10×10 容器，2px 白色横竖臂；`box-shadow` 微发光。
- 中心膨胀：120px 径向渐变 + `filter: blur(3px)`，中心 alpha 0.14，向外衰减。
- 线体：`rgba(255,255,255,0.3)` 实色 1px；线体带 `0 0 8px / 0 0 24px` 微光，形成“厚重暗角”感。
- 点击 / 拖拽：`pointerdown` 给根节点加 `is-pressed`，中心 core `scale(0.9)`、glow `scale(0.92)`；`pointerup` / `pointercancel` / `pointerout` / `blur` 复位。

**性能**：

- `pointermove` 不触发 React render；位置存在闭包里，`requestAnimationFrame` 内只写 `transform`。
- 指针坐标 `Math.round`，避免 1px 线在半像素上发虚。
- 窗口 resize 时 clamp 到视口内，只 schedule 一帧。
- 指针离开窗口（`pointerout.relatedTarget === null` / `mouseleave` / `blur`）时隐藏准星；重新移动即显示。
- 没有使用 20px `backdrop-filter` 毛玻璃层，改用径向渐变，避免每帧重算背景；视觉上仍是“中心微微发亮”。

**全局光标**：

- `app.css` 增加 `html, body, body *, body *::before, body *::after { cursor: none !important; }`。
- 覆盖现有 `.event-tree button` / `.parallax-demo button` 的 `cursor: pointer`、`app-drag-region` 的 `cursor: grab`，保证所有界面都不出现系统光标。
- 文本输入框仍保留文本插入符（caret 与 cursor 是两套机制），不影响输入。

- `.lg-glass`：`background` + `border` + `border-radius` + `box-shadow` + `backdrop-filter: blur(20px) saturate(180%)` + transition；带 `-webkit-` 前缀。

本轮不改造现有组件，只落变量和可选 utility；R3.5c 的 Toolbar / Inspector / 媒体面板直接套用。

## 5. 已知限制 / 边界

1. **X 层承载**：`Crosshair` 不是 A 类名，放 P 会触发 check-naming；本轮按授权用 X 全局注入。R3.5c 若 D-1 裁定 P，可把组件迁入 P 并新增 A 名。
2. **全局隐藏系统光标**：包括按钮的 `cursor:pointer`、拖拽区的 `cursor:grab`；若未来需要原生 resize/col-resize 光标，需要加 `[data-native-cursor]` 例外（本轮未加）。
3. **原生控件/系统菜单**：Tauri 原生对话框、系统右键菜单、窗口边框不在 DOM 内，准星不覆盖；这是预期边界。
4. **中心膨胀**：用 120px 径向渐变替代 20px `backdrop-filter` 毛玻璃，优先保证 60fps；如果后续想要真毛玻璃，可在编辑器静止时启用小面积 backdrop-filter。
5. **触控/笔**：准星按 pointer 事件跟随；触屏无系统光标，视觉上可能出现准星，未专门做 coarse pointer 隐藏。
6. **多显示器/窗口缩放**：resize 时 clamp 到视口；跨显示器移动由 pointermove 更新，未做 DPI 特殊处理。
7. **性能证据**：pointermove 不触发 React render，仅 rAF 写 transform；未做 long-task 采样，若后续编辑器出现掉帧，再补 Performance 面板证据。

## 6. 给 R3.5c 的交接

- 直接使用 `--lg-*` tokens；容器优先 `.lg-glass` / `.lg-glass--strong`。
- Toolbar / Inspector / 媒体面板采用 `--lg-radius`、`--lg-border`、`--lg-shadow`、`--lg-blur`。
- 动效统一 `var(--lg-ease)` / `var(--lg-duration)`；不要另造曲线。
- 文本主/辅色用 `--lg-text` / `--lg-text-muted`。
- 准星已全局挂载，编辑器不需要重复实现；编辑器只需保证 `pointer-events` 正常，不要给全屏 overlay 设 `cursor` 覆盖（`cursor:none !important` 已兜底）。
- 若 D-1 选 P，新增 `EditorView` 等 P 名后再把 `Crosshair` 一并迁入 P，保持“全局表现层”归属一致。
