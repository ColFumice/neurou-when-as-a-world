## 1. 输入行与日志重叠

原因：

- `.console-output` 有 Fisheye transform/filter，最后一行视觉上会向输入行溢出；
- input 背景透明，日志文字从 input 后面透出来。

修复：

```css
.project-console__input {
  position: relative;
  z-index: 5;
  background: #000000;
  padding: 0.45rem 0 0.2rem;
  margin-top: 0.15rem;
  min-height: 1.5em;
}
```

- input 行独立黑底；
- 提升到 z-index 5，压住 Fisheye 溢出的最后一行；
- 输入行下方的 7 行 tail space 同样纯黑。

## 2. 故障强度随机 + 滞留方框

### 强度

每次 burst 生成：

```ts
const intensity = 0.12 + Math.random() * 0.88;
const strength = intensity;
```

强度同时控制：

- 矩形群数量（1–2 群）；
- 每群矩形数（1–5）；
- 栅格数（1–6）；
- 雪花数（1–4）；
- 反色块（强度 > 0.35 才出现）；
- 错位切片数（1–4）；
- 长条数（1–7）；
- 所有 opacity 乘以 `0.45 + intensity * 0.55`；
- 全屏闪色透明度。

因此从几乎只有一条细线，到当前最大密度都会出现，不再全是同一档。

### 滞留方框

每次 burst 额外生成 2–4 个：

- 随机位置/大小；
- 1px 同色边框；
- 同色 16% 填充；
- 动画 `global-glitch-residue` 1050ms；
- 其他故障动画结束后，这些方框仍停留约 1s；
- burst 生命周期延长到 920–1180ms。

### 纯白矩形

- 仅强度 > 0.3 时出现；
- 第一个短矩形/长条可纯白；
- 避免低强度故障被纯白块抢走主体。

## 3. 匀速放大

之前 `console-camera-push` 有多段 scale 关键帧 + 抖动，视觉上像三段。

现在：

```css
animation: console-camera-push 700ms linear 900ms both;
```

```css
@keyframes console-camera-push {
  0% { transform: scale(1); }
  100% { transform: scale(2.18); }
}
```

- 900ms 后开始；
- 700ms 内从 1 线性匀速到 2.18；
- 不再有中间停顿/加速/抖动；
- 其他残影/复制流保持独立。
