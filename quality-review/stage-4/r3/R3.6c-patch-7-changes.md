# R3.6c-patch-7 变更说明

- 日期：2026-10-21（Asia/Shanghai）
- 范围：世界进入动画整体重构
- 原则：保留纯黑终端、白边、等宽字体的整体风格，用更克制的电影感替代此前的暴力震颤/全帧印记

---

## 1. 新的进入动画

```text
0.0–0.9s   日志持续滚动，终端静止
0.9–1.6s   镜头从点击节点方向推进，scale 1 → 2.18
1.6–2.0s   保持满屏，短暂受控抖动
2.0s       白色扫描线收束 + 黑屏（260ms）
2.0–5.0s   纯黑 3s，WorldInstance.prologue 字幕
5.0s       白色 Bloom + 世界场景出现
5.0–7.0s   blur(20px) brightness(2.2) → 正常
```

### 项目进入字幕

ProjectConsole 的启动文本不再一次性出现：

- `introText` 以 **2 字符 / 9ms** 逐字写入；
- 输入行跟随已打印文本向下移动；
- 完整打印后再自然进入可输入状态；
- 长文本、项目序言、Project ID 都逐字出现。

### 加载日志

进入世界前的日志改为多字段、近满行输出：

```text
[ OK ] world.w1/layer.02  pkg=30.0MB  chunk=02/64  crc=0x...  stream=parallax
[04%] shader.pass=202/2048  textures=32  buffers=10  vram=116MB  [====>       ]
       asset=world.w1.atlas  worker=render.main  node=c.2  elapsed=78ms  state=mounting
```

每 70ms 三行，包含 package、chunk、crc、shader pass、textures、buffers、VRAM、asset、worker、node、elapsed、state 等字段。

### 镜头推进

- CSS 动画而非每 20ms React 更新；
- `animation: console-camera-push 700ms cubic-bezier(0.22,0.61,0.36,1) 900ms both`；
- `transform-origin` 使用点击节点屏幕坐标；
- 1.6s 时已达到 2.18，满屏但不继续放大；
- 内置 4 次小幅抖动（±7px），保留“震颤”但不再破坏可读性。

### 复制流与加速上滚

- 0.9–2.0s 在终端上方叠加 `.project-console__stream`；
- 当前最后 16 行被向下复制 12 份；
- track 通过 `console-stream-rush 1100ms cubic-bezier(0.55,0,0.95,0.35)` 向上滚动；
- 35% 仅 -260px，70% -1100px，100% -2400px，速度持续加快；
- 偶/奇副本带水平错位，叠出“复杂化”的文本层；
- 后段 `console-stream-tear` 扫描线与 RGB 带渐显，形成花屏；
- 2.0s 黑屏时整层移除，不残留。

### 残影

不再渲染 80+ 全帧 DOM imprint，而是 3 层受控 echo：

- 当前终端最后 16 行；
- 三层水平/垂直偏移，opacity 0.10 / 0.07 / 0.045；
- 随父级镜头一起放大；
- 900ms 内缓慢淡出，形成“记忆残像”而不是噪声。

### CRT 收束

- 2.0s 黑场时叠加一条 1px 白色水平线；
- 260ms 内从屏幕宽度收束到 0；
- 然后只剩纯黑与字幕。

### 5s Bloom

- 5.0s 独立 timer；
- 白屏 opacity 1 → 0，200ms；
- 世界场景同时从 blur(20px)/brightness(2.2) 开始 2s 恢复。
