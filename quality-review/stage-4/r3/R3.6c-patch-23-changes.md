## 1. 问题

退出世界后：

```text
displayLines = [...intro, ...history, ...enterLogs]
```

`enterLogs` 仍保留加载日志，而新命令回复写入 `history`，所以回复出现在加载日志上方。

## 2. 修复

world `exit` / `quit` 时增加：

```ts
setEnterLogs([]);
```

效果：

- 退出世界后加载日志立即清除；
- 之后的新命令回复进入 `history`；
- 显示顺序变为：

```text
intro
history（旧命令 + 新回复）
enterLogs（空）
```

- 回复不会再出现在加载文字上方；
- 输入行仍可继续使用。

## 3. 保留

- 5–7s token 清理，防止回拉；
- input `autoFocus`；
- 输入行黑底，避免与上方文字重叠；
- 7 行尾部空白；
- 错误行红色；
- 加载期白块自然堆积。
