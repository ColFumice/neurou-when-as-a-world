## 1. 手感优化实现

### 1.1 新建 Folder 游走

`ProjectTreeLayout`：

- 空 Folder 使用 `phase(folderId)` 的确定性圆轨道；
- 半径从 10 改为 **24px**；
- 位置仍在中央空 folder 行（x 按数量居中、y 110、z 950）；
- 不再写死位置。

### 1.2 选中即定

`ProjectTreeLayout` 新增可选输入：

```ts
selectedNodeId?: string | null;
pinnedWander?: { nodeId: string; x: number; y: number } | null;
```

`LayoutNode` 新增输出：

```ts
wanderX: number;
wanderY: number;
```

规则：

- 选中节点：使用点击瞬间的 `pinnedWander`，不再推进 wander；
- 选中期间相机 `targetPanX / targetPanY = 0`，用原有 0.08 平滑归零；
- 点击空白：`pinnedWanderRef = null`，恢复节点游走和鼠标相机；
- 点其他节点：重新捕获该节点当前 wander。

`ProjectTreeView`：

- `layoutRef` 保存最新 layout；
- `pinnedWanderRef` 保存选中节点 wander；
- 每次 `ProjectTreeLayout.compute` 传入 `selectedNodeId` / `pinnedWander`。

## 2. ProjectConsole 与 useConsoleSession

### 2.1 同模块方案

按批准方案，`WorldFolderConsole` 与 `ProjectConsole` 放在同一模块：

`v4/core/presentation/console/WorldFolderConsole.tsx`

内部 `useConsoleSession` 和 `ConsoleSession` **不导出**，避免新增 non-A export；文件头已加注释说明。

`ProjectConsole` 是新增 A export，import 路径为：

```ts
import { ProjectConsole } from '@core/presentation/console/WorldFolderConsole';
```

### 2.2 Session 架构

`useConsoleSession` 统一维护：

- `ConsoleDirectory` / currentPath / visibleEntries；
- selected / hovered / selectionMode；
- history / input / effect / settings / contextMenu；
- command 解析、`ConsoleDirectoryConstraint`、open/cd/exit；
- `append` / `submit` / `handleRootKeyDown` / 右键菜单；
- add/remove/export（WorldFolderConsole 使用）。

两个组件只保留：

- WorldFolderConsole：目录栏 + 文件选择 + context menu；
- ProjectConsole：纯文本全屏、无栏目、项目 metadata 头。

### 2.3 ProjectConsole

Props：

```ts
project: Project;
worlds: readonly WorldInstance[];
onExit: () => void;
onEnterWorld?: (world: WorldInstance) => void;
```

头部输出：

```text
loading project package...
reading project.json...
mounting worlds...
ready.
NEUROU PROJECT CONSOLE / chromato
Author: …
Created: 2023-11-14
Completed: —
Worlds: 2
Theme: #607684
Prologue: chromato
  chromato 的项目序言。
Project ID: 1000 0001
Type 'help' to get command list
```

- `Prologue` 严格来自 `ProjectMeta.prologue`；
- `Worlds` 来自 `ProjectMeta.worldIds`；
- Project ID 本地格式化，不引入 S 层值依赖。

命令：

- `ls`：列出 World 条目（WorldExe）；
- `cd world`：进入虚拟目录并触发该 World；
- `open` / `open world`：触发 World；
- `pwd` / `help` / `clear` / `settings` / `export` / `import`；
- `exit`：返回项目树。

`exit` 已加入 `ConsoleCommand` 和 `ConsoleCommandList`，并补测试。

### 2.4 接入

- `ProjectTreeView` 新增 `onOpenProject(projectId)`；
- Project 第二次点击 → DOM 全屏放大 700ms → 720ms 后回调；
- `ProjectTreeDemoScreen` 增加 `activeProjectId`；
- 有 activeProject 时渲染 `ProjectConsole`；
- `ProjectConsole exit/← exit` → 回到项目树。

## 3. 5.2s 世界进入时序

`WorldLoadingSequence`：

```text
0.0s  WorldLoadProgressBar（加载行 + 进度）
0.7s  WorldPixelZoom
1.4s  黑屏；WorldEnterTransition 显示 WorldInstance.prologue
1.4–4.4s  字幕淡入 / 停留 / 淡出（3s）
4.4s  flash class 触发闪光
4.4–5.2s  世界视图从 blur + brightness 恢复
5.2s  onComplete
```

实现：

- `WorldEnterTransition` 新增 `prologue: string` 与 `flash: boolean`；
- 字幕 `<p class="console-enter-transition__prologue">`；
- CSS `console-prologue` 3s：0% 透明 → 16% 显示 → 84% 显示 → 100% 透明；
- `console-flash` 只在 `.is-flashing` 时触发，不在黑屏开始就闪；
- `ProjectConsole` 完成后渲染 `.project-console__world`，带 `project-world-recover` 动画（blur 18px/brightness 2.2 → 正常）；
- 过渡期间不写账本、不改世界状态。

验证截图：

- `r36c-subtitle2.png`：黑屏中央显示 `WorldInstance.prologue`（chromato 世界序言）；
- `r36c-world.png`：恢复后的世界视图，显示同一 world prologue；
- ProjectConsole 头部显示的是 `ProjectMeta.prologue`，两者未混用。

## 6. 人工验收清单

1. **选中即定**
   - 点击 Project/Folder：节点自身停止游走；
   - 相机 pan 平滑归零；
   - 点击空白：恢复游走与鼠标相机。
2. **新建 Folder 游走**
   - 新 Folder 在中央行，20s 内可见 24px 圆轨道；
   - 尺寸 0.65、白边、连线正常。
3. **进入 cmd**
   - 项目树点击 Project 两次 → 全屏放大 → ProjectConsole；
   - 头部 Author/Created/Completed/Worlds/Theme/Prologue/Project ID 正确；
   - 头部 Prologue 是 ProjectMeta.prologue。
4. **命令**
   - `ls` 显示 WorldExe w1/w2；
   - `cd w1` 或 `open w1` 触发进入；
   - `pwd` / `help` / `clear` / `settings` 正常。
5. **黑屏字幕**
   - 1.4s 黑屏，中央白色字幕来自 WorldInstance.prologue；
   - 3s 后闪光，世界从模糊过曝恢复；
   - 与 ProjectMeta.prologue 不混用。
6. **exit**
   - 输入 `exit` 或点击 `← exit` 返回项目树；
   - 无崩溃、无 textureSource 错误。
