## 1. 故障色调跟随项目

新增全局事件：

```ts
window.dispatchEvent(new CustomEvent('neurou:glitch-tone', {
  detail: 'cool' | 'warm' | 'neutral',
}));
```

判定：

```ts
const warmth = theme.r - theme.b;
if (warmth > 14) return 'warm';
if (warmth < -14) return 'cool';
return 'neutral';
```

- **ProjectTreeView 选中项目**：按项目 theme 发出 cool/warm；
- **ProjectTreeView 选中文件夹**：按文件夹平均 theme 发出；
- **空白点击/双击建文件夹**：neutral；
- **进入 ProjectConsole**：按 `project.meta.theme` 发出；
- **world 内**：保持该 project 色调；
- 退出项目/控制台：neutral。

调色板：

```text
cool:  #5f8fad #6f7fb0 #5fa99b #7a8fbf #88a6b8 #9aa8b8
warm:  #b06a5f #b38a55 #a35f78 #b07f5f #b99a72 #b8a8a0
neutral: #8f9498 #96918d #858c94 #9b9b9b #8f8b92
```

冷色项目内故障为蓝/青/紫灰；暖色项目内为红/琥珀/紫暖灰。

## 2. 不再所有操作都触发

### 鼠标移动

不监听 `pointermove`，移动完全不触发。

### 点击

从 `pointerdown` 改为 `click`，且只对交互目标触发：

```text
button, a, input, textarea, select,
[role="button"], [contenteditable="true"], canvas, svg
```

- 项目树 canvas：触发；
- 事件树 SVG：触发；
- 按钮/输入框：触发；
- cmp 空白、普通 div：不触发；
- 纯装饰点击：不触发。

### 键盘

- 普通输入字符不触发（避免打字每字符闪）；
- Enter / Esc / Tab / 方向键 / Backspace / 快捷键触发；
- Shift/Ctrl/Alt/Meta/CapsLock 单独按下不触发。

### 滚轮

- 160ms 节流；
- 不再每个 wheel event 都触发。

### 环境故障

每 12s 一次，45% 概率，比之前更低。

## 3. 退出世界输入加固

- `enterTokenRef`：进入 +1，退出 +1；
- 5s/7s timer 检查 token；
- 退出清 `activeWorld` / `loadingWorld` / phase / world command；
- cmp input `autoFocus`；
- rAF + setTimeout 双 focus。

避免退出后被旧时间线拉回，或输入框失焦。

## 6. 人工验收

1. 选择冷色项目：点击后故障为冷色；进入 cmp/world 仍是冷色。
2. 选择暖色项目：故障为暖色；进入 cmp/world 保持。
3. 鼠标移动：无故障。
4. 点击 cmp 空白/普通文本：不触发。
5. 输入框打字：字符键不触发；Enter 才触发。
6. 点击项目树 canvas、按钮、输入框：触发。
7. world `exit` 后立即可以输入。
8. 5–7s 内退出也不会被拉回。
