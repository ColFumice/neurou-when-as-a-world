## 6. 主题图占位策略

`ThemeBackground`：

- `ThemeBackground.createSpec(theme, seed)` 生成确定性 spec：1920×1080、gridSpacing 48~80、noiseSeed、20s Ken Burns 周期。
- `render(context, theme, seed)` 在 Canvas 2D 上画：
  - 主题 RGB 的低亮度渐变；
  - 0.42 alpha 的主题色中段；
  - 网格线；
  - 900 个确定性噪点。
- `ProjectTreeView` 为每个节点/主题生成一次 Canvas → `PIXI.Texture`，缓存在 `textureCache`；多节点共享。
- 选中/悬停时才需要纹理；24 节点压力下 60fps。
- 素材替换接口：`ThemeBackground.setCustomImage(image)` / `getCustomImage()` / `hasCustomImage()`；`ProjectTreeView` 目前仍使用程序化 Canvas，真实素材 R3.6c 接入。
- 背景 crossfade + Ken Burns 1.05× / 20s 在 `ProjectTreeView` 中实现。

## 10. 人工验收清单

`tauri dev` 启动后默认进入项目树：

1. 看到 3 个初始节点：`A Try` folder + `chromato` + `plasmato`。
2. 颜色：A Try 灰绿平均色、chromato 灰绿、plasmato 橙灰。
3. 近大远小：z 比方框更大；A Try 选中后放大 1.5×。
4. 方框缓慢游走；20s 内可见轻微移动。
5. 鼠标移到屏幕边缘：相机向该方向偏移。
6. 滚轮：dolly 变化，方框缩放。
7. 鼠标悬停项目：背景交叉淡入项目主题图；移开保持最后一张。
8. 点击项目：方框放大 1.5×，外部节点降亮。
9. 再次点击选中方框：主题图放大到全屏（视觉；ProjectConsole 跳转 R3.6c）。
10. 双击空白：反色涟漪扩散，并创建一个新的空 ProjectFolder（调用 R3.6a `Workspace.materialize` 内存端口）。
11. 右键空白：画面降饱和后恢复。
12. 鱼眼：屏幕边缘轻微桶形畸变；暗角：四角变暗。
13. 返回按钮回项目事件树；“视差演示”仍可用。

### 已知偏差

- 外部节点采用 `alpha=0.28` 降亮，没有额外 blur（避免 24 节点 filter 叠加；R3.6b 视觉可接受，后续可加）。
- `SPAN_X/SPAN_Y` 采用 900/400（计划草案 480/270），以让相近主题色方框不重叠；RGB→XYZ 关系与近大远小不变。
- 双击空白创建的是**空 folder**，只调用 `Workspace.materialize` 的内存目标；真实 workspace 文件写入留 R3.6c/d 接 UI。
- 24 节点压力 fixture 是临时测试数据，最终恢复 3 节点。
