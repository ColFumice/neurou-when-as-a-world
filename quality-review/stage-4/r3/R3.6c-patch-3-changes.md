## 3. 加载动画（定点缩放 + 5s Flash）

### 3.1 点击坐标

- `ProjectTreeView.onOpenProject(projectId, origin)` 把选中节点的屏幕中心传入；
- `ProjectTreeDemoScreen` 保存 `openOrigin`；
- `ProjectConsole` 接收 `origin`。

### 3.2 时序（7s）

```text
0.0–1.5s  输出区持续追加 [ OK ] / [xx%] / [====> ] 日志
1.0–2.0s  cmp transform: scale(1 → 11)
          transform-origin = 点击节点屏幕坐标
2.0s      scale + 黑屏遮罩；不显示像素点
2.0–5.0s  纯黑 3s，WorldInstance.prologue 字幕
5.0s      白色 Flash 瞬间 opacity 1 → 0（200ms）
5.0–7.0s  世界视图 blur(20px) brightness(2) → 正常
```

- 缩放使用 `easeInOutCubic`；
- 缩放只作用于 1.0–2.0s，避免一开始就看不到日志；
- 2.0s 不再使用低质量像素点，直接黑屏；
- Flash 严格在 reveal 阶段开始（elapsed ≥ 5000ms）；
- 世界恢复动画 2s。

说明：输入 `open` 时仍在 ProjectConsole 内，不弹全屏组件。

## 4. 新建 Folder 不游走：根因与修复

### 根因

`ProjectTreeView` 的长驻 effect 依赖 `[]`，但 ticker 里的 `ProjectTreeLayout.compute` 仍使用闭包中的初始 **`workspace` prop**，而不是 `workspaceRef.current`。

因此：

- 新建 Folder 后，`rebuildScene` 用最新 workspace 创建了 NodeView；
- 但每帧 ticker 仍用旧 workspace 计算 layout；
- 旧 layout 没有新 Folder → 新节点永远不会进入位置更新循环；
- 表现就是“定死”。

### 修复

```ts
const layout = ProjectTreeLayout.compute({
  workspace: workspaceRef.current,
  ...
});
```

同时：

- 空 Folder 从固定 `y:110` 改为按空 Folder 数量计算的环形轨道：
  - `x = cos(π/2 + index/count*2π) * 260`
  - `y = sin(π/2 + index/count*2π) * 150`
  - 不再与 A Try 重叠；
- 游走半径 24px，周期 6s；
- ticker 首次遇到新 Folder 时输出：

```text
[projecttree] folder wander folder:pf-0002 <wanderX> <wanderY>
```

确认 `wanderX/wanderY` 不为 0。

验证截图：`r36c-p3-folder-a.png` / `r36c-p3-folder-b.png`，2s 内位置可见变化。

## 5. 输入焦点

为彻底解决“输入一次后 Enter 不再提交”：

1. 单行 `<input>` 不再 unmount；
2. input `onKeyDown` Enter → `submitInput()`；
3. `submitInput()` 提交后 `requestAnimationFrame` 重新 focus；
4. 历史/加载行变化后再次 focus；
5. window 级 Enter fallback：

```ts
if (event.key === 'Enter' && document.activeElement === inputRef.current) {
  event.preventDefault();
  submitInput();
}
```

当前手动验证可连续单条 `ls` 提交；自动连发 20 条仍受本机键盘/输入法环境影响，需人工用实际键盘确认。
