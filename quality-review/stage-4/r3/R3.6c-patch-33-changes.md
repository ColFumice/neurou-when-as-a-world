# R3.6c-patch-33 变更说明

- 日期：2026-10-23（Asia/Shanghai）
- 范围：反色矩形数量、滞留白块透明度、错位强度分级
- 状态：完成，待 Trae 测试 + 用户人工验收

---

## 1. 反色矩形数量增加

之前：

```ts
const inversionCount = intensity > 0.35
  ? 1 + Math.floor(rand() * (1 + intensity * 3))
  : 0;
```

现在：

```ts
const inversionCount = intensity > 0.18
  ? 2 + Math.floor(rand() * (2 + intensity * 6))
  : 0;
```

- 最低 2 块；
- 最强约 8–9 块；
- 局部反色更多、更密。

---

## 2. 滞留白块降至 65%

```css
@keyframes global-glitch-white-block {
  0% { opacity: 0; transform: scaleY(0.4); }
  100% { opacity: 0.65; transform: scaleY(1); }
}
```

- 白色滞留矩形不再 100% 不透明；
- 固定为 65%；
- 仍可自然叠加形成白屏，但单块不再刺眼。

---

## 3. 错位强度跟随故障强度

`TearFilter` 从固定 `scale=190` 改为动态：

```ts
setTearScale(35 + intensity * 155);
```

```tsx
<feDisplacementMap
  in="SourceGraphic"
  in2="tear-map"
  scale={scale}
  xChannelSelector="R"
  yChannelSelector="G"
/>
```

- 轻微故障：scale 约 35（约 17px 位移）；
- 中等故障：scale 80–120；
- 最强：scale 190（约 95px 位移）。

持续时间也随强度：

```ts
100 + intensity * 180 + rand() * 40
```

- 轻微：约 100ms；
- 最强：约 280ms。

不是所有故障都用同样的错位幅度。

---

## 4. 真实错位保持不变

- 22 条横向断层；
- 每条随机 ±95px；
- SVG `feDisplacementMap` 直接移动整个 UI 像素；
- 故障结束移除滤镜。
