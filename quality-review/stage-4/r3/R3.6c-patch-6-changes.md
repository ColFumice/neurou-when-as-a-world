# R3.6c-patch-6 变更说明

- 日期：2026-10-21（Asia/Shanghai）
- 范围：震颤强度、逐帧固定印记、满屏时序
- 状态：完成，待 Trae 测试 + 用户人工验收

## 1. 震颤强度

从原来的 10–20px 提升到：

```ts
const amplitude = 24 + ramp * 28; // 24–52px
```

- 采样间隔 **20ms**（约 50 次/秒）；
- 1.5–2.0s 保持 scale 2.25，持续剧烈位移；
- 2.0s 黑屏时归零。

## 2. 逐帧固定印记（不是移动 text-shadow）

旧实现是给当前抖动文本叠加 text-shadow，阴影跟随当前文本移动，视觉上不是真正留在屏幕上的“印记”。

新实现：

- 每一帧记录 `{ x, y, scale }` 到 `shakeTrails`；
- 0.35–2.0s **不丢弃任何帧**（约 82 帧）；
- 在 `.project-console` 外层（不受抖动 transform 影响）渲染固定 DOM 层：

```text
.project-console__imprints (fixed, z-index 1)
  └─ .project-console__imprint × N
       ratio = zoomScale / frame.scale
       transform: translate3d(frame.x * ratio, frame.y * ratio, 0) scale(zoomScale)
```

- 当前 `.project-console` 为 z-index 2，并在缩放时背景半透明；
- 每个 imprint 是独立的白色终端文本快照（最后 16 行），固定停在那一帧的屏幕位置；
- 因此每一次震颤都会留下新的白色印记；旧印记停在历史位置，但按当前 `zoomScale` 一起放大；
- 透明度随帧序号提升，约 82 帧后白色文字铺满屏幕；
- 2.0s 黑屏时清空全部 imprint。

## 3. 缩放与满屏

```text
0.0–0.7s  scale 1；日志滚动
0.35–1.0s  scale 1 → 2.25（easeInOutCubic）
1.0–2.0s  scale 2.25，满屏震颤 + 全帧印记累积
2.0s      黑屏
```

- 最大只到 2.25，避免过度放大；
- 1.0s 已铺满，1.0–2.0s 通过印记累积形成白色覆盖。

## 4. 行距与像素感

- 行距 **1.1**；
- 扫描线/2px 点阵增强；
- 文本 RGB 分离与 contrast；
- Fisheye 设置仍可加强透视/暗角。

## 5. 退出世界输入

保持 patch-5 修复：

- world `exit` / `quit` 清 `loadingWorld`；
- 中止 7s 时间线；
- 返回 cmp 后自动 focus 输入框；
- 7s 不会再次拉回 world。
