## 1. 震颤只在最后 0.5s

加载时间线：

```text
0.8–3.6s   放大
3.1–3.6s   日志剧烈震颤（最后 0.5s）
3.6s       黑屏
```

实现：

```css
.project-console.is-zooming .project-console__fisheye {
  animation: console-log-shake 70ms steps(2, end) 3100ms infinite;
}
```

- animation-delay = 3100ms；
- 前 3.1s 完全静止；
- 3.1–3.6s 以 70ms 步进剧烈抖动；
- 最大横向位移 52px、纵向 26px、旋转 1°；
- 3.6s 移除 `is-zooming`，立即停止。

镜头放大本身仍为 0.8–3.6s 缓入缓出，不受影响。
