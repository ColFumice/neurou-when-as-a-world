# R3.6b 补丁 1 变更说明

- 日期：2026-10-21（Asia/Shanghai）
- 范围：双击空白崩溃、选中降亮、放大视觉、Folder 展开/收起、反色涟漪
- 状态：R3.6b 补丁 1 完成，待 Trae 测试 + 用户人工验收

## 1. 崩溃根因与修复

### 根因

`ProjectTreeView` 的 effect cleanup 中显式执行了：

```ts
for (const texture of textureCache.values()) texture.destroy(true);
```

此时 fisheye filter / stage shader 仍绑定同一批 `TextureSource`；双击空白会触发 `onCreateFolder` → workspace 更新 → `ProjectTreeView` 重挂载，cleanup 立即销毁纹理，WebGL 报：

```text
textureSource was destroyed while still bound to a shader
```

### 修复

1. **不再在 cleanup 显式 destroy Texture。**
   - `textureCache.clear()` 只丢引用；
   - 交给 `PIXI.Application.destroy()` 与 GC 处理，避免 shader 仍绑定时销毁 source。
2. **涟漪不再创建 Pixi Texture。**
   - `InvertRipple` 改为纯 DOM/CSS 覆盖层，不参与 Pixi texture 生命周期。
3. **双击后的 workspace 更新延后 760ms。**
   - 先完成 700ms 涟漪，再 `setWorkspace` 重挂载；
   - 避开 ripple 渲染中同步重挂载。
4. **保留 StrictMode 兼容的 `disposed` guard。**
   - async mount 完成时若已卸载，直接 destroy 新 app；
   - cleanup 移除 ticker、事件、app。
5. 纹理缓存仍共享：同 theme/seed 只生成一张 1920×1080 Canvas → Texture。

## 2. 五个调整点

### 2.1 外部节点降亮

- 选中节点：`alpha = 1`。
- 其他节点：`alpha = 0.1`（原来 0.28 在暗背景上不明显）。
- **选中 Folder 时，其子项目不降亮**（否则展开效果看不见）；Folder 外节点仍降到 0.1。
- 选中节点 `zIndex = 10000`，保证在节点层上方。
- 保留白色边框 + glow；外部节点不再淡到不可见。

### 2.2 放大效果

- 所有方框边框改为 `#FFFFFF`，并加一层白色 glow（5px、alpha 0.22）。
- 选中 Project：目标缩放 `1.5×`，通过 `displayScale += (target - displayScale) * 0.18` 每帧缓动，不是 jump。
- 进入全屏放大状态时：
  - `zoomActive = true`；
  - `VignetteEffect` 不渲染；
  - 只保留 fisheye / 背景。
- 空白点击或选择其他节点会退出 zoom，重新显示暗角。

### 2.3 ProjectFolder 交互

- Folder **不参与 1.5× 放大**。
- 点击 Folder：
  - 选中 Folder；
  - 切换 `collapsedFolders`；
  - 不做 zoom。
- 收起：
  - 子项目 `reveal` 从 1 → 0；
  - 位置向 Folder 中心插值（`0.16`/帧）；
  - 连线在 `reveal < 0.25` 时消失。
- 展开：
  - `reveal` 从 0 → 1；
  - 子项目从 Folder 中心滑出；
  - 连线淡入；
  - Folder glow 保持（展开或选中时）。
- Folder 选中时外部节点降亮；子项目保持可见。

### 2.4 反色涟漪（参考 `expanding_filtercircle_effect_code(html).txt` 的 ripple 模式）

实现 `InvertRipple`：

- 曲线：`ln(1 + 4p) / ln(5)`（先快后慢，参考实现同款）。
- 半径：80px → 画面对角线；软边 `8 + min(radius,600)*0.02`。
- 视觉：白色径向渐变 + `mix-blend-mode: difference`，圆内反色、边缘平滑。
- 动画：700ms；每帧更新 progress。
- 结束 20% 阶段叠加 `InvertRipple.exposure()` 曝光脉冲。
- **不用 `backdrop-filter`**：WebView2 在 WebGL canvas 上使用 backdrop-filter 可能卡死；改用 difference 混合，视觉等价且稳定。
- 不创建/销毁 Pixi texture，避免再次触发 shader source 错误。

### 2.5 其他

- `ProjectTreeLayout` 的 LayoutNode 增加可选 `projectId/folderId`，供 View 判定 Folder 子项目；3D 公式、相机、游走、RGB→XYZ 系数未改。
- 双击空白创建空 Folder：等 760ms 后调用 `Workspace.materialize` 内存端口；真实 workspace 写入仍在 R3.6c/d 接。
- 右键空白降饱和不变。
- 滚轮 dolly / 相机 pan / 悬停主题图不变。
