## 4. 新增 A 类名（12，全部 S 层）

| A 类名 | 语义 |
|---|---|
| `Workspace` | 工作区根 + 聚合 |
| `WorkspaceRoot` | 工作区根路径 |
| `ProjectFolder` | 项目文件夹（一层） |
| `ProjectFolderId` | `pf-0001` |
| `Project` | 项目（meta + folderId） |
| `ProjectId` | 8 位数字字符串 |
| `ProjectMeta` | schema v2 元数据 |
| `ProjectTheme` | RGB 主题色 |
| `ProjectPrologue` | 项目序言（项目 cmp 头） |
| `ProjectTree` | 节点 + Link 边 |
| `ProjectTreeNode` | Folder / Project 节点 |
| `ProjectTreeEdge` | 仅显式 Link |

- A 类总数 294；已实现 **137**；未实现 157。
- 无新增 A 名；全部来自 NAMEBOOK §1.21。

### 关键约定

- `ProjectId`：内部 `^\d{8}$`；显示 `1234 5678`。
- `ProjectFolderId`：内部 `pf-0001`；显示 `0001`。
- `ProjectTreeEdge.kind` 只有 `'Link'`；文件夹包含关系由 `folder.projectIds` 派生，`ProjectTree.deriveContainment()` 返回内部 `Contains` 视图边。
- `ProjectTreeNode.offset` 是 WASD 视觉偏移，不参与 RGB→XYZ 基础位置。
- `ProjectMeta.legacyProjectId` 只在迁移时写。
- `ProjectTheme` 只存 RGB；W 层不读取渲染颜色。

## 6. 迁移策略

`Workspace.migrateLegacy(source, target, options)`：

1. 只读读取 v1 `project.json`；校验 schemaVersion 1 / projectId / projectName / createdAt / worldIds。
2. 读取目标 `workspace.json`；若已有 project 的 `legacyProjectId` 等于旧 ID，返回 `AlreadyMigrated`，不新建。
3. `ProjectId.fromDigest(options.legacyDigest, taken)`：
   - SHA256 由调用方/测试注入（S 不 import crypto）；
   - 前 8 个 hex → 8 位十进制；冲突线性重试。
4. 生成/复用 folder；写 v2 `project.json`（legacyProjectId、theme、author、completedAt=null、prologue=empty）。
5. 复制 event-tree / worlds / media / drafts：
   - `source.listFiles` + `readBytes` + `target.writeBytes`；
   - 每个文件比较 source/target SHA256。
6. 成功后写 `folder.json` + `workspace.json`；失败删除本次 projectDir（及新建 folder），已有 folder 则恢复原 folder.json；源目录不动。
7. 测试覆盖迁移、逐文件 hash、失败回滚、可重入。

`Workspace.materialize(target, root, folders, projects)` 提供数据层落盘：workspace/folder/project 元数据 + 每个项目的 worlds/media/drafts 目录，不写世界内容。

## 9. Tauri workspace 端口

```text

workspace_read_json
workspace_write_json_atomic
workspace_ensure_dir
workspace_list_dir
workspace_move_to_trash

```

- `ActiveWorkspaceRoot` 是独立 newtype state，与 `ActiveProjectRoot` 分离。
- 路径限制：绝对路径、盘符、UNC、`..`、符号链接逃逸全部拒绝；复用 `resolve_in_root` 模式。
- trash：源移入 `<workspace>/.trash/<uuid>-<name>`；恢复拒绝覆盖已存在目标；禁止 trash 目录自身。
- capabilities：`core:default` + 8 个 `allow-workspace-*`；权限 TOML 跟踪，不开放通用 fs 插件。
