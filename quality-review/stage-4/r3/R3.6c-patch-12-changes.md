## 1. 退出世界后无法输入

### 加固

旧实现已经清 `loadingWorld`，但仍可能在 5–7s 窗口内被旧 timer 回写。

新增 token：

```ts
const enterTokenRef = useRef(0);
```

- `beginEnter`：token +1；
- world `exit` / `quit`：token +1，再清 world 状态；
- 5s flash timer / 7s timer 都检查：

```ts
if (token !== enterTokenRef.current) return;
```

同时：

- `setActiveWorld(null)`
- `setLoadingWorld(null)`
- `setEnterPhase('idle')`
- `setWorldCommandOpen(false)`
- `autoFocus` 控制台 input
- rAF + setTimeout 双保险 focus

返回 cmp 后输入行立即恢复。

## 2. 故障图形改为长条矩形

删除了独角鲸等不规则 clip-path，改为：

- 每次 4–7 条 **全宽长条矩形**；
- 高度 0.7–3.3%；
- 随机纵向位置；
- 水平位移 ±90px；
- 保留连续短矩形群作为叠层纹理。

长条样式：

```css
.global-glitch__long-strip {
  left: -12%;
  width: 124%;
  height: var(--strip-height);
  background: linear-gradient(
    90deg,
    transparent,
    var(--glitch-tone-2) 8%,
    var(--glitch-tone) 42%,
    var(--glitch-tone-2) 74%,
    transparent
  );
}
```

## 3. 增强错位

- 切片位移从 ±14px 提升到 **±80px**（总跨度 160px）；
- 长条位移 ±90px；
- 增加 skewX：
  - 长条 -4° / +3°；
  - 切片 -10° / +8°；
- 动画改为三段 steps：
  - 0% 反向偏移；
  - 18% 正向大幅错位；
  - 58% 反向过冲；
  - 100% 复位淡出。

同时保留：

- 雪花；
- 局部反色；
- 密集横向栅格；
- 全屏低饱和色闪。
