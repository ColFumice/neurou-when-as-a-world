```text

```

## 2. 白色矩形密度

### 短矩形

```ts
const whiteQuota = intensity > 0.7 ? 5
  : intensity > 0.4 ? 2
  : 0;
```

- 最强时每组 burst 最多 **5 块纯白短矩形**；
- 后续白块概率 `0.2 + intensity * 0.45`；
- 普通矩形群仍保留。

### 长条

```ts
const stripWhiteQuota = intensity > 0.7 ? 4
  : intensity > 0.4 ? 1
  : 0;
```

- 最强时最多 **4 条纯白长条**；
- 长条总数最多 9 条；
- 白条 box-shadow 在 max 档增强为：

```css
box-shadow:
  0 0 16px rgba(255,255,255,0.95),
  0 0 42px rgba(255,255,255,0.35);
```

## 3. 其他故障强度

最强档：

- 栅格最多 8 条，对比度/亮度更高；
- 雪花最多 7 块，`contrast(3.2) brightness(1.9)`；
- 反色最多 4 块，`invert(1) grayscale(0.8) contrast(1.65)`；
- 切片最多 7 条；
- 长条最多 9 条；
- 滞留方框最多 6 个；
- 全屏白闪持续时间 300ms；
- 所有 opacity 乘数提高。

低强度仍保持少量细线，不会全部变成满屏白块。
