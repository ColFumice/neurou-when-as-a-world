```ts

export type ProjectId = string;

/** 项目文件夹 ID；内部 pf-0001，显示 0001。 */
export type ProjectFolderId = string;

export type WorkspaceRoot = string;

export interface ProjectTheme {

  readonly g: number;
  readonly b: number;
}

export interface ProjectPrologue {
  readonly title: string;
  readonly lines: readonly string[];
}

export interface ProjectMeta {
  readonly schemaVersion: 2;
  readonly projectId: ProjectId;
  readonly projectName: string;
  readonly author: string;
  readonly createdAt: number;
  readonly completedAt: number | null;
  readonly theme: ProjectTheme;
  readonly prologue: ProjectPrologue;
  readonly worldIds: readonly string[];
  /** 迁移专用；v2 新项目不写。 */
  readonly legacyProjectId?: string;
}

export interface ProjectFolder {
  readonly schemaVersion: 2;
  readonly folderId: ProjectFolderId;
  readonly folderName: string;
  readonly projectIds: readonly ProjectId[];
}

export interface Project {
  readonly meta: ProjectMeta;
  readonly folderId: ProjectFolderId;
}

export type ProjectTreeNode =
  | {
      readonly nodeId: string;
      readonly kind: 'Folder';
      readonly folderId: ProjectFolderId;
      /** WASD 视觉偏移；不改变项目元数据。 */
      readonly offset?: { readonly x: number; readonly y: number; readonly z: number };
    }
  | {
      readonly nodeId: string;
      readonly kind: 'Project';
      readonly projectId: ProjectId;
      readonly folderId: ProjectFolderId;
      readonly offset?: { readonly x: number; readonly y: number; readonly z: number };
    };

export interface ProjectTreeEdge {
  readonly edgeId: string;
  readonly fromNodeId: string;
  readonly toNodeId: string;
  /** 只存显式链接；文件夹包含关系由 folder.projectIds 派生。 */
  readonly kind: 'Link';

export interface ProjectTree {
  readonly schemaVersion: 2;
  readonly nodes: readonly ProjectTreeNode[];
  readonly edges: readonly ProjectTreeEdge[];
}

export interface Workspace {
  readonly schemaVersion: 2;
  readonly root: WorkspaceRoot;
  readonly folders: readonly ProjectFolder[];
  readonly projects: readonly Project[];
  readonly tree: ProjectTree;
```

- `worldCount` 不落盘，由 `worldIds.length` 派生。

### 2.3 旧项目迁移

输入：v1 根目录（`project.json` schemaVersion 1、`event-tree.json`、`worlds/`、`media/`、`drafts/`）。

策略：**非破坏性复制迁移**。

1. 只读识别 v1；不自动改写旧目录。
2. 用户选择新 workspace 根；创建 `<workspace>/<folderId>/<projectId>/`。
3. 生成 8 位 `ProjectId`：
   - 优先从旧 `projectId` 的 SHA256 取模生成；
   - 冲突则重试；
   - `ProjectMeta.legacyProjectId` 保存旧 ID。
4. 写入 v2 `project.json`：
   - `projectName` 取旧值；`author` 取 `StudioProfile.displayName`（空则 `""`）；
   - `createdAt` 取旧值；`completedAt = null`；
   - `theme` 默认由旧 projectId 哈希生成稳定 RGB（可在迁移向导修改）；
   - `prologue = { title: '', lines: [] }`；
   - `worldIds` 保留。
5. 复制 `event-tree.json`、`worlds/`、`media/`、`drafts/`；逐文件校验 SHA256。
6. 写 `folder.json`、`workspace.json`、初始 `ProjectTree`。
7. 失败：删除本次新建的部分目录；旧目录不动；返回迁移诊断。
8. 成功：旧目录保留；用户确认后再手动删除。
9. 迁移前/中/后都允许只读打开旧项目作为“legacy workspace”，但写操作被禁止，直到迁移完成。

迁移测试：

- v1 → v2 目录结构、ID 格式、worldIds 不变；
- 复制失败回滚，旧目录无变化；
- 迁移可重复执行（legacyProjectId 已存在时不再生成新项目）；
- v1 `ProjectStore` R2 测试不变。

## 3. R3.6b 项目树视觉：3D 布局、鱼眼、暗角、主题图、缩放

### 3.1 3D 布局（Q2）

`ProjectTreeLayout` 是 P 层纯计算结果，不写 W/S 字段。

#### RGB→XYZ

对 Project（或 Folder 的平均色）取 0..1 归一化：

```text
nr = r / 255
ng = g / 255
nb = b / 255

baseX = (nr - 0.5) * 2 * SPAN_X          // SPAN_X = 480
baseY = (ng - 0.5) * 2 * SPAN_Y          // SPAN_Y = 270
baseZ = Z_NEAR + (1 - nb) * Z_RANGE      // Z_NEAR = 600, Z_RANGE = 700
```

- `baseZ` 越小越近；`nb` 越大越近。
- 对 ProjectId/NodeId 哈希加 ±12px 的确定性 jitter，避免 RGB 相同完全重叠。
- Folder 颜色 = 子项目 RGB 的算术平均；空文件夹用 `(64,72,88)`。

#### 透视投影

```text
perspective = FOCAL / (baseZ * dolly)      // FOCAL = 900, dolly = 0.7..1.6
screenX = cx + (baseX + wanderX + panX) * perspective
screenY = cy + (baseY + wanderY + panY) * perspective
scale = clamp(perspective, 0.55, 1.5)
```

- 方框始终 `rotation = 0`，只做 `scale`，所以始终正对屏幕。
- 近大远小由 `perspective` 自然得到；`scale` 用于文字/描边补偿。
- 深度排序：远（z 大）先画，近后画；点击命中按屏幕矩形，取最上层。

#### 相机（鼠标 + 滚轮）

- 鼠标相对屏幕中心距离越大，相机向该方向平移越多：

```text
targetPanX = clamp((mouseX - cx) / cx, -1, 1) * MAX_PAN_X
targetPanY = clamp((mouseY - cy) / cy, -1, 1) * MAX_PAN_Y
panX += (targetPanX - panX) * 0.08
panY += (targetPanY - panY) * 0.08
```

- 滚轮改 `dolly`：`targetDolly = clamp(targetDolly - wheelDelta * 0.0008, 0.7, 1.6)`，再平滑。
- `PAN` 只影响屏幕投影，不写持久化状态。

#### 游走路径

每个 Project 的路径点来自其 Worlds 的主题色：

```text
pathPoint(worldColor) = rgbToLocalOffset(worldColor) * 0.25
```

- `worldThemes` 从世界元数据读取；缺失则用 project.theme。
- 路径是闭合 **Catmull-Rom**；`phase = hash(projectId) / 2^32`；
  `t = (now / 16000 + phase) % 1`；输出 `wanderX/wanderY`。
- 只有一个世界主题色时，用半径 24px 的圆轨道，避免退化。
- Folder：用子项目颜色平均生成慢速轨道，周期约 24s。
- 每个节点有独立相位，避免整体同步游走。

### 3.2 渲染与效果

- `ProjectTreeView.tsx`：P，PixiJS 场景；路径线、背景、方框、文字在 Pixi；DOM 仅放右键菜单/HUD/输入弹层。
- `ProjectTreeLayout` 输出每节点 `screenX/screenY/scale/depth` 与 camera `panX/panY/dolly`；Pixi 只消费，不重复算 RGB。
- Folder 折叠时只画自身方框；展开时子项目从 Folder 中心按各自主题色径向滑出，边线从 Folder 连到子项目；折叠时反向收回。
- 选中 Project：方框放大 1.5×，内部显示主题图，方框外区域降亮/轻微糊化；再次点击方框内部：主题图先放大到全屏，方框遮罩随后放大，完成进入 ProjectConsole。
- 双击空白：新建 ProjectFolder；反色涟漪从点击点扩散。
- 右键空白：undo；右键 Project/Folder：删除/链接/新建项目（Folder）。
- 悬停 Project：背景交叉淡入该项目主题图；移开保持最后一张。
- `ThemeBackground`：悬停 Project 时交叉淡入项目 `theme/background.webp`；移开保持最后一张；静帧 + 慢 Ken Burns/视差/RGB 噪点，不直接依赖随机视频。
- `FisheyeEffect`：Pixi 自定义 fragment shader，径向桶形映射：

```text
n = (uv - 0.5) * 2
r2 = dot(n, n)
src = 0.5 + n * (1 + K * r2) * 0.5
K = 0.18
```

- `VignetteEffect`：径向暗角，`smoothstep` 叠加。
- `InvertRipple`：新建文件夹时从点击点扩张的差异圆；`mix-blend-mode: difference` 或 Pixi filter。
- `DesaturationEffect`：右键撤回时瞬间降饱和再恢复；CSS `filter: saturate()` 或 colorMatrix。
- 缩放：滚轮改 dolly；不改变 timeline/world。
- 性能预算：24 节点内 60fps；纹理缓存；只重绘变化层。

## 5. R3.6d 交互与回溯

### 5.1 历史栈数据结构（Q4）

只回放 **状态**，不回放真实鼠标轨迹。

内部快照（非导出，不新增 A 名）：

```ts
interface ProjectTreeVisualState {
  camera: { panX: number; panY: number; dolly: number };
  selectionNodeId: string | null;
  volume: number;
  effect: ConsoleEffect;
}

interface HistorySnapshot {
  revision: number;
  atMs: number;
  label: string;                 // "创建项目文件夹" / "链接" / "移动" ...
  workspace: Workspace;          // 只含 folders/projects/tree 元数据
  visual: ProjectTreeVisualState;
  trashRefs: readonly string[];  // 软删除路径；不复制文件内容
}
```

`UndoRedoStack`（A 类，泛型）：

```ts
class UndoRedoStack<T> {
  private past: T[] = [];
  private present: T;
  private future: T[] = [];
  private readonly capacity = 100;

  commit(next: T): void;   // past.push(present); present=next; future=[]
  undo(): T | null;        // future.unshift(present); present=past.pop()
  redo(): T | null;        // past.push(present); present=future.shift()
  canUndo(): boolean;
  canRedo(): boolean;
  clear(): void;
}
```

- 快照不包含世界文件、账本、媒体字节；删除通过 `.trash` 引用。
- 撤销/重做只恢复元数据与视觉状态；文件操作由 `WorkspaceMutation` 日志重放/回滚。
- 3 秒内再次右键：应用层识别为 `redo`；`UndoRedoStack` 本身保留 `lastUndoAt` 由调用方判断。
- 历史容量 100；超出丢弃最旧。

`TimeRewind`（A 类）：

```ts
type RewindMode = 'Idle' | 'Backward' | 'Forward' | 'Cancelled';

interface TimeRewindState {
  mode: RewindMode;
  cursor: number;        // 在 UndoRedoStack 历史中的索引
  speed: number;
  startedAt: number;
}
```

- 按住左方向键：`cursor` 逐步后退，按快照间隔（约 180ms）应用快照；视觉值可插值，文件状态只在快照边界应用。
- 松开左键：停在当前快照（相当于一次 undo）。
- 右键/ESC：`cancel()` 恢复到 rewind 开始前的快照，撤销这次回退。
- 按住右方向键：加速当前动画（不改变历史 cursor），不重放鼠标。
- `TimeRewind` 不直接写文件；由 App 将当前快照交给 WorkspaceStore。

### 5.2 撤销 / 重做策略

- 新建项目文件夹 / 新建项目 / 删除 / 链接 / WASD 移动 / Shift 加速视觉状态均可 undo。
- 删除：移动到 `.trash`；undo 恢复；redo 再移回 trash。
- 新建：undo 移到 trash；redo 恢复。
- 链接：只改 `workspace.json` / tree；快照恢复。
- 外部编辑冲突：**禁止覆盖**，只读诊断；undo 不强行写。
- 最大历史 100；不存世界 bytes。

### 5.3 输入优先级

从高到低：

1. **文本输入框聚焦**：所有字符/方向键归输入；Esc 只关闭最上层弹层。
2. **模态层**（链接编号、右键菜单、设置）：Esc 关闭；Enter 确认；方向键在菜单内移动；全局快捷键不触发。
3. **项目树拖拽**：超过 6px 才视为拖拽；竖直拖拽调音量，不触发点击/双击。
4. **项目树（无模态、无输入）**：
   - 左键单击：选中；再次点击已选中项目/文件夹：进入/展开；双击空白：新建项目文件夹。
   - 右键空白：undo；3 秒内再次右键：redo。
   - 右键项目：删除/链接；右键文件夹：删除/链接/新建项目。
   - 滚轮：缩放；WASD：移动选中；Enter：展开文件夹/进入项目。
   - 左/右方向键按住：时间回溯/加速；上/下方向键：音量（按住）；Esc：取消回退/关闭。
5. **世界/ProjectConsole**：输入框优先；Esc 返回项目树；左右键不再控制项目树。

- `ProjectSelectionMode` 记录 Keyboard / Pointer / Hover；
- WASD 选择：在所有节点中找方向点积最大且距离最近的节点；正交方向过滤；
- 音量：0..1，拖拽/上下键改 `volume`，亮度瞬间升降后恢复；R3.6 无音频源，先存状态与视觉反馈，真实音频 R3.5/R4 接入。

### 5.4 R3.6d 出口

- UndoRedoStack 单元测试：commit/undo/redo、容量、清空、快照不可变；
- TimeRewind 单元测试：反向 cursor、cancel、无鼠标轨迹；
- 输入优先级表测试（纯 resolver）；
- 人工：新建/删除/链接/撤回/3 秒 redo、左右回溯、音量手势、WASD。
