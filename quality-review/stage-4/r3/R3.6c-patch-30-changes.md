## 1. 输入行遮挡上方字幕

根因是：最后一行日志的 descender 超出 1.1 行盒，而输入行的黑色 mask / padding 从行盒底部开始，视觉上裁掉了上一行。

最终修复：

```css
.project-console__input {
  background: transparent;
  padding: 0.8em 0 0;
  margin: 0;
}

.project-console__scroll .console-output {
  padding-bottom: 0.6em;
}
```

- 输入行不再有黑色遮罩；
- 日志末尾额外 0.6em，容纳 descender；
- 输入行顶部 0.8em 空白；
- 输入仍在日志流里，不是独立栏；
- 下方 7 个空日志行不变。

实测截图：`r36c-tree-only.png` 中 help 末尾与输入行已分离。

## 2. 删除右侧滚动条

```css
.project-console__scroll {
  scrollbar-width: none;
  -ms-overflow-style: none;
}

.project-console__scroll::-webkit-scrollbar {
  width: 0;
  height: 0;
  display: none;
}
```

- 仍可滚动；
- 不显示右侧滚动条；
- 底部也不会出现横向滚动条。

## 3. 移除旧事件树

`App.tsx` 不再渲染事件树：

- 删除 `MainScreenView`
- 删除 `EventTreeBuilder` / `EventTreeDocument`
- 删除 `ParallaxDemoScreen`
- 删除顶部 header 与“项目树 / 视差演示”按钮
- 删除 `projectTreeOpen` / `demoOpen` / 事件树 fixture

现在 App 只有：

```tsx
<ProjectTreeDemoScreen onExit={() => undefined} />
<GlobalGlitch />
```

- 启动即项目树；
- 项目树 Esc 不会回到事件树；
- 旧事件树不再出现。
