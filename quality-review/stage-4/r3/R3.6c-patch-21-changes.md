## 2. 白色矩形自然堆积

新增 `WhiteBlock` 累积队列：

```ts
interface WhiteBlock {
  id: number;
  left: number;
  top: number;
  width: number;
  height: number;
  expiresAt: number;
}
```

每次 `fire(intensity)`：

```ts
if (intensity > 0.5) {
  // intensity > 0.82: 18–35 块/次
  // intensity > 0.65: 8–17 块/次
  // intensity > 0.50: 3–7 块/次
}
```

- 每次 surge 250ms 一次；
- 最强时每次新增 18–35 块；
- 每块生命周期 900–1600ms；
- 生成频率远高于消失频率；
- 块尺寸/位置随机：
  - 宽 12–104%；
  - 高 1.4–17%；
  - 72% 概率是长条，28% 是更大块；
- 累积数组限制 300 块；
- 清理间隔 110ms；
- 不使用固定网格，白块自然重叠覆盖全屏。

### 清除

新增 `neurou:glitch-clear`：

- 3.6s 黑屏时发送；
- 退出 world/卸载时发送；
- 立即清空全部 white blocks，避免白屏残留。

## 3. 错误行红色

`ConsoleOutput` 检测：

```ts
const isError = /^\s*(error\b|\[error\]|错误|失败)/i.test(line);
```

```css
.project-console .console-output__line--error {
  color: #ff4d4d;
  text-shadow: 0 0 8px rgba(255, 50, 50, 0.22);
}
```

- `error: ...` 整行红色；
- `[ERROR]`、`错误`、`失败` 开头同样红色；
- 错误内容与 error 前缀一起变红。

## 6. 人工验收
