## 1. 放大曲线

之前：

```css
animation: console-camera-push 700ms linear 900ms both;
```

线性匀速导致启动和停止都很生硬。

现在：

```css
animation: console-camera-push 1000ms cubic-bezier(0.66, 0, 0.34, 1) 900ms both;
```

```css
@keyframes console-camera-push {
  0% { transform: scale(1); }
  100% { transform: scale(2.18); }
}
```

曲线：

- 0.0s 速度接近 0；
- 中段加速到最大；
- 结束前减速到 0；
- 不是三段式，只是一条连续的 ease-in-out；
- 0.9s 开始，1.0s 完成，1.9s 到满屏；
- 2.0s 黑屏，仍保留 0.1s 满屏停留。
