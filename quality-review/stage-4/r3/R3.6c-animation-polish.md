# R3.6c 动画流程优化说明

- 日期：2026-10-21（Asia/Shanghai）
- 范围：项目树 → ProjectConsole → 世界进入 → 世界视图，以及终端/边框/命令栏细节
- 原则：保持纯黑、等宽、低饱和、无栏目；动画服务于“终端 → 世界”的叙事，不增加 UI 栏

---

## 1. 完整动画时间线

### 1.1 项目树 → ProjectConsole

```text
0ms      ProjectTreeView 第二次点击
0–700ms  DOM 方框从节点屏幕矩形扩展到全屏
         白色 border 保留
         项目主题背景图开始淡出为黑
700ms    切换 ProjectConsole
0–700ms  ProjectConsole 白色内边框淡入
         终端内容从下方 6px 淡入
```

细节：

- DOM zoom 的黑色遮罩 `project-tree__zoom-black` 700ms 淡入，避免从项目图直接硬切黑。
- ProjectConsole 使用 `inset: 2px` 的 2px 白边，边框从低透明度淡入。
- 终端 `.project-console__scroll` 使用 `terminal-in 520ms`，轻微 translateY + opacity。

### 1.2 cmp 空闲

- 每一行输出 `terminal-line-in 180ms`，新加载行有轻微上浮淡入。
- 输入行在输出流末尾，随滚动容器移动。
- 输入光标 blink 沿用 console-caret。

### 1.3 `open w1` 世界进入（7s）

```text
0.0–2.0s  日志流
          每 70ms 追加 [ OK ] / [xx%] / [====> ]
          滚动容器跟随到底部
1.0–2.0s  easeInOutCubic 缩放 1 → 11
          transform-origin = 点击节点的屏幕坐标
2.0s      80ms 黑场遮罩淡入
2.0–5.0s  纯黑 3s
          WorldInstance.prologue 淡入 16% / 停留 / 淡出
5.0s      白色 Flash：opacity 1 → 0，200ms
5.0–7.0s  世界视图 blur(20px) brightness(2.2)
          2s 内恢复 blur(0) brightness(1)
```

关键修复：

- 增加 `@keyframes project-world-recover`（此前只有 animation 引用、没有 keyframes，世界恢复实际不生效）。
- 缩放起点使用 `ProjectTreeView.onOpenProject(projectId, origin)` 的节点屏幕坐标。
- Flash 使用独立 5000ms timer，不依赖 70ms interval，避免提前/延后。
- 黑场使用 80ms 快速遮罩，既有“关闭”感，又不明显拖慢 2.0s 节点。

### 1.4 世界视图

- 增加低饱和“世界场景”层：
  - 主题色 radial gradient；
  - 两层模糊光斑缓慢漂移；
  - 极淡网格 mask；
  - `world-scene-drift 22s` 无限交替。
- 世界标题/序言放在 `project-console__world-copy`，z-index 1。
- 世界命令栏 `/` 使用 `world-command-in 180ms` 上浮淡入。
- 输入 `exit` / `quit` 后回到 ProjectConsole，终端内容重新使用 terminal-in。

## 2. 视觉风格约束

- 纯黑 `#000`，无栏目、无按钮栏。
- 2px 白边 + 4px 圆角，作为 cmp 的唯一边框。
- 字号 20px，等宽字体。
- 颜色只使用白、灰、世界主题色低透明度。
- 不引入闪光以外的强色/粒子/噪点。
- 世界场景只做背景氛围，不抢字幕和命令文本。

## 5. 人工验收重点

1. 项目树点击项目两次：白边从节点扩展到屏幕，项目图淡出黑，cmp 白边接续。
2. cmp 输入 `open w1`：
   - 日志/进度持续滚动；
   - 从点击节点方向放大，不是屏幕中心；
   - 2s 黑屏，2–5s 字幕；
   - **5.0s 白色 Flash**，200ms；
   - 5–7s 从 blur(20px)/过曝恢复到清晰。
3. 世界视图有低饱和主题光斑/网格，不干扰序言与 `/` 命令栏。
4. 世界内 `/` 命令栏上浮淡入，`exit`/`quit` 回 cmp。
5. 终端行/输入行滚动自然，不出现 40vh 固定输入区。
6. 新建 Folder 仍按 24px 轨道游走。
