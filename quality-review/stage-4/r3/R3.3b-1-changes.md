## 6. Rust 实现摘要

> 口径说明：任务标题写“8 个 command”，但正文列出的接口为 10 个（含 `project_open_root` / `project_get_root`）。本批按正文列出的 **10 个**实现并注册。

- `ActiveProjectRoot = Mutex<Option<PathBuf>>`；`project_open_root` canonicalize 后存。
- `resolve_in_root`：
  - 拒绝 `Component::Prefix` / `RootDir`（绝对路径、盘符、UNC）；
  - `ParentDir` 回退到 root 之上 → `EscapeDetected`；
  - 对候选路径的最近存在祖先做 canonicalize，确保符号链接不逃出 root；
  - 正常子路径与 root 内的 `..` 规范化允许。
- 原子写：
  - 临时文件 `.<name>.tmp-<uuid>` → `write_all` → `sync_all` → 若目标存在复制 `.bak` → `rename` → 失败清理临时文件。
- 账本：
  - `ledger_read_lines` 删除末尾空行；
  - `ledger_append_line` 追加 `line + "\n"` 后 `sync_data`；
  - `ledger_hash_sha256` 用 SHA-256 十六进制。
- 错误码：`ProjectNotOpen` / `InvalidPath` / `EscapeDetected` / `IoError`。
- `project_read_json` / `ledger_read_head` 对缺失文件返回 `null`（适配 `ProjectStore` / `LedgerStore` 的“缺失即 null”契约）。
