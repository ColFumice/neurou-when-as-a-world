# R3.5h · 编辑器渲染收尾与 NEU 补全

## 1. 覆盖层渲染架构

NEU 的 `Resource` 信号不再只显示占位文字，而是在 Stage 上创建 DOM 覆盖层。

```ts
interface StageMediaOverlay {
  overlayId: string;
  moduleId: string;
  assetId: string;
  kind: 'video' | 'videoStatic' | 'image';
  src: string;
  startMs: number;
  durationMs: number;
  opacity: number;
}
```

- 触发时由 EditorScreen 读取模块 `params` 创建 overlay；
- Video：`kind='video'`，挂载后立即播放，暂停时暂停；
- VideoStatic：`kind='videoStatic'`，`currentTime=0` 并暂停，保持冻结帧；
- Image：`kind='image'`，DOM `<img>`；
- 资源映射：
  - `asset:video:foreground` → manifest foreground 视频；
  - `asset:guidance:head-logo` → head-logo 图片；
- 层级：`.editor-stage__media-overlay` 为 z-index 7，位于 GLSL 双视频和 Logo 之上、光效 overlay 之下；
- 生命周期：`playhead - startMs` 超过 `durationMs` 后进入 260ms 淡出，随后卸载；
- 拖动 playhead / 重新开始时清空 overlay。

## 2. 局部光效

- `ActiveLight` 增加 `mode` 与 `targetAssetId`；
- `NeuSignal.Light` 携带 `mode`；
- Stage 将 Light 分为：
  - FullScreen → 现有全屏 compositor；
  - Local → 不进入全屏 filter，而是匹配 overlay 的 `assetId`；
- 命中目标 overlay 时：
  - 对该元素应用 `filter`；
  - 用 `mask-image: radial-gradient(...)` 做边缘羽化；
  - 背景 GLSL 画面不应用该 filter；
- 目标 asset 没有对应 overlay 时，不生效。

## 3. NOT 真实取反

NeuRuntime 的 pulse 逻辑：

```text
同一个 graph tick 内：
  输入有 Pulse → NOT 阻断
  输入无 Pulse → NOT 导通
```

- 新增 `tickHasPulse`；
- NOT 不再依赖“必须有输入脉冲”才进入求值；
- NOT 的 false 分支在下游产生 pulse；
- 单测覆盖：
  - RhythmPoint 输入 true 时 Audio 不触发；
  - 另一个 root 产生 graph tick、NOT 输入 false 时 Audio 触发。

## 4. 动效专属参数

E 层 `EditorEffectParams` 新增：

```ts
bounceCount
initialHeight
glitchOffset
scrollAmount
shakeAmplitude
wanderRadius
opacity
```

`EffectCompositor` 已使用这些参数：

- Bounce：次数 + 初始高度；
- Glitch：横向偏移量；
- ScrollOpen / ScrollClose：收展百分比；
- Shake：振幅；
- Wander：半径；
- ScaleUp / ScaleDown：scale。

Inspector Effects 区现在每个 effect 显示：

- Duration；
- Bounce：Count / Height；
- Glitch：Offset；
- Scale：Scale；
- Shake：Amp；
- Wander：Radius；
- Scroll：Amount。

修改后立即写入 `file.effects` 并刷新 Stage。

- NOT 阻断 / 导通单测；
- 动效合成仍覆盖多动效叠加、结束清空；
- 编辑器 schema/round-trip 保持通过。

### 人工验收清单

- [ ] NEU 放 Image 模块，播放到触发时刻，Stage 出现 head-logo 图片；
- [ ] Image 播放时应用 Bounce / Scale 等动效，覆盖层跟随；
- [ ] 放 Local Light，`targetAssetId=asset:guidance:head-logo`，图片模糊、背景仍清晰；
- [ ] 如果目标 asset 没出现，局部光效无效果；
- [ ] 放 NOT，输入 true 时下游不响；输入 false 且有 graph tick 时下游响；
- [ ] 修改 Bounce Count/Height、Glitch Offset、Shake Amp，播放时立即反映；
- [ ] 只有 Play 时出现模块/连线高亮，暂停拖动 playhead 不触发高亮。

## 6. 边界

- Video / VideoStatic 当前使用 manifest 的 foreground 视频；尚未接入独立视频资产选择。
- Local Light 只作用于 NEU 覆盖层 asset；基础 GLSL 双视频和 Logo 的局部矩形作用域仍可继续扩展。
- Image overlay 目前固定居中显示，不读取 Stage 坐标参数。
- 动效参数 UI 为最简数值输入，未做滑块/预设面板。
