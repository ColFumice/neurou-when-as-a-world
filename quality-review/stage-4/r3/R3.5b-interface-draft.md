# R3.5b 核心接口草稿（E 层）

- 日期：2026-10-23（Asia/Shanghai）
- 状态：**已按用户确认落盘**；最终接口/结果以 `R3.5b-changes.md` 为准
- 范围：时间轴、关键帧、撤销、Logo 纯逻辑、editor.json / v2 导出
- 不做：React UI、媒体导入、AI 生成、SGBM、Rust 后端改动

---

## 0. 先确认的 5 个点

1. **`EditorTimeline.viewEndMs` 用派生值**：`viewEndMs = viewStartMs + laneWidth / pxPerMs`；只存 `viewStartMs` / `pxPerMs` / `laneWidth`，避免三份状态互相打架。
2. **拖拽换轨由 UI 传 `targetLayerIndex`**：R3.5c 负责 lane 命中测试；E 负责 3px 拖拽阈值、24px 换轨阈值、Shift 锁时间、3 层 pad/grid 规则。E 不依赖 DOM 矩形。
3. **editor.json 不存 history / dirty / selection / timeline 视口**；只存 tracks + 最小 canvas（stage 尺寸）+ chart 元数据。推荐不存 `selectedKeyframeId` / `logoPosition`（UI 瞬态），但保留 canvas 的 stage 尺寸。
4. **R3.5b 一并落 `ChartSourceData` v2 + `parseChartSourceData`**：`EditorWorldFile.exportV2()` 需要一个强类型出口；否则 v2 导出只能用 `unknown`。
5. **`ChartKeyframe` 不可变、`EditorTrack` 可变**：keyframe 的 `withTime/withLayer/withLogo` 返回新对象；track 负责 add/remove/replace/sort；`EditorWorldFile` 是唯一写入口。

## 3. `ChartKeyframe`

```ts
export class ChartKeyframe {
  readonly keyframeId: string;
  readonly timeMs: number;
  readonly durationMs: number;
  readonly chartLayerIndex: number;   // 1 基
  readonly gridCellId: number | null; // 仅第 2 层
  readonly chartKeyId: string | null;
  readonly chartPadKind: PadKind;
  readonly logo: LogoGuide | null;

  constructor(input: {
    keyframeId: string;
    timeMs: number;
    durationMs: number;
    chartLayerIndex: number;
    gridCellId?: number | null;
    chartKeyId?: string | null;
    chartPadKind: PadKind;
    logo?: LogoGuide | null;
  });

  withTime(timeMs: number): ChartKeyframe;
  withLayer(
    layerIndex: number,
    gridCellId?: number | null,
    padKind?: PadKind,
  ): ChartKeyframe;
  withLogo(logo: LogoGuide | null): ChartKeyframe;

  static compare(a: ChartKeyframe, b: ChartKeyframe): number; // time -> layer -> id
  static roleOf(
    keyframes: readonly ChartKeyframe[],
    keyframeId: string,
  ): KeyframeRole | null;
}
```

规则：

- `timeMs` 非负整数；`durationMs >= 0`；`timeMs + durationMs <= timeline.durationMs`。
- 第 1 层：`pad=TopMost`，`gridCellId=null`。
- 第 2 层：`pad=Light|Heavy`，`gridCellId=1..8`。
- 第 3+ 层：`pad=Light`，`gridCellId=null`。
- 同层同时间允许多个 keyframe（和弦）；排序 `time -> layer -> id`，不合并、不覆盖。
- **v2 导入的原始 timeMs 不强制吸附**；`withTime` 不做 snap，snap 只发生在新增/拖动/Inspector 输入。

- 只取有 `logo` 的 keyframe；没有 → `null`。
- 按同层 time 排序后，找到 `timeMs` 两侧有 logo 的 keyframe：

## 5. `EditorTimeline`

```ts
export class EditorTimeline {
  readonly laneLeft: number;
  readonly laneWidth: number;
  readonly durationMs: number;
  readonly minPxPerMs: 0.01;
  readonly maxPxPerMs: 10;

  constructor(options: {
    laneLeft: number;
    laneWidth: number;
    durationMs: number;
    viewStartMs?: number;
    pxPerMs?: number;
    playheadMs?: number;
  });

  get viewStartMs(): number;
  get viewEndMs(): number;       // viewStartMs + laneWidth / pxPerMs
  get pxPerMs(): number;
  get playheadMs(): number;
  get viewportLocked(): boolean;

  timeAtX(x: number): number;    // viewStart + (x - laneLeft) / pxPerMs
  xAtTime(timeMs: number): number;

  setViewport(input: { viewStartMs?: number; pxPerMs?: number }): void;
  zoomAt(anchorX: number, nextPxPerMs: number): void;
  scrollTo(viewStartMs: number): void;
  scrollBy(deltaMs: number): void;
  setPlayhead(timeMs: number): void;
  setDuration(durationMs: number): void;

  snap(
    timeMs: number,
    options?: { altKey?: boolean; frameDurationMs?: number | null },
  ): number;

  lockViewport(): void;          // 拖动期间禁用缩放/滚动
  unlockViewport(): void;
}
```

实现约束：

- `pxPerMs` 钳制到 `[0.01, 10]`。
- `viewStartMs` 钳制到 `[0, max(0, durationMs - laneWidth / pxPerMs)]`。
- `zoomAt` 保持 anchorX 下的 time 不变，再重新钳制 viewStart。
- `setViewport` / `zoomAt` / `scrollTo` / `scrollBy` 在 `viewportLocked` 时直接 return（不抛错，方便 UI 高频调用）。
- `snap` 优先级：
  1. `altKey` → 原值；
  2. `frameDurationMs > 0` → 最近帧边界；
  3. 10ms 网格；
  4. clamp 到 `[0, durationMs]`。
- 映射本身不 clamp（允许 UI 画视口外的点）；`snap` 负责 clamp。
- `playheadMs` 是快照；真正的播放状态在 `EditorPlayhead`。`EditorWorldFile` 在 playhead 变更时同步 `timeline.setPlayhead`。

### 9.1 ID 生成

- E 禁用 `crypto.randomUUID()`（zero-engine 禁止 `crypto`）。
- X 注入 `documentId`；E 内部：
  - `keyframeId = ${documentId}-kf-${counter}`；
  - `logoId = ${keyframeId}-logo`；
  - 加载时扫描已有最大后缀，counter 从 max+1 开始。
- 测试注入固定 `documentId`，ID 可预测。

### 9.2 拖拽

- `beginKeyframeDrag`：记录 `原 keyframe / 原 pointer / 原 time / 原 layer`；`timeline.lockViewport()`；不写历史。
- `updateKeyframeDrag`：
  - 总位移 `<= 3px` → 返回原预览 `changed=false`；
  - `shiftKey` → 时间锁原值；
  - 否则 `timeMs = timeline.snap(timeline.timeAtX(pointer.x), { altKey, frameDurationMs })`；
  - `targetLayerIndex` 存在且 `|dy| > 24` → 切换层；否则保持原层；
  - 同步 `timeline.setPlayhead(preview.timeMs)`；
  - 不写 track、不写 history。
- `commitKeyframeDrag`：
  - 无变化 → 只解锁，不写历史；
  - 有变化 → 调用一次 `moveKeyframe`（内部 push 一条 `ChartEditUndo`）；
  - 解锁；清 drag 状态。
- `cancelKeyframeDrag`：解锁、清 preview、不写历史（Esc / pointercancel / lostpointercapture / blur 由 R3.5c 调它）。
- 换轨规则：
  - 第 1 层：`pad=TopMost`，`grid=null`；
  - 第 2 层：`pad=Light`（默认），`grid=1`；
  - 第 3+ 层：`pad=Light`，`grid=null`。
- 同层同时间多 keyframe 允许；commit 后按 `time -> layer -> id` 排序。

### 9.3 撤销

- 每次 add / move / update / delete / setLogo / removeLogo 最多 push 一条 patch。
- 空操作（time/layer/logo 都没变）不 push。
- `deleteKeyframe` 的 `before.keyframe` 带 logo，undo 恢复 keyframe 时 logo 一起恢复。
- `moveKeyframe` 跨轨时 patch 的 before/after 记录各自 trackId + index。
- `undo/redo` 由 WorldFile 应用 patch；`ChartEditUndo` 只维护栈和 cursor。

### 9.4 dirty

- 任何文档变更（keyframe/logo/seed）→ `dirty=true`。
- `markSaved()` → `dirty=false`；undo/redo 后若与保存点不同仍需 dirty=true（WorldFile 维护 savedVersion/currentVersion 或 dirty 置 true）。
- `toJson()` 不写 dirty；`fromJson()` 后 dirty=false。
- history 不持久化。

## 10. `ChartEditUndo`

```ts
export class ChartEditUndo {
  constructor(limit?: number); // 默认 100

  get size(): number;
  get canUndo(): boolean;
  get canRedo(): boolean;

  push(patch: KeyframePatch): void; // 新编辑截断 redo；空 patch 不应传入
  undo(): KeyframePatch | null;     // 返回要撤销的 patch
  redo(): KeyframePatch | null;     // 返回要重做的 patch
  clear(): void;
}
```

- `KeyframePatch` 见 §2；`before/after` 是 `KeyframeLocation` 快照。
- `push` 后 `cursor = entries.length`；超过 100 丢最旧。
- `undo` 返回 `entries[cursor-1]` 并 `cursor--`；`redo` 返回 `entries[cursor]` 并 `cursor++`。
- 空操作由 WorldFile 保证不调用 `push`。
- 删除 keyframe 的 patch：`before=location(keyframe+logo)`, `after=null`；undo 重新 insert。
- 新增：`before=null`, `after=location`；undo remove。
- 移动/改属性：before/after 都非空；跨轨时 trackId 不同。

## 11. Logo 纯逻辑

```ts
export class LogoPositionPicker {
  get active(): boolean;
  begin(): void;
  cancel(): void;
  commit(
    stageX: number,
    stageY: number,
    stageRect: { x: number; y: number; width: number; height: number },
  ): { x: number; y: number } | null;
}

export class LogoRandomPlacement {
  static place(
    seed: number,
    keyframeId: string,
    bounds?: { minX?: number; maxX?: number; minY?: number; maxY?: number },
  ): { x: number; y: number };
}
```

- `LogoPositionPicker`：
  - `begin()` → active；
  - `commit()` 只在 active 时生效；归一化 `(stageX - rect.x) / rect.width`，`(stageY - rect.y) / rect.height`；clamp `0..1`；空 rect 返回 null；
  - `cancel()` 清 active。
- `LogoRandomPlacement`：
  - 默认 bounds `[0.15, 0.85]`，避免贴边；
  - 32-bit FNV-1a hash：`hash = fnv1a(`${seed}|${keyframeId}`)`；
  - `mulberry32(hash)` 生成两个 `[0,1)` 值；
  - `x = minX + r1 * (maxX-minX)`，`y = minY + r2 * (maxY-minY)`；
  - 不调用 `Math.random`，同 seed + keyframeId 两次完全一致；
  - seed 先 `>>> 0`，keyframeId 用 UTF-8 字符串字节做 FNV。
- 级联删除：`EditorWorldFile.deleteKeyframe(id)` 删除整个 keyframe（含 logo）；undo 的 before 快照含 logo，因此恢复。
- “选位”流程：R3.5c 的按钮调 `picker.begin()`；stage 点击调 `picker.commit(...)` 得到归一化位置；WorldFile `setLogo` 写入。E 不碰 DOM。

- `notes` 只由 keyframes 派生；不带 `logo`、`documentId`、`selection`、`trackId`、`keyframeId`。
- 可选字段 `gridCellId` / `chartKeyId` 只在非 null 时写。
- `layers` 由 tracks 派生：1 TopMost、2 Grid、3+ FullScreen（Pointer）；没有第 2 层时按实际 tracks。
- `exportV2` 内部用 `parseChartSourceData` 回读校验，失败抛错，不返回半成品。
