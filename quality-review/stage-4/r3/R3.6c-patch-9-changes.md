## 1. 全局故障层

新增 `GlobalGlitch`（App 内部组件，不导出）：

- 监听全窗口的：
  - `pointerdown`（项目树、cmp、视差、事件树、按钮全部覆盖）
  - `keydown`（包括 cmp 输入）
  - `wheel`
- 触发节流 72ms，避免同一次操作连续刷屏；
- 另每 11s 有 62% 概率触发一次环境故障。

### 视觉

每次触发随机选择：

- 全屏闪色：红 `#ff1744` / 青 `#00e5ff` / 白 / 品红 / 蓝 / 黑；
- 1–2 条横向撕裂亮带；
- 一块随机位置的色差区域；
- 全屏扫描线；
- 随机水平位移。

CSS：

```css
.global-glitch {
  position: fixed;
  inset: 0;
  z-index: 12000;
  pointer-events: none;
}
```

关键动画：

- `global-glitch-flash`：全屏色闪，240ms；
- `global-glitch-slice`：横向 skew/位移；
- `global-glitch-region`：随机色差块；
- `global-glitch-scan`：扫描线。

截图：`r36c-p9-glitch.png`（单击 cmp 时捕获到红/品红全屏故障）。

## 2. cmp Fisheye 与暗角增强

```css
.project-console .console-output {
  transform: perspective(760px) scale(1.012) rotateX(0.35deg);
}

.project-console.console-effect-fisheye .console-output {
  transform: perspective(480px) scale(1.032) rotateX(0.9deg);
}
```

暗角：

```css
.project-console__fx-vignette {
  background: radial-gradient(
    ellipse at center,
    transparent 30%,
    rgba(0,0,0,0.42) 68%,
    rgba(0,0,0,0.72) 100%
  );
  box-shadow:
    inset 0 0 90px 18px rgba(0,0,0,0.55),
    inset 0 0 220px 60px rgba(0,0,0,0.42);
}
```

- 默认已有轻微 perspective；
- 选择 `Fisheye` 后透视更强、边缘更暗；
- 与扫描线/点阵/RGB 分离叠加。
