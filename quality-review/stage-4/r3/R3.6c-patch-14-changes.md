# R3.6c-patch-14 变更说明

- 日期：2026-10-22（Asia/Shanghai）
- 范围：故障白条/雪花/错位增强、文本选择样式、输入行路径与尾部空白
- 状态：完成，待 Trae 测试 + 用户人工验收

## 1. 故障增强

### 纯白矩形

- 每次 burst 的第一个短矩形强制为纯白；
- 第一个长条也强制为纯白；
- 其余矩形 28% 概率纯白，最多 2 块；
- 白块 `background:#fff`、`mix-blend-mode:normal`、白色 glow；
- 动画 210–230ms 闪烁，形成局部“反黑”高光。

截图 `r36c-p13-glitch2.png` 中可见两条纯白长条。

### 雪花增强

- 数量从 1–3 提到 2–4；
- 点阵改为三层：
  - 1.4px 纯白；
  - 1px 灰白；
  - 1px 半透明白；
- `background-size` 2/4/7px；
- `contrast(2.4) brightness(1.45)`；
- opacity 0.24–0.48。

### 错位增强

- 切片位移 ±90px；
- 长条位移 ±90px；
- 新增纵向位移 ±23px / ±25px；
- skewX 最大 -14° / +11°；
- 动画改为 `translate3d(x, y, 0)`，横向 + 纵向同时错位。

## 2. 文本选择

```css
.project-console ::selection,
.project-console input::selection {
  background: #ffffff;
  color: #000000;
}
```

- 选中背景纯白，文字纯黑；
- `.project-console` 设置 `-webkit-user-drag:none`；
- 输出区 `onDragStart` 阻止默认拖拽；
- 输出区 `onMouseDown` 先清除旧选区，再让浏览器从拖动处重新选择；
- 结果：不能拖动已选文本，但拖动会重新开始选择并高亮。

## 3. 输入行

### 虚拟路径

输入行改为：

```text
NeurOS  C:\A_Try\chromato >
```

- path 在 `>` 前面；
- `>` 右边不再显示 `/project`；
- 使用 `white-space: pre` 保留 `NeurOS` 后两个空格；
- 路径取当前项目 `project.meta.projectName`。

### 下方 7 行空白

```css
.project-console__tail-space {
  height: 154px;     /* 7 × 20px × 1.1 */
  min-height: 154px;
}
```

- 位于 input 之后；
- 滚动容器可滚到该空白底部；
- 输入变化时自动滚底。
