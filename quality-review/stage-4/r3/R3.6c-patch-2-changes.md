## 2. ProjectConsole 焦点与布局

### 2.1 输入不再 unmount

- 历史输出和输入区拆成稳定结构：
  - `.project-console__history`：上半部分，可滚动；
  - `.project-console__input-area`：下半部分，固定 40vh。
- 输入控件在历史输出之外，不会因为追加输出行而重新挂载。
- `useConsoleSession`：
  - `inputRef` 改为 `HTMLInputElement | HTMLTextAreaElement`；
  - 新增 `submitInput()`；
  - 提交后 `requestAnimationFrame(() => inputRef.current?.focus())`。
- ProjectConsole 使用 `<textarea>`，`onKeyDown` 的 Enter 直接调用 `submitInput()`，Shift+Enter 换行。

### 2.2 下半屏输入区

- `.project-console__input-area { flex: 0 0 40vh; background:#080808; }`
- `> ` 在输入区顶部；
- textarea 高度填满输入区，自动换行向下延伸；
- 上半历史使用独立滚动区域，长文本不会把输入框顶走；
- 输入区宽度与历史区一致，无边框/栏目。

验证截图：`r36c-p2-console.png`。

## 4. 加载动画重做

### 4.1 缓动

`easeInOutCubic`：

```ts
const eased = progress < 0.5
  ? 4 * progress ** 3
  : 1 - ((-2 * progress + 2) ** 3) / 2;
setZoomScale(1 + eased * 10);
```

- 0–1.5s 平滑加速推进；
- 到 1.5s 跳到像素级黑屏；
- 不再使用线性/平方节奏。

### 4.2 日志滚动

每 70ms 追加多行：

```text
[ OK ] Mounting world...
[01% ] Loading shader / w1
      [=>          ] 1%
```

- 文本进度条 + 百分比 + 世界 ID；
- 1.5s 前持续滚动；
- 日志在 ProjectConsole 原有输出域中，不弹全屏组件。

### 4.3 黑屏字幕

- 1.5–2.0s：4px 白色像素点 → 全黑；
- 2.0–5.0s：纯黑 3s；
- 中央白字 `WorldInstance.prologue` 淡入/停留/淡出；
- 无顶部/底部 UI。

### 4.4 Flash + 模糊恢复

- 5.0s：全屏白色 `.project-console__flash`，0.46s 内亮起再消失；
- 同时世界视图出现：
  - `blur(20px)` / `brightness(2.2)`；
  - 2s 内过渡到清晰、正常亮度；
- 与 patch-1 不同：本补丁按要求恢复 **Flash**。

## 5. 新建 Folder 游走

`ProjectTreeLayout`：

- 删除固定 `y: 110`；
- 空 Folder 的 base 改为 `y: 0`，仅保留 x 居中和 z；
- 24px 圆轨道仍由 `phase(folderId)` 驱动；
- 周期 12s；
- 双击空白时：

```ts
setSelectedId(null);
selectedRef.current = null;
pinnedWanderRef.current = null;
```

确保新 Folder 不会被上一节点的 pinned wander 冻结。

测试：

- 空 Folder 在 1000ms / 3000ms 的 screenX/screenY 必须不同；
- `hypot(wanderX, wanderY)` 必须为 24。

## 6. 世界内命令栏

- 进入 world view 后监听键盘 `/`；
- 左下角显示半透明灰色输入栏：

```css
.project-console__world-command {
  position: fixed;
  left: 2.2rem;
  bottom: 2.2rem;
  background: rgba(80, 80, 80, 0.55);
  backdrop-filter: blur(6px);
}
```

- 输入 `exit` / `quit` → 关闭 world view，回到 ProjectConsole；
- 再按 `/` 或 `Esc` 关闭命令栏；
- 命令栏打开时自动 focus 输入框。
