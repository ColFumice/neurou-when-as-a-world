# R3.6c-patch-10 变更说明

- 日期：2026-10-21（Asia/Shanghai）
- 范围：全局多形态低饱和故障、局部雪花/反色/错位、Fisheye/暗角增强
- 状态：完成，待 Trae 测试 + 用户人工验收

---

## 1. 随机多形态故障

`GlobalGlitch` 每次 burst 不再只生成一条色带，而是同时生成：

- **2–8 个连续矩形**：2 个纵向集群，每个 2–6 个叠放矩形；
- **3–6 条竖向栅格**：横向细线密集堆叠并上下延伸；
- **1–3 块局部雪花**：径向点阵 + 对比度增强；
- **1–2 块局部反色**：`backdrop-filter: invert/grayscale`；
- **2–5 条错位切片**：水平位移 + 随机高度；
- 全屏扫描线。

所有元素位置、尺寸、透明度、位移、层级均每次随机。

## 2. 低饱和灰色

调色板改为：

```text
#8d9298  #96918d  #858c94  #9b9b9b
#7f8890  #a0a0a0  #918b92
```

- 不再使用高饱和红/青/品红；
- 保留轻微冷暖偏差；
- 不会完全黑；
- 全屏闪色透明度提升到 strength × 0.26 / 0.16，仍保持低饱和。

## 3. 密度与触发

- 操作触发节流从 72ms 降到 **58ms**；
- 环境故障从 11s 改为 **9.5s**，触发概率 68%；
- burst 生命周期 260–450ms；
- 单次故障可包含 10–20 个独立图形。

## 4. 栅格穿插

`.global-glitch__ladder`：

```css
background: repeating-linear-gradient(
  to bottom,
  var(--glitch-tone) 0 1px,
  transparent 1px 4px
);
mask-image: linear-gradient(transparent, #000 12%, #000 88%, transparent);
```

- 从上/下随机延伸；
- 覆盖在矩形与文本上；
- 形成“水平细线穿插图形”的效果。

## 5. 局部反色与雪花

局部反色：

```css
backdrop-filter: invert(0.8) grayscale(0.9) contrast(1.25);
mix-blend-mode: difference;
```

局部雪花：

```css
background-image:
  radial-gradient(circle, rgba(205,205,205,.85) 1px, transparent 1px),
  radial-gradient(circle, rgba(150,150,150,.7) 1px, transparent 1px);
background-size: 3px 3px, 5px 5px;
```

## 6. cmp Fisheye/暗角

保持并增强：

- 默认 `perspective(760px) scale(1.012)`；
- Fisheye `perspective(480px) scale(1.032)`；
- 暗角中心 30% 透明，100% 到 rgba(0,0,0,0.72)，叠加两层 inset shadow。
