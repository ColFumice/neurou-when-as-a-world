# R3.5d · 编辑器运行时与持久化

## 1. editor.json schema

`editor.json` 升到 `schemaVersion: 2`，读取兼容 v1；v1 缺省数组按空迁移。

新增顶层字段：

```json
{
  "schemaVersion": 2,
  "bindings": [
    { "keyframeId": "editor-w1-kf-3", "assetId": "asset:audio:main", "triggerAtMs": 4167 }
  ],
  "neuModules": [
    {
      "moduleId": "neu-1",
      "type": "RhythmPoint",
      "x": 0.18,
      "y": 0.30,
      "params": { "timeMs": 0 },
      "inputs": [],
      "outputs": [
        { "port": 1, "targets": [{ "moduleId": "neu-2", "port": 1 }] }
      ]
    }
  ],
  "effects": [
    {
      "interfaceId": "fx-1",
      "effectKind": "EaseIn",
      "params": { "durationMs": 600, "intensity": 1 }
    }
  ]
}
```

关键帧新增：

```json
"effectInterfaceIds": ["fx-1", "fx-2", "fx-3"]
```

- `bindings` 严格使用 `{ keyframeId, assetId, triggerAtMs }`；
- `neuModules` 使用 `{ moduleId, type, x, y, params, inputs[], outputs[] }`；
- `effects` 使用 `{ interfaceId, effectKind, params }`；
- `x/y` 0..1，端口 1..6，`triggerAtMs` 0..durationMs；
- 引用不存在的 keyframe/effect/module 时 Load/Save 校验失败；
- 有环 NEU graph 在 Compile 阶段拒绝。

验证：

```text
v4/tests/r3/editor-runtime.test.ts
✓ bindings / neuModules / effects round-trip
✓ schema v1 空迁移
✓ 非法 binding 引用
```

## 2. 音频触发时序

### 架构变化

Stage 不再用 `audio.wav` 作为连续主音轨，也不再由音频 `currentTime` 驱动 playhead。

```text
rAF transport clock
  → playhead
  → binding crossing detection
  → WebAudio AudioBufferSourceNode
  → GainNode(0.8) → DynamicsCompressor → destination
```

- `audio.wav` 从 manifest 读取，decode 成 `AudioBuffer`；
- 同一时刻多条 binding → 多个 source，各自进入 GainNode 混音；
- 总 Gain 0.8，另有 compressor，避免叠加削波；
- `stopAll()` 对每个 source `stop(0)` 并 disconnect，不留长尾。

### 状态机

```text
Paused
  └─ play(from) → resume AudioContext → stopAll → Playing

Playing
  ├─ rAF: triggerAtMs ∈ (previous, next] → play(assetId)
  ├─ pause() → stopAll → Paused
  ├─ seek(to) → stopAll → 不追帧 → Paused/Playing
  └─ end → stopAll → Paused
```

- 拖动 playhead 调用 `seek()`，立即 `stopAll()`，不追播过去事件；
- 播放开始瞬间正好等于 playhead 的 binding 会触发一次；
- Autoplay/AudioContext suspended 时显示：

```text
声音未启用：请点击 Play 或画面后再次播放 · 点击此处启用
```

点击提示会再次 `resume()`。

## 3. NEU 执行引擎

### 架构

```text
NeuGraph.ts     outputs 建边 + Kahn 拓扑排序 + 环检测
NeuRuntime.ts   纯 playhead 执行器
types.ts        editor.json v2 / module / signal 契约
```

`NeuRuntime` 不依赖 React/Tauri/DOM：

```ts
runtime.reset(playheadMs - 1);
runtime.advanceTo(playheadMs, playing, (signal) => sink(signal));
```

- 每帧在 rAF 中比较 `lastMs` 与 `currentMs`；不使用 setTimeout；
- 暂停时不调用 `advanceTo(playing=true)`，Delay 的 dueMs 是 playhead 绝对时间，因此自然冻结；
- Seek 会 `reset()`，清空已调度 Delay，不补发过去脉冲；
- 有环 graph 的 `compileError` 阻止执行。

### 语义

- `RhythmPoint`：`timeMs ∈ (last, current]` 发 pulse；
- `AND`：所有已连接输入为真；单输入 passthrough；
- `OR`：任一输入；
- `Delay`：输入 pulse 后调度 `current + delayMs`，到点再传播；
- `Random`：`moduleId + sequence + seed` 确定性哈希；
- Resource/Effect/Light：收到 pulse 后发 `NeuSignal`；
- Audio 真实播放；Video/Image 发占位信号并在 Stage 显示占位标签；Subtitle 显示文字层。

### Signal

```ts
type NeuSignal =
  | { kind: 'Audio'; assetId; volume; atMs }
  | { kind: 'Effect'; interfaceId; atMs }
  | { kind: 'Light'; presets; targetAssetId; atMs; durationMs }
  | { kind: 'Resource'; resourceType; assetId; atMs }
  | { kind: 'Subtitle'; text; atMs };
```

### UI

- 蓝图中每个模块有 input/output 圆形端口；
- 点击 output → 点击另一模块 input 建立连接；
- 连接持久化到 `inputs[]/outputs[]`，SVG 曲线按真实边绘制；
- Edit 页可编辑 Delay / Random / RhythmPoint / Audio / Effect / Light 参数；
- Light 页签支持 `Invert / FlashWhite / FlashBlack / Noise / Blur / Vivid`。

## 4. 动效 / 光效合成

### 动效

`EffectCompositor.ts` 纯函数合成：

```ts
composeStageEffects(activeEffects): {
  transform, filter, opacity, clipPath, overlays
}
```

- 10 种：`EaseIn / EaseOut / ScaleUp / ScaleDown / Glitch / ScrollOpen / ScrollClose / Bounce / Wander / Shake`；
- 同一 keyframe 可以挂多个 `effectInterfaceIds`；
- 每帧按 `playhead - keyframe.timeMs` 计算 localMs；
- 多个 effect 的 transform/filter 拼接，不是多个互相覆盖的 CSS animation；
- `localMs > durationMs` 时该 effect 不进入 active 列表，Stage 的 transform/filter 立即回空，无残留。

### 光效

`composeStageLights`：

- 全屏 filter：反色、去色、鲜活、模糊；
- 全屏 overlay：噪点、滚屏、闪白、闪黑、叠黑、叠白；
- 多个 preset 同时叠加；
- Stage 使用绝对定位 `.editor-stage__fx-layer` + `.editor-stage__fx`；
- 信号结束即从 activeLights 移除，overlay/filter 同步消失。

### 当前边界（明确）

- `Light.params.mode='Local'` 与 `targetAssetId` 已进入数据契约和 signal，但 Stage 当前先按全屏 compositor 应用；按视频/图片/字幕矩形做 `mask-image` 的局部羽化仍未完成。
- NEU `NOT` 已进入类型/拓扑/参数体系，但当前 pulse 图语义不是完整布尔电路取反；`AND/OR/Delay/Random` 已由单测覆盖。
- Video/Image 模块为占位信号 + Stage 标签，不显示真实画面；Subtitle 为文字占位层。
- 动效参数目前统一 `durationMs/intensity`，逐接口自定义参数 UI 尚未展开。
- 未做痕遮罩、键盘映射、8 网格、多选鼠标共同拖拽、长按门控（按授权推迟）。

### 人工验收清单

- [ ] 选择一个 keyframe，点击 Assets 的 `audio.wav`，再点击关键帧，Inspector `BOUND` 显示音频。
- [ ] 播放越过该 keyframe 能听到 audio.wav；拖动 playhead 再播放会重新触发。
- [ ] 同一 keyframe 绑定多条音频，播放时同时发声且不互相打断。
- [ ] 点击 Play 时若 AudioContext 被拦截，顶部出现“声音未启用”提示，点击提示可恢复。
- [ ] 保存后完全重启，bindings/neuModules/effects/effectInterfaceIds 全部恢复。

- [ ] NEU Delay：修改 delayMs，音频按延迟触发；暂停后继续，Delay 倒计时不提前。
- [ ] 给一个 keyframe 连续挂 3 个 effect，播放到该 keyframe，transform/filter 同时生效；超过 duration 后恢复。
- [ ] 挂 Light `Invert + FlashWhite`，播放时画面反色并闪烁；结束后 filter/overlay 清除。
- [ ] `schemaVersion:2` 的 editor.json 重载后保持 round-trip。
