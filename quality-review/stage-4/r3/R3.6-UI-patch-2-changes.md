## 1. 居中字幕：显示时间 ×3，并隐藏光标

### 1.1 时长

原实现：

- 黑屏开始：`3600ms`
- 闪光 / 进入世界：`5600ms`（黑屏实际约 2s）
- 世界视图稳定：`7600ms`
- CSS：`console-black-prologue 3s`

新实现：

| 常量 / CSS | 值 | 说明 |
|---|---:|---|
| `WORLD_BLACK_START_MS` | 3600 | 进度条结束、黑屏开始 |
| `WORLD_PROLOGUE_MS` | 9000 | 原 3s 的 3 倍 |
| `WORLD_FLASH_AT_MS` | 12600 | 黑屏 + 字幕结束，闪光 |
| `WORLD_IDLE_AT_MS` | 14600 | 闪光后 2s，世界视图稳定 |
| `console-black-prologue` animation | 9s | 与 `WORLD_PROLOGUE_MS` 对齐 |

- 9s 动画的 16%–84% 为完全不透明，实际“稳定显示”约 6.12s；加上淡入/淡出共 9s。
- 黑屏阶段从约 3.6s 延长到约 12.6s；世界进入总时长从约 7.6s 变为约 14.6s。
- `WORLD_FLASH_AT_MS` 和 `WORLD_IDLE_AT_MS` 都由 `WORLD_BLACK_START_MS + WORLD_PROLOGUE_MS` 派生，避免再次出现 CSS 与 JS 时间不一致。

### 1.2 字幕期间隐藏光标

- `ProjectConsole` 在 `enterPhase === 'black'` 时用 `useLayoutEffect` 给 `<body>` 加 `data-crosshair-hidden="true"`；进入 `reveal` / `idle` 时 cleanup 移除。
- `crosshair.css` 增加：

```css
body[data-crosshair-hidden='true'] .crosshair {
  opacity: 0;
}
```

- 系统光标本来已被全局 `cursor: none !important` 隐藏；字幕期间连自绘准星也隐藏，因此黑屏字幕期间完全不出现鼠标指针。
- 字幕结束、闪光进入世界后自动恢复准星；鼠标位置保持在原处，移回/移动即正常跟随。
- 使用 `useLayoutEffect` 而不是 `useEffect`，避免字幕首帧出现准星闪烁。

## 2. 准星鱼眼（中心膨胀）+ 暗角修正

### 2.1 之前为什么没有

- 旧实现只有中心 120px 径向微光；横竖线是均匀 1px 实线，只在中心有 glow。
- 线本身没有厚度变化、没有边缘衰减，所以视觉上“中心有光，但线到边缘是平的”。
- 旧线用 2× viewport（200vw/200vh）保证任意位置覆盖全屏，但无法对“视口边缘”做精确的 mask。

### 2.2 新结构

- 横线 / 竖线改为固定 `100vw` / `100vh`，通过 `transform` 平移到指针位置：
  - 横线：`translate3d(0, var(--crosshair-y), 0)`
  - 竖线：`translate3d(var(--crosshair-x), 0, 0)`
- 线体增加 **边缘暗角 mask**：
  - 横线：`linear-gradient(90deg, rgba(0,0,0,.16), #000 7%, #000 93%, rgba(0,0,0,.16))`
  - 竖线：`linear-gradient(180deg, ...)`
  - 线到屏幕边缘仍可辨认，但亮度衰减，形成暗角。
- 中心新增 **156px 鱼眼镜片**：
  - 圆形细边 + 轻微径向填充 + 内外阴影；
  - 不做 `backdrop-filter`，避免每帧模糊下方 UI / 掉帧；
  - 镜片内叠 **132px × 2px** 的横/竖“膨胀段”，比主线粗 1px，形成中心膨胀。
- 保留 120px 径向 glow、10×10 中心白十字、点击 `scale(0.9)` 反馈。
- 位置更新仍由 rAF 完成：`pointermove` 只写 `--crosshair-x` / `--crosshair-y` 两个 CSS 变量，不触发 React render。
- 线体 `will-change: transform`，中心 `will-change: transform`；隐藏时只改 opacity。

> 径向鱼眼的数学特性：过中心的正交直线在径向畸变下仍然近似直线，变化主要体现在**中心放大/变粗**与**边缘压缩/变暗**。因此本轮用“中心 2px 膨胀段 + 边缘 mask + 镜片轮廓”表达鱼眼，而不是用 SVG 位移滤镜把线弯成曲线。

## 6. 已知边界

1. **时长口径**：本轮按“CSS 3s × 3 = 9s 总时长”实现；稳定不透明约 6.12s。如果你要的是“稳定显示 3×（约 6s）+ 淡入淡出不计”，当前也接近；若要更长/更短，只改 `WORLD_PROLOGUE_MS` 与 `console-black-prologue` 两个值，测试会同时校验。
2. **鱼眼是风格化实现**：中心 2px 膨胀 + 156px 镜片 + 边缘 mask，不是 SVG `feDisplacementMap` 的真实光学畸变。优点是 60fps、不模糊 UI；若必须真实弯曲，需要另做 SVG 滤镜并接受性能/兼容性成本。
3. **镜片轮廓**：在亮背景（视差）上仍能看到 156px 圆环；已把填充/阴影压到很低，若觉得仍重，可继续降 `crosshair__lens` 的 border/box-shadow。
4. **字幕期间完全无光标**：这是按“隐藏光标”要求做的；如果希望保留一个极淡的中心点，可把 `opacity: 0` 改为 `0.15`。
5. **Parallax 路由**：`ParallaxDemoScreen` 当前未挂 App 路由；视差截图用临时 dev mount，未改路由。
6. **隐藏逻辑**：`data-crosshair-hidden` 只由 `ProjectConsole` 的黑屏阶段控制；未来其他全屏字幕应复用同一属性，避免各自实现。
