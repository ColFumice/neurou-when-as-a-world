## 1. 退出世界后无法继续输入

### 根因

世界进入由 `loadingWorld` 驱动 7s 时间线：

- 5.0s 已 reveal world；
- `loadingWorld` 要到 7.0s 才清空；
- 玩家 5–7s 内 `exit` 时旧代码只清 `activeWorld`；
- 7.0s interval 仍会 `setActiveWorld(loadingWorld)`，把玩家重新拉回 world；
- 返回 cmp 后输入框没有重新 focus。

### 修复

world command `exit` / `quit`：

```ts
setActiveWorld(null);
setLoadingWorld(null);   // 中止 7s 时间线
setEnterPhase('idle');
setWorldCommandOpen(false);
setWorldCommand('');
setZoomScale(1);
setFlash(false);
requestAnimationFrame(() => inputRef.current?.focus());
```

`loadingWorld=null` 触发 effect cleanup，清除 interval / flash timer / 5s reveal timer。

另加：

```ts
useEffect(() => {
  if (activeWorld || enterPhase !== 'idle') return;
  requestAnimationFrame(() => inputRef.current?.focus());
}, [activeWorld, enterPhase]);
```

## 2. 进入世界前的缩放

### 新参数

- 缩放起点：**0.7s**
- 结束：**1.5s**
- 最大 scale：**2.25**（不再 11×）
- 0.7–1.5s 使用 `easeInOutCubic`
- 1.5–2.0s 保持满屏，持续剧烈震颤
- 2.0s 黑屏

```text
0.0–0.7s  scale 1；日志滚动
0.7–1.5s  scale 1 → 2.25
1.5–2.0s  scale 2.25，满屏震颤
2.0s      黑屏
```

### 震颤

独立 20ms shake timer：

```ts
const amplitude = 24 + ramp * 28; // 24–52px
x = sin(t*0.115)*amp + sin(t*0.041)*4
y = cos(t*0.093)*amp*0.72 + cos(t*0.033)*3
```

- `.project-console` 使用 `translate3d(shakeX, shakeY, 0) scale(zoomScale)`；
- 2.0s 黑屏时 shake 归零。

### 保留轨迹

- 保留 0.7–2.0s 内每一次 20ms shake 位置（约 65 帧），直到黑屏；
- 通过 inline `textShadow` 直接把每一帧位移写入终端；
- 透明度随缩放强度提升，叠层保留全部轨迹；
- 同时保留上下虚影，形成“每一次位移都留痕”的残像。

## 3. 行距与 cmp 像素感

### 行距

```css
.project-console {
  font: 400 20px/1.1 "Cascadia Mono", "Consolas", monospace;
}
.project-console__scroll .console-output__line {
  min-height: 1.1em;
}
```

行距从 1.4 收紧到 **1.1**。

### 像素/终端纹理增强

- 扫描线 opacity 0.09；缩放时 0.24。
- 点阵 grid 改为 2px，opacity 0.04；缩放时 0.13。
- 文本基色加入轻微 RGB 分离：

```css
text-shadow:
  0.55px 0 rgba(255,70,120,0.14),
  -0.55px 0 rgba(60,220,255,0.12);
```

- `filter: contrast(1.03)`。
- Fisheye：默认 `perspective(900px) scale(1.004)`；选择 Fisheye 后 `perspective(700px) scale(1.016)` + 更深暗角。
- 故障亮带保持 7.5s 周期偶发。
