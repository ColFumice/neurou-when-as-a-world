## 1. 恢复原来的故障效果

已删除 patch-31 添加的镜面锯齿覆盖层：

- `.global-glitch::before`
- `.global-glitch::after`
- `global-fracture` 动画

原故障的矩形、栅格、雪花、反色、切片、白块生成逻辑保持不变。

---

## 2. 真正的错位（不是画几条线）

新增 **SVG 位移图滤镜**，直接移动整个 UI 的像素：

1. 每次故障生成 256×256 位移图；
2. 画面切成 22 条横向断层；
3. 每条断层随机横向偏移 ±95px；
4. 通过 `feDisplacementMap` 作用到 `.app-tear-surface`：

```tsx
<feDisplacementMap
  in="SourceGraphic"
  in2="tear-map"
  scale="190"
  xChannelSelector="R"
  yChannelSelector="G"
/>
```

```css
body.glitch-tearing .app-tear-surface {
  filter: url(#global-tear);
}
```

- 被移动的是**实际渲染的整个界面**；
- 不同横带位移不同，形成镜面破裂/断层式错位；
- 每次故障持续 180–280ms；
- 位移图每帧随机，不重复；
- 故障结束后移除滤镜，恢复原画面。

不是覆盖一条色带，而是像素级真实错位。
