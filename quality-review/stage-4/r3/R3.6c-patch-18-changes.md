## 2. 加载期故障由少到多

加载期间新增 `neurou:glitch-surge` 事件：

```ts
emitGlitchSurge(0.18 + ramp * 0.82);
```

- 从 0.35s 开始，每 250ms 一次；
- ramp = elapsed / 3400；
- 初始强度 0.18（只有少量细线/单矩形）；
- 接近 3.4s 时强度接近 1.0（当前最大密度）；
- 3.4s 后停止，3.6s 黑屏。

`GlobalGlitch` 新增：

```ts
const onSurge = (event: unknown) => {
  const value = (event as CustomEvent<number>).detail;
  if (typeof value === 'number') fire(value);
};
```

`fire(forcedIntensity)` 会跳过随机强度，直接使用 ramp 值，从而保证：

- 加载开始：故障少、弱；
- 加载中段：逐渐增多；
- 加载末尾：连续接近最强故障。
