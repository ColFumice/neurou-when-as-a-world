## 2. UI 布局与 CSS 实现

### 2.1 全屏骨架

```text
┌────────────────────────────────────────────────────┐
│ EditorToolbar 54px  (glass)                        │
├───────────────────────────────────────┬────────────┤
│ EditorStage (flex 1, pure black)       │ Inspector  │
│                                       │ (absolute) │
├───────────────────────────────────────┴────────────┤
│ EditorTimeline 252px (glass)                       │
└────────────────────────────────────────────────────┘
MediaPanel: absolute left 88px / trigger
```

- `.editor-screen` 固定 `inset: 0`，无外框、无页面滚动；
- `.editor-workspace` flex，Stage 占据剩余高度；
- Timeline 固定 252px；
- Inspector `position:absolute; right; top; bottom:276px`，不挤压 Stage；
- Media trigger 在 Stage 左上角（避开 54px toolbar）。

### 2.2 液态玻璃 tokens

```css
--editor-glass: rgba(10, 10, 12, 0.72);
--editor-glass-strong: rgba(10, 10, 12, 0.86);
--editor-border: rgba(255, 255, 255, 0.15);
--editor-text: rgba(255, 255, 255, 0.9);
--editor-muted: rgba(255, 255, 255, 0.5);
```

- Toolbar / Timeline / Inspector / Media 均使用：
  `backdrop-filter: blur(20–24px) saturate(180%)`；
- 1px 极细边框 + 内侧 `box-shadow` 高光；
- 面板进入使用 `cubic-bezier(0.4, 0, 0.2, 1)`；
- Inspector `inspector-in` 从右侧 26px 滑入；
- Media `media-in` 从上方 12px 滑入；
- 按钮 hover / active 带 border/背景/scale 过渡；
- 全局 `Crosshair` 保留，编辑器内不显示系统光标（输入框仍可输入）。

### 2.3 时间轴视觉

- Ruler 10 等分刻度；
- Playhead 顶部圆点 + 贯穿线；
- Layer 1 / 2 / 3+ 三行玻璃轨道；
- 关键帧用旋转 45° 的小方块（菱形）表示，按层着色；
- 选中关键帧白色发光；

## 3. 播放循环与 Tauri 媒体同步

### 3.1 双视频 Stage

- `EditorStage` 复用 Stereo3DDemoScreen 的 R3.5a 双视频 + GLSL 分层思路；
- GLSL：
  - `bgUv = vUv + uCamera * 0.035`
  - `fgUv = vUv + uCamera * 0.120`
  - 前景黑底按 `max(r,g,b)` 透明，产生物理遮挡；
- 相机来自当前选中关键帧的 `parallaxFactor`：
  ```text
  camera = clamp(factor * (0.10 + sin(playhead/1000 * 1.35) * 0.18), -1, 1)
  ```
  - 保留非零基准，Inspector 调 factor 时即使 playhead=0 也立即可见；
  - 拖动时间轴 / 播放时 `camera` 连续变化。

### 3.2 键盘移动

- **WASD**：Stage 相机移动
  - `A/D` 水平，`W/S` 垂直；
  - `Shift` 加速；
  - 带线性加减速惯性（速度渐变，不瞬移）；
  - GLSL 同步增加 `uCameraY`，背景/前景垂直偏移量不同。
- **方向键**：Timeline 移动
  - `←/→`：playhead 前进/后退 1 帧（`1000/24ms`）；`Shift` 为 10 帧；
  - `↑/↓`：playhead 前进/后退 100ms；`Shift` 为 1000ms；
  - playhead 接近时间轴可视边缘时自动 `scrollTo`，时间轴跟随。
- 输入框/select 聚焦时键盘移动自动禁用，不抢文本输入。
- Timeline 顶栏提示：`←→ FRAME · ↑↓ SEEK`。

### 3.2.1 时间轴拖拽

- 拖拽只取鼠标 **X** 计算时间；`targetLayerIndex: null`，纵向移动不会换层/打断；
- 按下后 `setPointerCapture`，监听 window `pointerup`，直到松开左键才 commit；
- 拖拽期间 `document.body.userSelect=none` + `cursor=ew-resize`；
- 编辑器全局 `user-select:none`，输入框/textarea 例外；
- 换层改由 Inspector 的 Layer 下拉完成，避免拖拽误触。

### 3.3 播放时钟

- 有媒体时以 `audio.currentTime` 为母钟；每 48ms 回调 `onTime`；
- `onTime` 写入：
  - `EditorPlayhead.seek`
  - `EditorTimeline.setPlayhead`
  - React `playheadMs`
- 视频不逐帧 seek：播放时自然播放，暂停/拖动时按 `playheadMs` 对齐 `currentTime`；
- 无媒体时 EditorScreen 用 `performance.now()` 兜底时钟；
- 播到 duration 自动 pause。

### 3.4 Logo 插值

- `ChartKeyframeAnimation.sample(keyframes, playheadMs)` 驱动位置/大小/stretch；
- 选中关键帧且暂停时，固定显示该关键帧 Logo，便于 Inspector 调参；
- 播放时使用采样值，切换时由 CSS 动效类呈现；
- 支持 Inspector 显示/隐藏、X/Y、Size、Stretch、Appear/Disappear/Easing。

### 3.5 保存 / 读取

```text
project root: v4/.stereo-demo/project
editor path:  charts/chart-<worldId>.editor.json
```

- `EditorWorldFile` 负责 editor.json 形状；
- `TauriProjectIo.readProjectFile / writeProjectFile` 走 `project_read_json` / `project_write_json_atomic`；
- 保存后 `markSaved()`，Save 状态 `SAVED`；
- 重进时 `fromJson` 恢复 tracks / logo / parallaxFactor；
- 媒体通过 `media/manifest.json` 自动恢复最后一对：
  - `media_read_file` 读字节 → `blob:`；
  - `audio.wav` 走 asset protocol；
  - MediaPanel 仍可重新导入/覆盖。

### 3.6 媒体导入

- 新增 `tauri-plugin-dialog` + `dialog:allow-open`；
- MediaPanel 点“选择”调 native dialog；
- 选择 left/right 后：
  - `project_open_root`
  - `media_import_stereo`
  - `media_read_file` × 2 → blob
  - `audio` asset URL
  - 进度 8 → 24 → 52 → 76 → 92 → 100
- 导入完成 550ms 后抽屉自动收起。

## 4. E/X 层改动

### 4.1 E 层 `parallaxFactor`

R3.5b 的 `ChartKeyframe` 实际没有 `parallaxFactor` 字段；R3.5c Inspector 必须持久化该值，因此做了**最小补齐**：

- `KeyframeInput.parallaxFactor?: number`，默认 `1`；
- 范围 `-5..+5`；
- `withTime / withLayer / withLogo` 保留；
- `withParallaxFactor` 便捷方法；
- `editor.json` 写入/读取（可选字段，旧文件默认 1）；
- **v2 `exportChartSource` 不写 parallaxFactor**，不影响判定数据；
- `EditorInspector.parallaxFactor` 暴露。

> 这是 R3.5c 唯一触碰 E 层的地方；不是新判定规则，只是把 Inspector 需要的预览字段补到编辑文档。

### 4.2 新增 Tauri 能力

- `media_read_file`：只允许 `media/` 相对路径，上限 256 MiB；用于 blob 视频纹理；
- `tauri-plugin-dialog`：native 文件选择；
- `dialog:allow-open` capability；
- `media_read_file` 已在 `lib.rs` / `build.rs` / capabilities / generated schemas 注册。

### 4.3 X 适配器

- `TauriProjectIo.readProjectFile / writeProjectFile`；
- `TauriMediaImporter.readMediaFile`；
- `TauriProjectIo.openProjectRoot` 复用。

## 7. 已知边界

1. Logo 是内联 SVG/CSS 的“雨”字占位，不是真实 Live2D/Spine 绑定。
2. `parallaxFactor` 是 R3.5c 对 E 的最小补齐；v2 判定数据不变。
3. 媒体自动恢复选择 manifest 中最后一对；暂无双目 pair 选择器。
4. `assetProtocol.scope=["**"]` 仍是 Demo 范围；R3.5c 后应收窄。
5. 播放同步以音频时钟为准；无音频时用 `performance.now()` 兜底。
6. Inspector 的 Appear/Disappear 动效目前以 CSS 近似呈现，未做逐帧合成。
7. `media_read_file` 是 Demo/编辑器读取通道，不是通用文件 API。
8. 时间轴拖拽只取 X 后，换轨入口改为 Inspector 的 Layer 下拉；E 层 24px 换轨逻辑仍保留给后续专用手势。
9. 编辑器全局禁用文本选择，输入框/textarea 例外；避免拖拽时选中文字。
