# R3.6c-patch-28 变更说明

- 日期：2026-10-22（Asia/Shanghai）
- 范围：cmp 输入行与最后一行日志的垂直重叠

## 1. 原因

输入行已经并入日志流，但 `line-height: 1.1` 非常紧，20px 字体的 ascender/descender 会超过 11px 行盒。

输入行紧接最后一行日志时，字形视觉上互相压住，看起来像输入栏覆盖了 `exit` 行。

另外 Fisheye filter 的视觉溢出会进一步加重覆盖。

## 2. 修复

### 输入行上边距

```css
.project-console__input {
  padding: 0.9em 0 0;
  margin: 0;
  min-height: 1.1em;
  line-height: 1.1;
  background: transparent;
}
```

- 输入行仍属于日志流；
- 不是独立黑条/终端栏；
- 增加 0.9em 顶部空隙，避免字形互相压住；
- 视觉上仍然紧接最后一行。

### Fisheye 严格裁切

```css
.project-console__fisheye {
  overflow: hidden;
  clip-path: inset(0);
  contain: paint;
}
```

- 防止 filter/transform 的输出绘制到输入行区域；
- 与输入行 padding 双重保护。

### 空行

输入下方仍是 7 个真正的空日志行：

```tsx
<div className="project-console__tail-line" />
```

- 行高 1.1em；
- 背景透明；
- 与日志同种类。
