## 1. 输入行不再是独立终端栏

之前：

- `.project-console__input` 黑底；
- `position: relative; z-index: 5`；
- padding/margin 独立；
- 下方空白是 154px 的块。

现在：

```css
.project-console__input {
  position: static;
  z-index: auto;
  background: transparent;
  padding: 0;
  margin: 0;
  min-height: 1.1em;
  line-height: 1.1;
  font: inherit;
}
```

下方 7 行改为真正空行：

```tsx
<div className="project-console__tail-lines">
  {Array.from({ length: 7 }, ...)}
</div>
```

```css
.project-console__tail-line {
  height: 1.1em;
  min-height: 1.1em;
}
```

- 输入行与上方日志同字体、同行高、同背景；
- 不再有独立黑条；
- 7 行空白是日志流的一部分；
- Fisheye 输出仍 `overflow:hidden`，不会压到输入行。

## 2. 加载日志强烈震颤

振幅从 ±17px 提升到 **最大 52px**，频率 90ms → **70ms**：

```css
animation: console-log-shake 70ms steps(2, end) infinite;
```

```css
@keyframes console-log-shake {
  0% { transform: translate3d(-38px, 16px, 0) rotate(-0.7deg); }
  20% { transform: translate3d(46px, -24px, 0) rotate(0.9deg); }
  40% { transform: translate3d(-34px, -15px, 0) rotate(-0.6deg); }
  60% { transform: translate3d(28px, 26px, 0) rotate(1deg); }
  80% { transform: translate3d(-52px, -12px, 0) rotate(-0.9deg); }
  100% { transform: translate3d(22px, 14px, 0) rotate(0.5deg); }
}
```

- 只抖日志，不抖镜头；
- 镜头仍保持缓入缓出；
- 0.8–3.6s 持续。

## 3. 少量日志上色

ProjectConsole 注入：

```css
--console-accent: rgb(project.theme)
```

`ConsoleOutput` 选择少量行：

- 每 5 个 `[ OK ]` 取 1 个；
- 每 7 个 `[xx%]` 取 1 个；
- 每 9 个 `asset=` 取 1 个。

```css
.project-console .console-output__line--accent {
  color: color-mix(in srgb, var(--console-accent) 58%, #e8f4ff);
  text-shadow: 0 0 6px color-mix(...);
}
```

- 少量日志带项目主题色；
- 字体、字号、行高不变；
- 错误行仍优先红色。
