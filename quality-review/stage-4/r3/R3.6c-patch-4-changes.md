## 1. 退出世界后无法继续输入

### 根因

世界进入使用 `loadingWorld` 驱动的 7s 时间线：

- 5.0s 已经切到 world view；
- `loadingWorld` 要到 7.0s 才清空；
- 玩家在 5–7s 内输入 `exit`/`quit` 时，旧代码只清 `activeWorld`，没有清 `loadingWorld`；
- 7.0s 的 interval 仍执行 `setActiveWorld(loadingWorld)`，把玩家重新拉回世界；
- 即使不重新拉回，输入框也没有在返回时获得焦点。

### 修复

world command 的 exit/quit 分支：

```ts
setActiveWorld(null);
setLoadingWorld(null);   // 关键：中止 7s 时间线
setEnterPhase('idle');
setWorldCommandOpen(false);
setWorldCommand('');
setZoomScale(1);
setFlash(false);
requestAnimationFrame(() => inputRef.current?.focus());
```

`loadingWorld=null` 会触发时间线 effect cleanup，清除 interval / flash timer / 5s reveal timer，不再重复进入世界。

另外增加：

```ts
useEffect(() => {
  if (activeWorld || enterPhase !== 'idle') return;
  requestAnimationFrame(() => inputRef.current?.focus());
}, [activeWorld, enterPhase]);
```

返回 cmp 后输入行立即恢复焦点。

时间线也改为 **5.0s 由独立 timer 同时 reveal + flash**，不再依赖 70ms interval，避免世界切换时抖动。

## 2. 放大阶段文字上下虚影

进入世界时的 1.0–2.0s：

- `.project-console` 仍整体 `scale(1 → 11)`；
- `transform-origin` 仍是点击节点的屏幕坐标；
- 新增 `.is-zooming`：
  - 终端文本增加多层上下 `text-shadow`；
  - 随 DOM scale 放大，虚影拉开并覆盖屏幕；
  - 2.0s 时黑场遮罩接管。

效果：

```css
.project-console.is-zooming .project-console__scroll {
  text-shadow:
    0 -0.24em rgba(255,255,255,0.22),
    0  0.24em rgba(255,255,255,0.18),
    0 -0.48em rgba(255,255,255,0.10),
    0  0.48em rgba(255,255,255,0.08);
}
```

同时缩放期间提高 scanline / pixel overlay 不透明度，产生“终端被拉近到屏幕外”的感觉。

## 3. cmp 行距与视觉纹理

### 3.1 行距

```css
.project-console {
  font: 400 20px/1.4 "Cascadia Mono", "Consolas", monospace;
}

.project-console__scroll .console-output__line {
  min-height: 1.4em;
}
```

行距从 1.65 收紧到 1.4，屏幕可容纳更多历史行。

### 3.2 Fisheye

- `.console-output` 默认：

```css
transform: perspective(900px) scale(1.004);
```

- 当 `ConsoleEffect.Fisheye` 选中：

```css
transform: perspective(700px) scale(1.016);
```

- 同时加深边缘 vignette。

### 3.3 Glitch

新增 `.project-console__fx::before`：

- 两条极淡水平/垂直错位亮带；
- `mix-blend-mode: screen`；
- 7.5s 周期，仅在 93–96% 瞬间位移；
- 不影响文本选择/输入。

### 3.4 Pixel / Scanline

新增固定覆盖层：

```text
.project-console__fx
  ├─ fx-scan     重复 1px 扫描线，9s 纵向滚动
  ├─ fx-pixel    3px 点阵，opacity 0.018
  └─ fx-vignette 四角暗角
```

- 普通状态极淡；
- `is-zooming` 时 scanline / pixel opacity 提升；
- 2.0s 黑屏时覆盖层在黑色之下，不干扰字幕。
