## 1. 全屏放大改用纯 DOM/CSS

### 旧问题

- 放大层是 Pixi `zoomSprite` + `zoomFrame`，stage 上的 Fisheye filter 会无差别扭曲白色边框，导致弧线。
- Pixi zoom 还持有纹理，增加 destroy 时的 shader/texture 生命周期风险。
- 底部 `selected · click again to zoom` DOM 提示仍露在全屏画面之上。

### 新实现

- 选中 Project 再次点击时，读取方框**当前屏幕坐标**：

```ts
const rect = canvas.getBoundingClientRect();
const scaleX = rect.width / 960;
const scaleY = rect.height / 540;
from = {
  left: rect.left + (view.container.x - width / 2) * scaleX,
  top: rect.top + (view.container.y - height / 2) * scaleY,
  width: width * scaleX,
  height: height * scaleY,
};
```

- `zoomState` 为 React 状态，渲染一个 **`position: fixed` DOM 层**：
  - `z-index: 2000`；
  - `border: 3px solid #ffffff`；
  - `background-image` 使用 `ThemeBackground` 生成的 1920×1080 Canvas → WebP data URL；
  - 初始 `left/top/width/height` 等于方框屏幕矩形；
  - 下一帧 `expanded=true` → `left/top=0`, `width=100vw`, `height=100vh`；
  - CSS transition 700ms `cubic-bezier(0.4,0,0.2,1)`；
  - 白边是 DOM border，不受 Fisheye 影响，且随矩形同步放大；
  - 点击 overlay 退出 zoom。
- `zoomState` 期间：
  - `VignetteEffect` 不渲染；
  - 顶部 header、底部 hint 透明度降到 0.08；
  - selected 提示不渲染；
  - fixed overlay 覆盖整个窗口。
- 不再创建 Pixi zoomSprite/zoomFrame，也不再持有 zoom 纹理。

## 2. Pixi 销毁逻辑

报错在 cleanup 的 `app.destroy` 内部。修改为：

1. `app.ticker.remove(update)`；
2. `detachFilters(app.stage)` 递归把 stage 及所有子 Container 的 `filters = null`；
3. `app.stage.removeChildren()`；
4. `app.destroy(false, { children: true, texture: false, textureSource: false })`；
5. **不调用** `textureCache.clear()` / `imageCache.clear()`；
6. 不显式调用任何 `texture.destroy()`；
7. cache 都是 effect 局部变量，离开作用域交给 GC。

`removeView = false` 保持 React 托管 canvas，避免 workspace 更新重挂载时黑屏。
