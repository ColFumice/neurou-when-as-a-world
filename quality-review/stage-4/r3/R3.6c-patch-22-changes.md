## 1. 强度分布

之前非加载期的强度：

```ts
0.12 + Math.random() * 0.88
```

均匀分布，强故障概率过高。

现在：

```ts
const intensity = forcedIntensity === undefined
  ? 0.04 + Math.pow(Math.random(), 2.4) * 0.64
  : Math.min(1, Math.max(0.05, forcedIntensity));
```

- 普通操作/环境故障：0.04–0.68；
- 指数 2.4 将概率向低强度压缩；
- 约 50% 故障 intensity ≤ 0.16；
- 约 90% 故障 intensity ≤ 0.54；
- 最大 0.68，不会进入 `.global-glitch--max`（阈值 0.78）；
- 最强故障概率在非加载期为 **0%**。

## 2. 加载过程不变

`neurou:glitch-surge` 传入 `forcedIntensity`：

- 0.18 → 1.0 渐增；
- 末尾仍可进入 max 档；
- 白色矩形自然堆积直至黑屏。

因此最强故障只出现在进入世界过程中。
