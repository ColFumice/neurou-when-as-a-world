# R3.5e · 拖拽 / 连线 / 控件风格修正

## 1. 拖拽改为指针事件

HTML5 DnD 在 Tauri WebView2 中不可靠，已改为统一指针拖拽：

- 资产：pointerdown 记录起点，移动超过 4px 进入拖拽，release 时按 `elementFromPoint + 元素矩形` 找落点；
- 落点：
  - `data-keyframe-id` → 绑定资产并选中该关键帧；
  - `data-drop-blueprint` → 按资产类型创建 NEU 模块；
  - `data-track-layer` → 按轨道时间创建/绑定；
  - 最近关键帧 70px 内兜底；
- 模块库：同样的 pointer 拖拽，落到蓝图创建模块；
- 蓝图内模块移动：改为 window `pointermove/pointerup`，不再依赖模块自身的 pointer capture；
- 指针捕获失败时不再卡死；
- 右键 `contextmenu` 全局阻止，不出现原生菜单。

## 2. 模块不重合

`moveNeuModule` 在移动模块时检测其它模块：

- 横向距离 < 0.15 或纵向 < 0.14 → 沿远离方向推开 0.02/0.018；
- 其它模块的 `left/top` 使用 200ms cubic-bezier 过渡；
- 正在拖拽的模块加 `.is-dragging`，关闭自身过渡，避免跟手迟滞。

## 3. 连线

- 端口点击区域扩大到 13px；
- 点击 output → 蓝图顶部出现“已选输出端口”提示；
- 再点击目标模块整卡或 input 端口即可建线；
- 右侧 Edit 页新增 CONNECT 区：
  - source / target 选择；
  - “建立连线”按钮；
  - 作为端口操作失败时的可靠兜底；
- 连线仍写入 `outputs[].targets[]` / `inputs[]`，SVG 曲线按真实边绘制。

## 4. 控件风格

新增 `EditorSelect` 深色玻璃下拉，替换原生 `<select>`：

- Inspector：Layer、Grid、BIND、Effects、Logo Appear/Disappear/Easing；
- NEU Edit：Effect interface、CONNECT source/target；
- 菜单为暗色 `rgba(10,17,25,.96)` + 毛玻璃 + 细边框；
- 不再出现 WebView2 浅色系统下拉。

## 5. Tab 切换

编辑器全局 keydown：

```text
Tab → ROU ⇄ NEU
```

输入框 / textarea / select / contenteditable 内不拦截；切换仍走 1s 转场。
