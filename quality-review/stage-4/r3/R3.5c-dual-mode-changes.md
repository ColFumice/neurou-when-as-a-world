- 状态：**双模式编辑器第一版已落盘；NEU 事件执行/R3.5c 全部高级玩法仍待后续迭代**

## 1. 本轮修复

### 1.1 滑块数值框 spinner 被裁剪

- 取消原生 number spinner 的溢出；
- `ParallaxFactor` 数字框改为**自定义上下步进按钮**：
  - 边框内 ▲ / ▼；
  - 步长 0.05，范围 -5..5；
  - 不再被输入框边框裁掉。

### 1.2 0 时刻节奏点被左栏遮挡

- `.editor-timeline__tracks` 从 `overflow:hidden` 改为 `visible`；
- 0 时刻关键帧左半边、Logo hint 均可在 LAYER 标签左侧完整显示；
- 关键帧 z-index 提高。

### 1.3 文本选择打断时间轴拖拽

- 编辑器全局 `user-select:none`，仅 `input/textarea` 可选中；
- 时间轴 `touch-action:none`；
- 关键帧按下后 `setPointerCapture`；
- 拖拽期间锁定 `body.userSelect/cursor`；
- 时间轴拖拽**只取 X**：`targetLayerIndex:null`；
- 指针纵向漂移不再换层，直到 `pointerup` 才 commit。

## 3. ROU / NEU 双模式

### 3.1 上栏切换

- 顶栏新增 `ROU` / `NEU` 开关；
- 两种模式共用同一条 Timeline；
- 当前模式只影响中央预览/蓝图与右栏，不影响 editor.json 轨道数据。

### 3.2 左侧 Assets 栏

ROU/NEU 共用：

- `head-logo`（图片）
- `audio.wav`（音频）
- `事件接口`
- `痕 / Trace`（NEU 下显示 `逻辑 / AND`）
- `字幕`

支持 HTML5 drag：

- 拖到 ROU 时间轴关键帧 → 记录绑定，Inspector 显示 `BOUND`；
- 拖到 NEU 蓝图 → 生成对应资源/逻辑模块。

### 3.3 ROU

- 中央仍是双视频 GLSL Stage；
- Logo / 关键帧 / 时间轴共用；
- 新增 Logo hint 小图标；
- 选中关键帧后：
  - `←/→` 移动 ±1000ms（Shift ±5000ms）；
  - `↑/↓` 跃层（1..3）；
  - 无选中时方向键才移动 playhead。

### 3.4 NEU 第一版蓝图

- 中央 `EventBlueprint`：
  - 左侧输入接口序号 1..6；
  - 右侧输出接口序号 1..6；
  - 可拖动模块卡片；
  - 顺序贝塞尔曲线；
  - 空状态提示。
- 右栏 `EditorNeuPanel`：
  - 书签 `Edit / Modules / Effects`；
  - Modules：逻辑、资源、动效/光效模块库；点击或拖入蓝图；
  - Edit：模块 X/Y、模块列表；
  - Effects：10 个动效接口选项。

> NEU 目前是**可交互蓝图骨架**：模块参数、执行语义、事件运行时、动效/光效真实效果尚未接入。

## 4. 时间轴增强

### 4.1 多选

- `Ctrl/Cmd + 点击` 关键帧切换多选；
- 轨道空白处拖拽框选：
  - 白色边框 + 半透明白色填充；
  - 按时间范围 + 轨道行范围选择；
- 选中集合用 React UI 状态维护，Inspector 显示主选中项。

### 4.2 帧动画

- 关键帧 `durationMs` 直接渲染为时间轴长条；
- Inspector 新增 `帧动画 → 下一节奏点`：
  - 有下一关键帧：时长 = 下一节奏点时间 − 当前；
  - 无下一关键帧：默认 1000ms，且 clamp 到 timeline 末尾；
  - 新建关键帧默认 1000ms（自动 clamp）。
- 长条数据写入 editor.json 的 `durationMs`，保存/重进可恢复。

### 4.3 滚轮 / 键盘

- **滚轮**：移动 playhead（100ms/格；Shift 500ms）；
- **Ctrl/Cmd + 滚轮**：以鼠标为锚点缩放；
- 方向键：
  - 有选中 → 移动关键帧；
  - 无选中 → playhead 1 帧 / 100ms。

## 7. R3.5c-3 交互修正

1. **WASD / 方向键统一**
   - `A/D` 与 `←/→` 都是“相机 + 时间轴”双移动；
   - `W/S` 与 `↑/↓` 都是相机垂直移动；
   - 时间轴速度带线性缓动/惯性，松键后继续滑行；
   - Shift 加速。
2. **点击空白取消选中**
   - ROU Stage 空白点击取消选中并收起 Inspector；
   - Timeline 空白/框选空集合清空选择；
   - NEU 蓝图空白点击收起右栏。
3. **移除关键帧后的 Logo hint**
   - 删除 timeline 上的节奏点提示图片；
   - 同层相邻关键帧之间新增细连接线；
   - `durationMs` 长条加粗到 6px。
4. **Effects 下拉**
   - 原生 select 改为自定义深色玻璃下拉菜单；
   - 与编辑器边框/背景/过渡一致。
5. **NEU 模块拖拽**
   - 按光标相对模块的偏移移动，不再跳到左上角；
   - 蓝图横向 pan 时同步补偿。
6. **NEU 右栏/蓝图**
   - 右栏收起后蓝图占满；
   - Shift + ←/→ 横向移动蓝图视窗；
   - 蓝图右侧接口列不再被固定遮挡；
   - 右上按钮方向修正：展开时 `›`，收起后 `‹`；
   - 右栏 `translateX` 滑出/滑入。
7. **滚轮**
   - 滚轮移动 playhead；Ctrl/Cmd + 滚轮缩放。
8. **ROU↔NEU 转场**
   - ROU→NEU：旧画面向左加速、模糊；中点切换；蓝图从右侧清晰减速进入；
   - NEU→ROU 向右，反向；
   - 460ms out + 540ms in，总计约 1s。
9. **资产拖拽 / 绑定**
   - 左栏新增视频资产；
   - 时间轴每层轨道支持 dragOver/drop，绑定最近 800ms 的关键帧，否则在该位置新建；
   - 关键帧按钮支持 drop；
   - 点击资产后再点击关键帧也可绑定；
   - NEU 蓝图支持资产 drop，也支持选中资产后点蓝图空白放置模块；
   - Inspector 显示 `BOUND`。
