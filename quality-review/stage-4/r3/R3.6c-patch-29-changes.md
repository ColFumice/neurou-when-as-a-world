## 1. 输入行遮住上方字幕

最终原因：

- 20px 字体在 `line-height:1.1` 下行盒只有 22px；
- 字形的 ascender/descender 会超过行盒；
- 输入行虽然已经在日志流末尾，但紧贴最后一行时字形仍会压住上一行；
- Fisheye filter 的输出还会从输出容器绘制到输入行区域。

修复：

```css
.project-console__input {
  position: static;
  z-index: auto;
  background: #000000;
  padding: 1.1em 0 0;
  margin: 0;
  min-height: 1.1em;
  line-height: 1.1;
  font: inherit;
}
```

```css
.project-console__fisheye {
  overflow: hidden;
  clip-path: inset(0);
  contain: paint;
}
```

- 输入行不再有独立黑条（背景与纯黑终端一致）；
- 与最后一行之间留出一整行高度；
- 输入行仍在日志流后面，不是固定终端栏；
- 下方 7 行仍是同类型空日志行。

实测截图：`r36c-fullscreen-cmp2.png`

- `decorations:false` 保持不变；
- 下一次启动生效。

## 3. 全屏底部明亮横线

根本不是滚动条，而是原来的：

```css
inset: 2px;
border: 2px solid #ffffff;
border-radius: 14px;
```

在全屏时，屏幕最底部 2px 纯白边框看起来就是一条非常亮的横线。

修复：

```css
inset: 6px;
border: 1px solid rgba(255, 255, 255, 0.66);
border-radius: 16px;
```

- 边框从 2px 纯白改为 1px 半透明白；
- 离屏幕边缘 6px，不再贴着底部；
- 圆角改为 16px；
- `project-console__fx` 同步 inset6、radius15；
- 底部不再出现贴着屏幕边缘的亮线。
