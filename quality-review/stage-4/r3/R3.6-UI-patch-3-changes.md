# R3.6-UI-patch-3 变更说明

- 日期：2026-10-23（Asia/Shanghai）
- 范围：移除准星镜片；缩小中心粗十字
- 状态：实现完成，自跑通过，待人工验收
- 前置：R3.6-UI-patch-2（字幕 ×3 / 隐藏光标 / 鱼眼暗角）

---

## 1. 改动

### 1.1 移除准星镜片

- 删除 `Crosshair.tsx` 中的 `crosshair__lens` 容器及内部 `crosshair__bulge--x/y`。
- 删除 `crosshair.css` 中 `.crosshair__lens`、`.crosshair__bulge`、`.crosshair__bulge--x`、`.crosshair__bulge--y` 及 `is-pressed .crosshair__lens`。
- 不再有 156px 圆环、镜片填充、内阴影/外阴影。
- 保留：
  - 100vw / 100vh 的 1px 横竖线；
  - 线体边缘暗角 mask（从屏幕边缘向中心渐亮）；
  - 中心 80px 径向微光；
  - 点击/拖拽 `scale(0.9)`。

### 1.2 缩小中心粗十字

| 项 | 原 | 新 |
|---|---:|---:|
| 中心 core 尺寸 | 10×10 | **8×8** |
| 竖臂 | 2×10，left 4px | **2×8，left 3px** |
| 横臂 | 10×2，top 4px | **8×2，top 3px** |
| 中心 glow | 120px | **80px** |
| glow 中段 alpha | 0.045 | **0.03** |
| 长粗臂 | 132×2 横/竖各一 | **移除** |

- 中心仍是“白色小十字”，但整体比之前小一圈；1px 主线与 8×8 中心形成明确层级，不再有长 132px 的粗臂。
- `prefers-reduced-motion` 同步移除 lens 选择器。

## 5. 边界

1. **鱼眼效果移除**：本轮按“除去镜片”要求删掉了镜片和中心膨胀段；保留的是边缘暗角 mask。若以后要鱼眼，应作为独立可选效果重新加，不要默认铺在 UI 上。
2. **中心尺寸**：8×8 是折中；如果仍觉得粗，可把 core 降到 6×6、臂宽 1px；如果觉得小，可回到 10×10。
3. **线条暗角**：边缘 mask 仍保留；若希望线在边缘更实，可把 0.16 的端点 alpha 提高到 0.3。
4. **字幕时长**：本轮未改，仍为 9s 总时长 / 约 6.12s 稳定显示。
5. **Parallax 路由**：截图仍用临时 dev mount，未改路由。

## 6. 一句话

去掉 156px 镜片和 132px 粗臂，中心粗十字从 10×10 缩到 8×8、glow 从 120px 缩到 80px；保留 1px 全屏线、边缘暗角和点击 scale(0.9)。
