## 1. R3.6b-patch-6 手感优化

### 1.1 新建 Folder 游走

当前空 folder 已有独立 hash 相位 `phase(folderId)`，但游走半径只有 10；改为：

- 空 Folder 圆轨道半径 **24px**（与单世界节点默认退化圆轨道一致）；
- 使用 `phase(folderId)` 确定角度，不依赖布局时的创建顺序；
- 仍然保持在中央空 folder 行（x 按数量居中、y 110、z 950）；
- 不改变已有 Project 的游走路径。

### 1.2 选中即定

`ProjectTreeLayout` 增加可选输入：

```text
selectedNodeId?: string
pinnedWander?: { nodeId: string; x: number; y: number }
```

规则：

1. 选中节点：
   - 不再推进该节点的 `wanderX/wanderY`；
   - 使用点击瞬间的 `pinnedWander`（从当前 layout 读取）；
   - 节点位置只在相机平滑归零时随屏幕坐标移动，自身不游走。
2. 相机：
   - 存在 selectedNodeId 时，`targetPanX = targetPanY = 0`；
   - 仍用 `0.08` 平滑；
   - 取消选中后恢复 `targetPan` 跟随鼠标。
3. 取消选中（点击空白）：
   - 清空 `pinnedWander`；
   - 恢复游走和鼠标相机。
4. LayoutNode 输出增加 `wanderX/wanderY`，供 View 在点击时记录。
5. 测试：
   - 选中节点在不同 `timeMs` 下 screenX/Y 不变（相机固定）；
   - 相机 target 归零；
   - 取消选中后恢复变化。

`ProjectTreeView` 用 `layoutRef` 保存最新 layout，在 `pointertap` 时记录选中节点 wander。

## 2. ConsoleSession 抽取

### 2.1 现状

`WorldFolderConsole` 内部包含：

- entries/currentPath/selectedEntryId/hovered/selectionMode；
- history/input/effect/settingsOpen/contextMenu/loadingEntry/activeWorld；
- `handleCommand`、`openEntry`、`submit`、`handleRootKeyDown`、context menu 等。

### 2.2 关键 A 名约束

`ConsoleSession` 不能作为 non-A export，否则 `check-naming` 会报错。

方案：

- 把 `WorldFolderConsole` 与 `ProjectConsole` **放在同一个 console 模块**（可保留现有 `WorldFolderConsole.tsx` 文件名），`ConsoleSession` 在该模块内 **非导出**；
- 两者共用同一个 `useConsoleSession` 内部 hook（也不导出）；
- `ProjectConsole` 作为该模块的第二个 A export。

这样：

- 没有新增 A 名；
- `ConsoleSession` 不跨模块导出；
- R3.3 的 A 类 `WorldFolderConsole` 保持原名；
- `ProjectConsole` 的 import 路径为 `console/WorldFolderConsole`（文件名历史原因；如需改文件名，必须整体搬移两个 A export，不能做 re-export 副本）。

### 2.3 Session 责任

`useConsoleSession` 统一维护：

- `ConsoleDirectory` 根 + 当前路径；
- entries（World 或文件条目）；
- selected/hovered/selectionMode；
- history/input/effect/settings/contextMenu/loading/active view；
- `ConsoleCommand.parseCommand`、`ConsoleDirectoryConstraint`；
- `append` / `submit` / `openEntry` / `exit`。

`WorldFolderConsole` 与 `ProjectConsole` 只负责：

- 顶部/布局差异（World 有目录栏；Project 纯文本无栏目）；
- 元数据头/项目树返回；
- 把 session 的输出交给 `ConsoleOutput`。

### 2.4 `exit`

`ConsoleCommand` 当前没有 `exit`。需要：

- 在 `ConsoleCommandKind` / 解析表 / `ConsoleCommandList` 增加 `exit`；
- 这是既有 A 类 `ConsoleCommand` 的演进，不新增 A；
- 回归 Command 解析测试；
- `WorldFolderConsole` 收到 exit 时忽略或回退（保持兼容），`ProjectConsole` 用 `onExit` 返回项目树。

## 3. ProjectConsole

文件：与 `WorldFolderConsole` 同一 console 模块，导出 `ProjectConsole`。

### 3.1 Props / 数据

```text
ProjectConsole {
  project: Project;             // ProjectMeta + folderId
  worlds: readonly WorldInstance[];
  onExit(): void;
  onEnterWorld(world: WorldInstance): void;
}
```

- `worlds` 由 App/ProjectTreeDemoScreen 提供；按 `ProjectMeta.worldIds` 过滤/排序。
- `WorldInstance.prologue` 用于进入世界字幕。
- `ProjectMeta.prologue` 只用于头部。

### 3.2 头部

第一行 `>` 上方输出：

```text
Author: ...
Created: ...
Completed: ...   // null -> —
Worlds: N
Theme: #RRGGBB
Prologue: ...    // 项目序言
Project ID: 1234 5678
Type 'help' to get command list
```

### 3.3 视觉

- 全屏纯文本，无左目录/右输出栏目；
- `ConsoleOutput` 全宽；
- `ConsolePrompt` + input；
- `ConsoleEffect` / `SettingsConsole`；
- 鱼眼/暗角使用现有 console effect class；不新增渲染层；
- 返回项目树只通过 `exit` 命令（或顶部极简文字，不形成栏目）。

### 3.4 命令

- `ls`：列出 World 条目；
- `cd world`：进入虚拟目录；
- `pwd`；
- `help`；
- `clear`；
- `settings`；
- `open`：选中 World → `WorldLoadingSequence`；
- `export`：`WorldExportIntent` 输出；
- `import`：占位；
- `exit`：`onExit` 返回项目树。

World 条目用 `WorldFileEntry` 表达（entryId=worldId，displayName，kind=WorldExe）；不引入新 A 类型。

## 4. 世界进入与黑屏字幕（AC4-50）

### 4.1 流程

ProjectConsole `open` 选中 World：

```text
WorldLoadingSequence
  0.0s  WorldLoadProgressBar（命令行加载行 + 进度）
  0.7s  WorldPixelZoom（视角拉近到像素点）
  1.4s  黑屏；WorldEnterTransition 中央字幕
  1.4s–4.4s  WorldInstance.prologue 淡入 / 停留 / 淡出
  4.4s  闪光
  4.4s–5.2s 世界从模糊/过曝恢复
  5.2s  onComplete
```

- 过渡期间不写账本、不改 WorldInstance。
- 字幕文本严格取 `WorldInstance.prologue`；空字符串时不显示字幕但仍完成过渡。
- `ProjectMeta.prologue` 不进入此字幕。

### 4.2 修改

- `WorldEnterTransition` 增加 `prologue: string` prop；
  - 中央白色字幕，CSS `fade-in 500ms / hold / fade-out 500ms`；
  - 保留叠黑、闪光；
  - 不再把 worldName 当字幕，仅作为小号 ENTER 标签。
- `WorldLoadingSequence` 增加 `prologue: string`；阶段计时改为上述 700/1400/4400/5200ms；
- ProjectConsole 记录 `loadingWorld: WorldInstance | null`，完成后显示世界占位视图；
- `WorldInstance.prologue` 已存在。

## 5. 项目树 → ProjectConsole 接入

### 5.1 ProjectTreeView

增加可选 `onOpenProject?: (projectId: string) => void`。

- 选中 Project 再次点击：DOM 全屏放大（现有）；
- DOM 放大 700ms 结束后调用 `onOpenProject(projectId)`；
- 选中 Folder 不触发；
- 点击空白清除 zoom，不触发。

### 5.2 ProjectTreeDemoScreen / App

- state `activeProjectId: string | null`；
- `onOpenProject` → setActiveProjectId；
- activeProjectId 时渲染 `ProjectConsole`（项目数据 + worlds fixture）；
- ProjectConsole `exit` → activeProjectId=null，回到项目树；
- ProjectTreeView 长驻 app 不受影响（组件卸载时按现有安全 destroy）。

### 5.3 项目加载滚动

ProjectConsole 首次挂载时：

- 先输出 `loading project...` / `reading project.json` / `mounting worlds...` 等命令行；
- 再输出 metadata header；
- 不需要新增 A 组件；可用现有 `ConsoleOutput` 行。

## 8. 风险 / 待确认

1. **ConsoleSession 的模块归属**：本计划选择“WorldFolderConsole + ProjectConsole 同模块，ConsoleSession 非导出”。如果 PROTOCOL 要求 ProjectConsole 独立文件，则必须允许一个非 A 的 internal export，或接受把两个 A export 放到同一文件。
2. **`exit` 扩展**：需要修改 R3.3 的 `ConsoleCommand` / `ConsoleCommandList`；这是 A 类演进，不是新 A，但会改动 R3.3 文件。
3. **WorldLoadingSequence 时长**：上述 5.2s 为建议；3s 黑屏 + 闪光 + 恢复，可按验收调整。
4. **项目树 DOM zoom 后的切换时机**：700ms 动画结束后切 ProjectConsole，避免 DOM 层叠在 console 上。
5. **WorldInstance fixture**：需要为每个 world 构造完整实例；不写账本。
