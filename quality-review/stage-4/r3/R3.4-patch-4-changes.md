# R3.4 补丁 4 变更说明

- 日期：2026-10-20（Asia/Shanghai）
- 范围：ParallaxDemoScreen 左右键推进手感
- 状态：R3.4 补丁 4 完成，待 Trae 测试 + 用户人工验收

## 1. 根因

旧实现只在 `keydown` 中调用 `timeline.advance()`，连续推进依赖 Windows 键盘 auto-repeat：

- 首次重复延迟约 250ms；
- 之后重复间隔约 30ms。

因此按住左右键会先停顿约 250ms 才开始连续移动。Pixi 渲染与 `TimelineStateMachine.advance` 本身没有延迟。

## 2. 新方案

`ParallaxDemoScreen.tsx` 改为 **pressedKeys + requestAnimationFrame**：

- `pressedKeys: Set<'ArrowLeft' | 'ArrowRight'>` 记录当前按住的左右键。
- `keydown`：
  - 左右键 `event.repeat` 直接忽略；
  - 首次加入 `pressedKeys` 时立即 `advance(±INITIAL_STEP_MS)`，保证短按有响应；
  - 启动 rAF 循环。
- `keyup`：移除对应键；集合为空时 `cancelAnimationFrame` 并清空 lastTime。
- `tick(now)`：
  - `dt = min(now - lastTime, 50)`；
  - 单方向：`advance(±PER_FRAME_MS * dt / FRAME_MS)`；
  - 双方向：互相抵消，不推进；
  - 继续请求下一帧。
- `window.blur`：清空按键并停止循环，避免切走窗口后按键卡住。
- 左右键的 auto-repeat 不再参与推进。

### 同时按住左右键的策略

选择 **互相抵消**：

- 两键同时按住时，tick 不推进；
- 第二键按下时不追加 initial step（只有 `pressedKeys.size === 1` 才应用 initial step）；
- 松开其中一键后，剩余方向立即恢复推进；
- 该策略比“最后按下优先”更可预测，也避免两键抖动造成方向跳变。

## 3. 常量与理由

放在 `ParallaxDemoScreen.tsx` 顶部：

```ts
const INITIAL_STEP_MS = 50;
const PER_FRAME_MS = 8;
const FRAME_MS = 1000 / 60;
```

- `INITIAL_STEP_MS = 50`：短按一下至少推进 50ms，肉眼可见，不出现“按了没反应”。
- `PER_FRAME_MS = 8`：60fps 下每秒约 480ms；加上首步 50ms，按住 1 秒约 530ms。按用户允许的“可接受更快/更慢”，如需精确 480ms 可把 `PER_FRAME_MS` 调到约 7.2。
- `FRAME_MS = 1000/60`：以 60fps 为时间基准，dt 会随实际帧间隔缩放。
- `dt` 上限 50ms：避免切后台/卡顿后一帧跳太远。

## 4. 边界、暂停、清理

- 边界：仍由 `TimelineStateMachine.advance` 内部 clamp；到 0 / 12000ms 停止，屏幕层不额外处理。
- 暂停：`playbackState === Paused` 时 `advance` 内部冻结；rAF 可继续跑，但不移动。
- 清理（effect cleanup）：
  - 移除 `keydown` / `keyup` / `blur` 监听；
  - `cancelAnimationFrame`；
  - 清空 `pressedKeys` 与 `lastTime`。
- StrictMode 双调用：每次 effect 独立 set/raf/lastTime，cleanup 完整取消；不会遗留循环。

## 7. 人工验收清单

`tauri dev` → 视差演示：

1. **短按一下左/右**：立即推进约 50ms，不是没反应。
2. **按住不放**：从第一帧开始连续推进，无 250ms 首延迟。
3. **按住约 1 秒**：推进约 530ms（初始 50 + 480）；若觉得偏快，调 `PER_FRAME_MS`。
4. **松开**：立即停止，无惯性。
5. **同时按住左右**：互相抵消，画面不推进；松开一键后单向恢复。
6. **到边界**：0 / 12000ms 停止。
7. **暂停时按住左右**：无推进。
8. **卸载后重新进入**：正常；无残留 rAF/按键。
9. 三层视觉、视差框、HUD、target 切换保持正常。
