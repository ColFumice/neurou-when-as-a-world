# R3.4 补丁 3 变更说明

- 日期：2026-10-20（Asia/Shanghai）
- 范围：ParallaxRenderer 三层层级/尺寸/纹理修正 + fixture 视差因子
- 状态：R3.4 补丁 3 完成，待 Trae 测试 + 用户人工验收

## 1. 三层的新尺寸与视觉标识

渲染器现在按 stage 尺寸计算三层，全部居中；背景层做 1.5× overscan，避免视差移动时露出空白。

| 层 | 尺寸 | 颜色 | 图案 | 透明度 | Pixi 标签 |
|---|---|---|---|---|---|
| 背景 L1 | 容器 1.5× 宽高 | `#101c2c` 深蓝 | 40px 网格 | 1.0 | `L1 / BACKGROUND` |
| 中景 L2 | 容器 0.7× 宽高 | `#1d4a5e` 青蓝 | 34px 斜纹 | 0.85 | `L2 / MIDGROUND` |
| 前景 L3 | 容器 0.4× 宽高 | `#4c8fae` 亮蓝 | 18px 横纹 | 0.7 | `L3 / FOREGROUND` |

- 三层都居中：container 位于 stage 中心，graphics 以 `(-w/2, -h/2)` 为左上角绘制。
- 容器 `alpha` 分别为 1.0 / 0.85 / 0.7；图形填充 alpha 为 1，避免双重衰减。
- 每层有独立色相 + 图案 + Pixi 文字标签，不看 HUD 也能区分。
- F3 可选调试开关未实现；层标签、独立边界/尺寸与 HUD offset 已覆盖调试需求。
- 背景 1.5× overscan：即使 offset 到 12000ms 的 96px，也不会露出底色。

## 2. 新的 parallaxFactor

fixture 的 `WorldInstance.layers` 与 `VisualFrame.parallaxFactors` 同步改为：

| 层 | 旧 | 新 |
|---|---|---|
| L1 背景 | 0.35 | **0.1** |
| L2 中景 | 0.7 | **0.5** |
| L3 前景 | 1.3 | **1.5** |

HUD 增加 layers 行，并显示每层当前 offset：

```text
offsets: L1 <positionMs*0.08*0.1>px · L2 <...*0.5>px · L3 <...*1.5>px
```

## 3. 视差公式

**未调整。**

```text
offsetPx = timeline.positionMs * 0.08 * parallaxFactor
```

- 12000ms：L1 96px / L2 480px / L3 1440px。
- 1200ms：L1 9.6px / L2 48px / L3 144px，肉眼差异明显。
- 层尺寸改为居中后，offset 位移不再被“同尺寸全屏矩形”遮挡。
- `ParallaxCamera` 文件未改（仍为 1,349 字节 / `b1a27b6d…`）。
