## 1. 新建 Folder 游走修复

### 根因

- 双击空白时只清除了选择 state，但 `selectedRef` / `pinnedWanderRef` 可能仍保留上一个选中节点；
- 新 Folder 进入 `ProjectTreeLayout` 后，如果被当作 pinned，它的 wander 就被冻结；
- 空 Folder 的轨道周期为 24s，24px 半径在短时间内不明显。

### 修复

`ProjectTreeView.onDoubleClick`：

```ts
setSelectedId(null);
selectedRef.current = null;
pinnedWanderRef.current = null;
```

`ProjectTreeLayout`：

- 空 Folder 继续使用确定性 `phase(folderId)`；
- **半径 24px**；
- 轨道周期从 24s 改为 **12s**，肉眼可见；
- 新增测试：同一空 Folder 在 1000ms 与 3000ms 的 `screenX/screenY` 必须变化，同时半径保持 24。

## 2. 加载动画重构

ProjectConsole 不再渲染全屏 `WorldLoadingSequence`。所有阶段都在 ProjectConsole 内部完成：

### 2.1 视角拉近（0–1.5s）

- 输入 `open w1` 后，不弹全屏组件；
- 在文本输出区持续追加：
  - `[====>     ] 42% Loading shader / Mounting world...`
  - `stream: world.w1 / frame ...ms`
- 整个 `.project-console` 通过 inline `transform: scale(...)` 逐渐放大；
- 缩放上限约 9×，仍能读出加载行；到 1.5s 跳到像素级并黑屏。

### 2.2 像素黑屏（1.5–2.0s）

- 全屏黑底；
- 中央 4px 白色像素点，0.5s 内淡出/放大；
- 随后纯黑。

### 2.3 黑屏字幕（2.0–5.0s）

- 纯黑 3 秒；
- 中央白字淡入 / 停留 / 淡出；
- 内容严格为 `WorldInstance.prologue`；
- **无闪光、无白闪**。

### 2.4 亮屏与糊化恢复（5.0–7.0s）

- 5.0s 世界视图出现；
- CSS `project-world-recover`：
  - 0%：`blur(18px) brightness(2.2)`；
  - 55%：`blur(5px) brightness(1.35)`；
  - 100%：正常亮度/清晰度；
- 持续 2s，不是闪光，是高亮过曝 + 模糊恢复。

### 2.5 时序

```text
0.0s  open w1，开始打印加载行 + console scale
1.5s  像素点 / 黑屏
2.0s  黑屏字幕开始（WorldInstance.prologue）
5.0s  亮屏 + 极度模糊
7.0s  完全恢复，activeWorld
```

过渡期间不写账本、不改世界状态。

## 3. UI 栏移除与 Esc 返回

### 3.1 项目树

移除：

- 顶部 `← 返回`；
- `项目树` 标题 / R3.6b eyebrow；
- 右上角节点数 / fps / fisheye 状态；
- 底部 hint；
- 选中态 DOM 提示条。

保留：

- 全屏 canvas；
- 涟漪、暗角、白边、游走、选中放大、DOM 全屏放大。

返回：

- `Esc`：若 zoom 打开先关闭 zoom；否则 `onExit()` 返回上一级。

### 3.2 App 顶栏

- `projectTreeOpen || demoOpen` 时隐藏 App header；
- 项目树 / 视差演示 / ProjectConsole 均不再显示全局标题栏。

### 3.3 ParallaxDemoScreen

- 移除顶部 `header`（返回、标题、hint）；
- `Esc` 返回事件树。

### 3.4 ProjectConsole

- 移除 topbar（`← exit` / `PROJECT CONSOLE` / settings）；
- 移除所有边框；
- 返回只通过：
  - `Esc`；
  - `exit` 命令。

### 3.5 验证截图

- `r36c-p1-tree.png`：无任何 UI 栏的项目树；
- `r36c-p1-console.png`：纯黑 ProjectConsole，输入行紧跟正文；
- `r36c-p1-esctree.png`：Esc 从 console 回项目树；
- `r36c-p1-escevent.png`：Esc 从项目树回事件树。

## 4. ProjectConsole 纯黑沉浸化

- 背景：`#000000`；
- 字体：`20px` 等宽 `Cascadia Mono / Consolas`；
- 输出：无边框、无栏目、无 topbar；
- 输入行 `> /` 位于 **ConsoleOutput 最后一行之后**，不是固定在屏幕底部；
- 外层 `.project-console__scroll` 自动滚动到最新输出；
- 头部 metadata 全部为纯文本行。

CSS 关键点：

```css
.project-console {
  background: #000;
  font: 400 20px/1.65 "Cascadia Mono", "Consolas", monospace;
}
.project-console__scroll {
  flex: 1;
  overflow-y: auto;
}
.project-console__input {
  position: static;
  border: 0;
}
```
