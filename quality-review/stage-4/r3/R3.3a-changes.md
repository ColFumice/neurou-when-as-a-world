| 文件 | 内部名 | 用途 |

| `ConsoleDirectory.ts` | `addChild` / `getParent` | 树构造与父节点读取（额外方法，不新增导出名） |

`ConsoleDirectoryConstraint` 与 `ConsoleCommand.parseCommand` 的返回类型使用内部类型；测试通过结构访问，不导出新名字。

### 语义实现说明

- `ConsoleCommand` 同时是类型与值：类型为 9 个命令变体联合；值为 `{ parseCommand }`。没有导出独立的 `parseCommand`，以遵守“所有导出名必须在 NAMEBOOK”的约束。
- `WorldExportIntent` / `WorldImportAuto` 同样采用 interface + 同名值对象，提供 `create` / `detectFromPath` 静态方法。
- `WorldImportAuto.detectFromPath` 的映射：
  - `.exe` / `.world` → `WorldExe`
  - 尾部 `/` 或无扩展名 → `Folder`
  - `.ini` / `.json` / `.cfg` / `.toml` → `Settings`
  - 其他扩展名 → `Other`
  - 空字符串 → `null`
- `ConsoleDirectoryConstraint` 只在 `cd` 上执行路径约束；其他命令返回 `ok: true` 且目录不变。
- `ConsoleDirectory` 的 `addChild` / `getParent` 为树构造和测试所需的额外方法，不新增 A 类名。
