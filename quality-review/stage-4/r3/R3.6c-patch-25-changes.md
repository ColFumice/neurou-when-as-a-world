## 1. 输入口未衔接末尾

原因有两层：

1. `.console-output` 的 Fisheye transform/filter 视觉上会溢出到输入行；
2. 退出 world 后 input 虽然存在，但焦点落回 body，用户打字没有进入输入框。

修复：

```css
.project-console__fisheye {
  overflow: hidden;
}
```

```css
.project-console__input {
  position: relative;
  z-index: 5;
  background: #000000;
}
```

焦点增加：

- `focus({ preventScroll: true })` 立即执行；
- rAF 一次；
- 90ms / 240ms 两次重试；
- 全局 keydown 兜底：console idle 时，如果焦点不在 input，先 focus 再处理按键。

这样退出 world 后直接打字就会进入输入行，不会停在 body 上。

---

## 2. 再次进入世界

之前“再进不了世界”的主要原因是退出后 input 实际没有焦点，`open w1` 没有被提交。

焦点修复后：

- `open w1` 可在退出后直接重新提交；
- token 机制仍防止旧 5s/7s timer 回拉；
- 再次进入会重新走 0.8–3.6s 放大、3.6s 黑屏、5.6s Bloom。

---

## 3. 加载日志强烈震颤

镜头本身仍然匀速缓入缓出，但日志层增加独立震颤：

```css
.project-console.is-zooming .project-console__fisheye {
  animation: console-log-shake 90ms steps(2, end) infinite;
}
```

```css
@keyframes console-log-shake {
  0% { transform: translate3d(-14px, 6px, 0) rotate(-0.15deg); }
  20% { transform: translate3d(16px, -9px, 0) rotate(0.18deg); }
  40% { transform: translate3d(-12px, -5px, 0) rotate(-0.12deg); }
  60% { transform: translate3d(10px, 10px, 0) rotate(0.2deg); }
  80% { transform: translate3d(-17px, -4px, 0) rotate(-0.18deg); }
  100% { transform: translate3d(7px, 5px, 0) rotate(0.1deg); }
}
```

- 只抖日志，不抖镜头；
- 90ms 步进跳动；
- 最大位移 17px；
- 0.8–3.6s 持续；
- 退出 `is-zooming` 后停止。
