## 1. 渲染错位根因

新建 Folder 错位由三个问题叠加：

1. **空 Folder 中性色映射到左上角**
   - 空 folder 没有子项目，`folderTheme()` 返回 `{64,72,88}`；
   - RGB→XYZ 后 x≈-450、y≈-176，屏幕坐标落在 stage 左上；
   - 0.65 尺寸后被 stage 边缘裁切，表现为“扭曲/切一半”。

2. **新节点初始 `displayX/displayY = 0`**
   - `createNodes()` 新建 NodeView 时显示位置为 0；
   - 虽然 ticker 下一帧会插值，但重建/首帧期间新节点停留在 (0,0)，连线也指向左上角。

3. **增量重建后没有立即应用 layout**
   - workspace 更新 → rebuildScene → createNodes，而位置只由下一帧 ticker 更新；
   - 新 folder 在首帧前处于未布局状态。

## 2. 数据更新时的正确刷新顺序

`ProjectTreeView` 保持长驻 Application，workspace 变化时：

1. `workspaceRef.current = workspace`（render 阶段）；
2. `useEffect([workspace, worldThemes])` → `syncSceneRef.current()`；
3. `rebuildScene()`：
   - `nodeLayer.removeChildren()`
   - `nodeViews.clear()`
   - `backgroundLayer.removeChildren()`
   - `edgeGraphics.clear()`
   - `createNodes()`（NodeView `initialized: false`）
4. **立即执行一次 `ProjectTreeLayout.compute()`**；
5. 对每个新节点直接写入：
   - `displayX = node.screenX`
   - `displayY = node.screenY`
   - `displayScale = node.scale`
   - `container.x/y/scale`
   - `initialized = true`
6. `setBackground()`；
7. ticker 后续帧再做平滑插值。

这样新节点不会从 (0,0) 漂移，也不会错过首帧布局。

## 3. 空 Folder 的布局

`ProjectTreeLayout.nodePosition()` 对空 Folder：

- 颜色固定为中性灰 `{128,128,128}`；
- 位置不再由 RGB 映射到左上，而是放在屏幕中央下方的空 folder 行：
  - 按空 folder 数量水平居中；
  - 每个间隔 260；
  - y = 110；
  - z = 950；
- 仍保留 0.65 尺寸、游走、白边、鱼眼。

`ProjectTreeView.themeForNode()` 的空 folder 默认色同步改为 128 灰。

## 4. 连线

- `Workspace.create()` 增加可选 `links` 参数；
- `Workspace.materialize()` 同步接收 links；
- `ProjectTreeDemoScreen` 新建 folder 时增加：
  - `fromNodeId: 'folder:pf-0001'`（A Try）
  - `toNodeId: 'folder:<newFolderId>'`
- 新 Folder 会有一条连线到 A Try，随布局/相机移动。
