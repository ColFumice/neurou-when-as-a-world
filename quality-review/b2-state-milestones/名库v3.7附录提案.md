# 名库 v3.7 附录提案 · 交 Trae 落盘

日期：2026-10-10。状态：提案，生产未新增这些名称。本文件不是 docs/NAMEBOOK.md 更新，不修改任何已冻结名。依据 VERDICT-211～225 和 PROTOCOL-B2.2-001；新名追认与 scope 决定分开进行。

| 新增候选名称 | 归属 | 职责 / 边界 |
| --- | --- | --- |
| AccountMilestoneStorage | presentation | FirstWorldCleared 本地投影的平台适配；独立 key，永不覆盖 AccountStartupStorage。无远程认证含义。 |
| AccountMilestoneProjection | director 契约 | 持久化结构 schemaVersion/accountId/FirstWorldCleared；不含 CopyPermission。 |
| AccountMilestoneSnapshot | director 契约 | 只读账号投影结果，包含派生 CopyPermission；区别于持久载荷。 |
| AccountMilestoneReader | director 契约 | 只读 `getMilestoneSnapshot()`，presentation 经 IntentPort type 转发读取。 |
| WorldStateSession | director | 七项跨域聚合及完整性/恢复事务协调；不把业务写入给 View。 |
| WorldStateSnapshot | director 契约 | 完整验证通过的七项世界状态投影及恢复支持状态；不含账号通关记录。不是 FileCarryPayload。 |
| WorldStateCaptureResult | director 契约 | Complete 携带完整快照；Incomplete 携带已有部分及缺失诊断。 |
| WorldStateRestoreResult | director 契约 | 恢复成功/明确拒绝/校验失败；只有完整且兼容状态才成功。 |
| WorldStateDiagnostic | director 契约 | 缺少权威载体、机制、身份或保存边界的原因；只读诊断，不是游戏事实。 |
| WorldStateReader | director 契约 | 读取状态完整性与操作结果；不暴露删除/改写账本。 |
| WorldStateStorage | presentation | 按账号与世界隔离的本地完整状态平台适配；不持有目录决策权。 |
| WorldForkAvailability | director 读取契约 | 产品实现状态；本轮 NotImplemented，与 CopyPermission、状态完整性分别表达。 |
| captureWorldState | WorldStateSession | 只读 capture 操作，深复制/冻结，无法捕获时返回 Incomplete；不产生叙事事件。 |
| restoreWorldState | WorldStateSession | 对未激活新图的受控 hydration；不是修改/删除活跃账本，不产生首演/通关事实。 |
| getMilestoneSnapshot | AccountMilestoneReader | 读取账号里程碑和派生权限。 |
| readProjection / saveProjection | AccountMilestoneStorage | 平台读写签名候选；业务解析与单向事实检查仍归 director。 |
| getLastCaptureResult | WorldStateReader | 只读最近捕获结果；不触发副作用。 |

沿用冻结名，不计本轮新增：AccountProfile、AccountMilestone、PrologueCompleted、FirstWorldCleared、CopyPermission、WorldClearRecord、RouteSignature、WorldInstance、WorldKind、FormatTime、WorldLink、LinkState、RecallCount、PuzzleProgress、ChartSnapshot、ChartScore、ChartRef、Ledger、NarrativeEvent、WallClock、SphereCrossing、LedgerPosition、ChartEntry、WorldBossChart、WorldFork、ChartTier。

沿用后续修订：Final 的快照/得分属于 FinalShore 个人层；球面穿越必须由 Player 写入触发；世界分叉继承完成账本/快照/得分而不继承通关记录，不允许重首演刷记录。

必要支持元数据沿用冻结名 ShoreOrigin、AIProfileSnapshot；没有把它们作为本轮新名。前者区分彼岸来源，后者支持 WorldLink 来源删除后的孤立恢复。

存储键不是新增业务实体名：

- 既有序章：`neurou-account-milestone-v1:<encodeURIComponent(accountId)>`。
- 新首次通关投影：`neurou-account-first-world-cleared-v1:<encodeURIComponent(accountId)>`。
- 既有目录：`neurou-world-folder-v1:<encodeURIComponent(accountId)>`。
- 新世界完整状态：`neurou-world-state-v1:<encodeURIComponent(accountId)>:<encodeURIComponent(worldId)>`。

FormatTime `{epochMs}` 是待追认的最小结构提案；createdAt、capturedAt、AppendedAt 与 FormatTime 分别保留其已有/提议用途，不做语义合并。Complete/Incomplete/NotImplemented 是读取结果取值候选，不建立永久业务里程碑。

接口草案中的内部品牌 `validatedWorldState` 只用于说明解析后类型与原始 JSON 的区别，不作为业务实体名。readSnapshot/saveSnapshot 沿用已有存储适配的方法命名习惯。diagnostic 的 section/reason/detail、capturedParts/issues 等为结果 DTO 字段候选，完整目录以接口草案为准；所有名称均尚未加入生产代码。
