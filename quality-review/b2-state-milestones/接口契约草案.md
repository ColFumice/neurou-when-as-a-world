# B2.2 捕获/恢复与账号投影接口草案

日期：2026-10-10。状态：评审提案，仅写在证据文档中，不是已编译的生产 TypeScript。领域载荷尚未冻结的部分不以 `unknown` 冒充完整状态。实际实施前须确定各领域 codec 和保存边界。

## 账号投影

```ts
// director 契约，presentation 经 IntentPort 仅类型引用。
interface AccountMilestoneProjection {
  readonly schemaVersion: 1;
  readonly accountId: string;
  readonly FirstWorldCleared: boolean;
}

interface AccountMilestoneSnapshot {
  readonly accountId: string;
  readonly FirstWorldCleared: boolean;
  readonly CopyPermission: boolean; // 计算值，绝不持久化
}

interface AccountMilestoneReader {
  getMilestoneSnapshot(): AccountMilestoneSnapshot;
}

// presentation 平台适配，不暴露给产品 View 作为写权限。
class AccountMilestoneStorage {
  readProjection(accountId: string): unknown | null;
  saveProjection(
    projection: AccountMilestoneProjection,
    expected: unknown | null,
  ): void;
}
```

以上类签名为接口示意，省略方法体，不可直接作为 `.ts` 实现提交。director 校验 accountId、版本、字段、布尔和单向事实。存储 read 返回 unknown；业务解析失败中止，不能把损坏投影解释为新账号。CopyPermission 每次由 FirstWorldCleared 计算。有效重复通关输入必须幂等；产品 View 不获得 CompleteWorld 或 SetPermission 意图。未来的合法首演结果由 director 内部可信链路处理，不能只凭调用者提交 `tier:'World'` 或 `completed:true` 成为通关事实。

事实写入和投影更新分层：AccountMilestoneProjection 只是本地读取面，不包含/替代 WorldClearRecord、RouteSignature 或首演账本。真实提交必须先建立可恢复的一致性协议，避免世界已记首演、账号里程碑却未保存后无法补记。此协议不伪称已被单 key localStorage 解决。

## 捕获结果与恢复边界

```ts
// WorldStateSnapshot 由内部七项 codec 和关联校验共同产生。
// 内部品牌不导出构造途径；原始 JSON 不能强转后被当作有效快照。
declare const validatedWorldState: unique symbol;

interface WorldStateSnapshot {
  readonly schemaVersion: 1;
  readonly accountId: string;
  readonly worldId: string;
  readonly worldKind: 'Primary' | 'Shore';
  readonly shoreOrigin: 'BugShore' | 'FinalShore' | null;
  readonly revision: number;
  readonly capturedAt: number;
  readonly [validatedWorldState]: true;
  // 真实内部结构必须包含七项已验证的载荷和必要恢复支持状态。
  // 当前不发布未实装机制的伪造 DTO；此头部自身不能产生 Complete。
}

interface WorldStateDiagnostic {
  readonly section:
    | 'Ledger' | 'PuzzleProgress' | 'RecallCount' | 'FormatTime'
    | 'WorldLink' | 'ChartSnapshot' | 'ChartScore' | 'RuntimeBoundary';
  readonly reason:
    | 'MechanismMissing' | 'ProjectionUndefined' | 'AuthorityUnavailable'
    | 'IdentityUnavailable' | 'RestoreUnsupported' | 'UnsupportedBoundary'
    | 'InvalidSnapshot' | 'SchemaUnsupported' | 'IdentityMismatch'
    | 'ReferenceMismatch' | 'StaleRevision';
  readonly detail: string;
}

type WorldStateCaptureResult =
  | { readonly kind: 'Complete'; readonly snapshot: WorldStateSnapshot }
  | {
      readonly kind: 'Incomplete';
      // 诊断投影，不可作为常规世界存档，也不能送入 restore。
      readonly capturedParts: Readonly<Record<string, unknown>>;
      readonly issues: readonly WorldStateDiagnostic[];
    };

type WorldStateRestoreResult =
  | { readonly kind: 'Restored'; readonly snapshot: WorldStateSnapshot }
  | { readonly kind: 'Rejected'; readonly issues: readonly WorldStateDiagnostic[] };

interface WorldStateReader {
  getLastCaptureResult(): WorldStateCaptureResult | null;
}

// director 聚合仅由组合根装配和业务协调使用；不直接交给 View。
class WorldStateSession {
  captureWorldState(): WorldStateCaptureResult;
  restoreWorldState(raw: unknown): WorldStateRestoreResult;
}

// presentation 平台适配；逻辑不导入浏览器 API。
class WorldStateStorage {
  readSnapshot(accountId: string, worldId: string): unknown | null;
  saveSnapshot(snapshot: WorldStateSnapshot, expected: unknown | null): void;
}

type WorldForkAvailability = 'NotImplemented'; // 本轮功能状态
```

restoreWorldState 的原始 unknown 入口必须重做完整 schema/身份/领域与关联验证；内部才接受品牌快照。品牌不序列化，不信任 JSON 的完整性标签。Incomplete 不能作为 restore 输入被接受；当前未建立七项 codec 和 hydration，所有完整恢复请求都应明确拒绝，不能返回假成功。未来 Restored 只能在未激活新对象图全部准备完成并发布后返回。

shoreOrigin 仅在 worldKind=Shore 时必须有合法来源；Primary 必须为 null。此 null 是经领域验证的不适用，不能用它替代未知来源。

本轮只设计同账号/同世界的恢复，拒绝身份不匹配和已观察到的过期版本；不能通过 restore 任意改 worldId 达成隐式分叉，也不能借旧快照覆盖已有更新账本。B2.3 的合法新 ID 分配与继承须另经 WorldFork，不属于这里的恢复入口。

## 七项 codec 必须验证什么

| 项 | 运行对象到投影的必要条件 | 关联校验 |
| --- | --- | --- |
| Ledger | 同一权威读写载体；每角色有序事件；深拷贝向量和所有附加项；VectorSchemaVersion=1、恰 20 维、每维有限且非负；缺维不补零。 | 角色身份、重复占位事件 ID 的处理，保留 append-only 历史；T6 endpoint 引用不能误认成首演完成。 |
| PuzzleProgress | 阶段、链身份、稳定边界或完整私有计时状态；终点及揭示/入口状态的恢复策略。 | Completed 与已有结算事实一致；恢复不重复写终点；不悬挂门控。 |
| RecallCount | 合法零值与机制缺失区别；非负安全计数。 | characterId + eventId 存在于该角色账本；ChartReplay 不影响。 |
| FormatTime | 有权威来源的非负安全纪元毫秒；不可在重入时刷新。 | 分叉继承；历史缺失为 Unavailable，而非 silent Date.now。 |
| WorldLink | 经世界 kind/shore origin 验证的不适用，或单层来源弱引用；孤立恢复所需 AIProfileSnapshot 必须已捕获并冻结。 | BugShore 指向同一来源，孤立后使用最后进入时的配置快照；FinalShore 不伪造链接；恢复不复制来源世界、不把孤立状态误删。 |
| ChartSnapshot | 首演完成冻结的实际播放数据及稳定内容引用；不是表现运行快照或 ChartPlaybackResult。 | 和首演账本引用逐项对应；仅入口引用不要求首演快照；修改资源不能改变既有快照。 |
| ChartScore | 冻结计分规则下的有效成绩载荷；持久档案更新语义另定。 | 对应有效 ChartRef/快照；计分结果不证明通关；进行中分数不冒充可恢复首演。 |

捕获应在同一逻辑边界取得一致投影，不能跨帧拼出 stage 已完成却账本尚未结算的快照。恢复时不提交 PlayerIntent、不调用普通 append 重放历史、不产生新账号事实。只在全部校验、对象构造及必需媒体引用准备成功后发布新图；任何失败保留原图/存储。

## 本批最小验收与后续恢复验收

恢复实施范围 A 后，至少验证：权限读取和派生、序章 key 不变、true 不回退、账号隔离、损坏/未知版本拒绝、保存失败不发布、Incomplete 能准确列缺项、正式存储/restore 拒绝 Incomplete、WorldFork 仍 NotImplemented。

完整性前置完成后额外验证：七项逐个非空/有效零值 round-trip、跨账号/世界拒绝、深拷贝无别名、重复恢复不写新账本/通关、完成链不重复结算、历史谱面冻结内容一致、失败时原图原存储不变。不能只断言 JSON stringify 前后相等，必须推进恢复后的玩法确认行为一致。

本轮没有运行上述 B2.2 测试；三门禁只覆盖未改的现有生产基线。
