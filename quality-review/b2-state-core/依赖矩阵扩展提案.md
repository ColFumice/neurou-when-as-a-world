# B2.2d-1 依赖矩阵提案

无新增模块，无新增矩阵边，不修改依赖门禁、docs/spec/stage-1.md 或参照文件。

director 继续作为最高逻辑编排层：LedgerHydration 依赖 ledger/constants/chart 类型；PuzzleHydration 依赖 trace/ledger/chart 引用分类；WorldStateCodec 聚合 director 内部载荷。trace 只增加自己的纯数据私有状态接口，不反向依赖 director。WorldInstance 的 FormatTime 保持 world 自身值结构。

presentation 继续通过 IntentPort 的 type-only 转发读取 director 结构，不导入 director 运行时校验器，也不产生账本事件或权限。WorldCoreStateStorage 接收组合根注入的严格验证器；FormatTimeStorage 共用该适配器。Web Locks/localStorage 留在 presentation，逻辑层无 cc、DOM 或浏览器存储调用。

assets/scripts 组合根负责资源加载、正式内容验证器绑定、lease 获得、未激活对象图构建、hydrate 后激活。玩家交互沿既有 PlayerIntent，不增加直接恢复、向量或权限输入。

需 Trae 同步的只有 ownership 元数据说明：Ledger / PuzzleProgress / FormatTime codec=Implemented，其余四项 NotImplemented；七项全可用才 Complete。依赖方向矩阵本身无需扩展。
