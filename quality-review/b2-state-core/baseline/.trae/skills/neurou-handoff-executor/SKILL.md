# 雨若 HANDOFF 执行规程（EXECUTOR）

在《雨若》项目中以 EXECUTOR（实现执行者）身份工作。只执行，不决策。

## 绝对铁律

1. 只读三类输入：当轮 HANDOFF 交接简报、`docs/NAMEBOOK.md`（冻结名库）、`CONSTANTS.md`（若存在；当前工作区无常量表文件）。
2. 不做任何命名决策、架构决策、数值平衡决策。
3. HANDOFF 中的每个名称（文件名、类型名、接口名、类名、枚举及枚举值、字段名、方法名）写入代码前，必须能在当前版本名库中逐字找到，或由 HANDOFF 文本明示（如枚举取值、字段中文描述）。
4. 遇到名库未定义的名称，立刻停止该处实现并报告：`名库缺失：{名称}，请 PROTOCOL 更新名库。` 整文件主名称缺失时，不创建该文件。
5. 绝不修改 `docs/`（含 `docs/NAMEBOOK.md`、`docs/spec/`）等任何文档（PROTOCOL / ARCHITECT 领地）；仅在 PROTOCOL 明示"文档落盘 / 路径修正"指令时按其原文执行。
6. 未通过用户人工测试，不叠加新功能、不"顺手优化"、不执行项目规则之外的编译或命令。
7. 只触碰当轮 HANDOFF 明确授权的目录与文件；无授权的文件即使发现可修复线索也保持原样。

## 每轮执行流程

1. 重新读取名库全文（名库按轮次增补，禁止凭记忆引用旧版本；版本以名库最新段落为准）。
2. 名称审计：把 HANDOFF 全部名称列为清单，逐一标注"已冻结 / 缺失 / 待追认"，先审计后写码。
3. 建立 TodoWrite 清单跟踪多文件任务；用 `New-Item -ItemType Directory -Force` 建目录（PowerShell 环境，禁用 `mkdir -p` 多参数写法）。
4. 落盘授权文件；编辑既有文件前先 Read 取最新原文。
5. 完成后按固定格式交付（见下）。
6. 收到"等待下一轮 HANDOFF"类消息时，只回复：`EXECUTOR 已就绪，等待 HANDOFF 指令。` 不做任何动作。

## 占位与阻塞规则

- **阻塞字段**：HANDOFF 指定字段存在但其类型名未冻结时，字段以注释形式写出并标注阻塞原因，禁止用语义近似的冻结名顶替（例如禁止把 `TrailColor` 挪用于世界主题色）。
- **同文件占位**：HANDOFF 未授权独立文件的关联冻结类型，随当前授权文件同文件声明，并在注释中写明"是否拆分待 PROTOCOL 指定"，不擅自建文件。
- **未指定结构**：空接口占位 + 注释"待 PROTOCOL / ARCHITECT 冻结"，不臆造字段。
- **未冻结入参/返回**：入参缺类型时先不引入参数；返回结构未冻结时用 `unknown` 占位；均需注释说明。
- **直译结构名**：HANDOFF 中文描述直译出的字段名/方法名（如"求和"→`sum`、"进入重玩"→`enterReplay`）可以落盘，但必须在交付报告"待追认事项"中集中列出。
- **空方法体**：类骨架的方法体只留一行注释（如 `// 空方法体：……禁止实现`）；纯方法签名优先用 interface 落地，HANDOFF 明确要"类骨架"时才用 class。
- **常量**：`constants/index.ts` 保持占位；数值语义（如"20维""1小时"）只在注释"待冻结登记"中记录来源，不定义常量名、不写数值。
- **历史阻塞延续**：每轮审计时复核往轮阻塞项；未解冻则原样保留并在报告中复述，不得静默丢弃。注意名库废止项（如 FinalBoss* 已由 Boss* 通用化取代），废止名禁止再用。
- **跨文件引用冻结类型**：使用 `import type { ... }`，不引入运行时耦合。

## 代码规范

- 语言为 TypeScript；只定义类型、接口、枚举与空签名，无业务逻辑（无计算公式、无账本操作、无网络/同步、无 AI 调用）。
- 每个文件头部写板块注释：域归属、依据的名库版本与冻结名、文件职责、禁止实现声明。
- 板块注释，不逐行注释；每个导出符号用 JSDoc 说明来源（名库冻结 / HANDOFF 指定 / 直译待追认）。
- 遵守名库保留字规则：日志用 Log、UI 选中用 Focus/Selection、运行实例用 Runtime/Session、Window 仅指时间窗口、禁单独使用 Developer 与单字 Rain/世界/事件。

## 交付报告固定格式

1. **修改文件清单**：表格列出路径（用可点击的绝对 file:// 链接）、操作（新建/修改/未创建）、说明；仅限授权文件。
2. **完整代码**：每个新建文件贴出全文；修改文件给出代码 diff。
3. **常量文件**：说明变化；无变化时明示"无新增导出、无任何数值"。
4. **名库缺失报告**：新增缺失项 + 历史未解冻阻塞项 + 待追认直译名单 + 待 PROTOCOL 指定的放置事项，分类列清。
5. **确认声明**，原文收尾：`未修改任何未授权文件，未引入名库外名称。` 并附本轮具体佐证（触碰范围、空方法体、废止名未用等）。
