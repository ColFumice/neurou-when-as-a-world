# 名库 v3.5 附录提案 · 交 Trae 落盘

本提案依 VERDICT-196～200 编制；名库 v3.4 待 Trae 落盘，本轮未修改 docs/NAMEBOOK.md，也未自动发送给 Trae。

| 名称 | 归属 / 种类 | 定义与边界 |
| --- | --- | --- |
| `ChartResourcePath` | assets/scripts/SceneBuilder · Inspector 配置字段 | 无扩展名的 Cocos resources 相对谱面路径；默认 `chart/guidance_c`，只在游戏世界创建前配置，由世界工厂传递。不能作为 chartId、文件系统绝对路径或世界身份。 |
| `chartResourcePath` | SceneBuilder.start · 局部变量 | 本次资源加载使用的路径快照：引导线取 ChartResourcePath.trim()，旧 T7 使用原固定路径。 |
| `showChartLoadError` | SceneBuilder · 私有方法 | 主谱面资源边界失败时创建可读错误信息，保持拒绝加载和返回世界的原入口行为；不写账本、不替换谱面。 |
| `bindNodeColors` | ChartPadView · 表现接线方法扩展 | 接收已经校验的 GuidanceVisualData.nodes，缓存并传递到 LineEraseEffect。同名方法已存在于 LineEraseEffect，本批扩展使用范围，不创建新概念。 |
| `nodeColors` | ChartPadView · 私有表现状态扩展 | 缓存可选伴随颜色，支持颜色资源和视图的不同到达顺序；换谱清空。LineEraseEffect 已有同名映射，本批延用其语义。 |

延用既有名称：GuidanceVisualData、parseGuidanceVisualData、parseGuidanceChart、ChartPremiere、ChartRef、NarrativeEvent、UseGuidanceChart。没有新增 ChartRegistry、ChartCatalog、ChartResourceLoader、EditorExportTarget 或逻辑模块。

建议附录语义：游戏资源身份由 JSON 的 chartId 决定；资源路径只用于定位。颜色文件按所选资源路径的 `.visual` 后缀寻址，再按 chartId / nodeId 配对校验。RGB 仅表现，不进入 GuidanceChart、判定、得分或账本。

阶段 2 候选：世界文件夹中的谱面列表；多媒体资源配置；显式导出目标管理。以上未登记为本批已实施命名。
