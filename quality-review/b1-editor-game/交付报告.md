在 Creator 中演奏本次样本：

1. 选中入口 SceneBuilder，保持 `UseGuidanceChart=true`。
2. 在进入世界前设 `ChartResourcePath=chart/music-project-1-chart`，不写 `.json` 或 `assets/resources/` 前缀。设为 `chart/guidance_c` 即使用默认旧谱面。
3. 本次导出的资源对已放入 [assets/resources/chart](D:/Project/A_New_Begin/Neurou_official/assets/resources/chart)。换成自己的谱面时，从 `编辑器/导出/引导线/` 成对复制 `{chartId}.json` 与 `{chartId}.visual.json`；颜色文件可省略。
4. 等待 Creator 完成资源导入与预览编译，然后启动预览、打开初始世界。
5. 按既有玩法靠近深痕并持续完成节奏解谜，随后进入谱面、演奏；完成自动回世界。
6. 以深痕事件已入账后的条数为基线检查演奏 +1。中途退出不增加完整演奏事件，可从保留入口重新进入。

`ChartResourcePath` 是资源定位路径；JSON 的 `chartId` 才是谱面身份。颜色文件按资源路径加 `.visual` 寻址，再严格校验 chartId 与 nodeId。主谱面非法或缺失时显示拒绝加载信息，按 Esc 返回世界；颜色失败只降级表现。
