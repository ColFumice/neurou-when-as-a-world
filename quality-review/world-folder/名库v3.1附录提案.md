# 交给 PROTOCOL → Trae：名库 v3.1 附录提案

本附录对应 VERDICT-158～168。下列名称在本轮实现范围内正式冻结，仍需 PROTOCOL 追认、Trae 写入共享名库；实施者没有修改 docs/NAMEBOOK.md。本附录不表示名库真源已更新。

| 名称 | 归属 | 语义 |
| --- | --- | --- |
| WorldFolderView | presentation | 登录及首次序章后的统一世界文件夹界面 |
| WorldFolderEntry | presentation | 只读世界入口描述，不是 WorldInstance |

| FolderStartupView | presentation | 开发阶段本地登录、简短序章及错误显示 |
| AccountStartupStorage | presentation | 浏览器本地账号序章完成事实的存储适配 |
| FolderPresentationTheme | presentation | 世界文件夹、目录、启动与外层退出控件的可替换美术参数；文件 FolderTheme.ts |

## 字段、公开成员和判别值

| 接收者 | 追认字段或成员 |
| --- | --- |
| WorldFolderEntry | worldId、title、description |
| WorldFolderReader | getAccountId、getWorlds |
| EditorFolderEntry | entryId、title、availability、children |
| EditorCatalog | getRoot |
| AccountStartupSnapshot | accountId、phase、PrologueCompleted |

| AccountStartupPort / Session | submitStartupIntent |

| FolderPresentationTheme | background、panel、foreground、muted、border、fontFamily |

availability 字面值：Folder / Implemented / Placeholder。phase 字面值：Login / Prologue / WorldFolder。启动意图 kind：Login / CompletePrologue。前者是目录展示可用性，后者是账号启动阶段，不能代替玩法 ChartPlaybackState 或 PerceptionMode。

同名 getRoot、title、destroy 等限定其接收者，不修改其他域既有成员。生命周期方法 start/onDestroy 是 Cocos 既有约定，不冻结为新的玩法机制。

## 目录与入口 ID

世界 ID：InitialWorld。

编辑器 ID 完整集合：EditorRoot、MusicEditor、RgbWavetableEditor、GridEditor、MidiTrackEditor、MapEditor、NarrativeEventEditor、StoryEditor、PasserbyEditor、SubtitleEditor、ChartEditor、GuidanceEditor、VideoTimingEditor、PositionEditor、SpecialNarrativeEventEditor。

这些字符串是 presentation 目录身份，不是新 editor 实现类。NarrativeEventEditor 和 SpecialNarrativeEventEditor 避免新增裸 Event 名；RgbWavetableEditor 的显示名保留“RGB波表编辑器”；MidiTrackEditor 的显示名保留“MIDI以及音轨编辑器”。GuidanceEditor 打开既有 GuidanceEditorSession，不重命名第 29 批公开类型。

常量/变量 InitialWorld、editorCatalog、folderPresentationTheme 及 applyFolderTheme 一并登记。FolderTheme 是文件名，不另冻结同名类型；公开配置类型为 FolderPresentationTheme。私有方法、成员、局部变量、DOM ID、CSS 变量与资源名称不另扩为世界观领域实体；交付机器清单是完整词形核对附件，应与本附录共同追认。

## 复用及正式修订

- 复用 AccountMilestone.PrologueCompleted 的完成事实名称；**不定义或扩展 AccountMilestone 全量 enum/interface/schema**。本轮 PrologueCompleted 是浏览器开发投影，不补造 FirstWorldCleared 等未实现字段。ShoreRestored 已被 VERDICT-076 废止，不能重新引入。
- 复用 ShorePrologue、EditorTutorial、ShoreHub、ShoreHubState、AccessCode；本轮不删除这些名称。
- 修订 VERDICT-062 与 VERDICT-068 默认启动入口为登录 → 首次序章 → WorldFolderView；ShoreHub 未来功能入口另议。
- InitialWorld 不新增 WorldKind 值，不替换 WorldInstance，不改 WorldRegistry。
- 原 GuidanceChart、GuidanceLineRuntime、GuidanceChartRuntime、ChartPremiere、GuidanceEditorSession、GuidanceEditorView、GuidanceEditorBuilder、DirectorSession、PlayerIntent、IntentPort 及全部 A/B/C 名称保持原职责。
- 既有 Inspector 配置 UseGuidanceChart / GuideTransparency 复制给新 gameplay 会话，字段不重新冻结或改语义。独立 Scene 3D 世界根由创建它的 gameplay 会话拥有，退出显式销毁；不因此新增世界存档类型。

## 存储与保留字

本地完成事实保存键为 `neurou-account-milestone-v1:` 加 encodeURIComponent(accountId)，值为 `{ PrologueCompleted: true }`。该格式只承诺本次浏览器开发适配，不声明 AccountProfile 的正式跨设备存档结构。未来服务迁移必须显式兼容或迁移，不能静默丢弃账号完成事实。

界面采用 View/Panel，Window 仍只用于时间窗口；日志采用 Log；目录选中/展开状态不使用 Highlight/Trace/Process 代称。本轮未引入裸 Event、Developer、Rain、World 类型或变量名。
