本轮**不新增模块，不扩展九模块依赖矩阵**。文件名沿用交付约定，内容是范围同步提案与既有依赖边说明；实施者不修改 docs/spec/stage-1.md、名库、参照或门禁脚本。

## 本轮源码归属

| 文件或类型 | 归属 | 允许关系 |
| --- | --- | --- |
| FolderCatalog、WorldFolderEntry、WorldFolderReader、EditorFolderEntry、EditorCatalog、InitialWorld | presentation | 同域只读数据与工厂，不引用 gameplay 状态 |
| WorldFolderView、EditorFolderView、FolderStartupView、AccountStartupStorage、FolderTheme.ts / FolderPresentationTheme | presentation | 同域展示、导航回调、浏览器平台适配 |
| AccountStartupSession 及 Snapshot/Intent/Reader/Port | director | 纯逻辑，零 cc；不导入 world/ledger/chart/editor，不创建世界或账本 |
| director/IntentPort 的 export type 转发 | director | 同域类型边，编译擦除 |
| FolderStartupView → director/IntentPort | presentation → director | 既有 I 边，仅 import type AccountStartupSnapshot，不携带写权限 |
| WorldFolderBuilder | assets/scripts 组合根 | 创建启动编排、存储适配与 UI；按导航创建既有 gameplay/editor 运行节点 |
| SceneBuilder / GuidanceEditorBuilder 生命周期接线 | assets/scripts 组合根 | 保留原业务装配，增加退出与失效回调防护 |

presentation 不直接值导入 AccountStartupSession，director 不引用 presentation。AccountStartupSession 构造时接收无平台依赖的持久化回调，组合根将其连接至 AccountStartupStorage。director 决定合法完成事实；浏览器适配只执行候选快照持久化；保存成功后 director 提交 WorldFolder 完成快照。存储失败仍停留 Prologue。

## 交 Trae 同步的阶段范围

用户本轮已直接授权，可将 stage-1 §4 的“登录”“Neurou 文件夹”排除修订为以下有限范围：

1. 开发阶段本地账号登录，以及由 director 编排的一次简短序章灰盒；账号完成事实保存在当前浏览器，未接真实服务。
2. 登录/首次序章之后统一进入 WorldFolderView；唯一 InitialWorld 入口接通现有 A/B/C/T6/T7 gameplay。
3. 世界编辑器目录 15 项，只 GuidanceEditor 可打开；所有未实现编辑功能标注 Placeholder。
4. 世界/编辑器退出回 WorldFolderView；运行节点和 Scene 下独立拥有的 3D 世界根共同清理，停用时同步停止输入/帧驱动并暂停媒体，销毁完成后的 EVENT_AFTER_DRAW 显示文件夹。世界重入 fresh session，不需要新世界存档接口，不新增进度持久化承诺；既有 UseGuidanceChart / GuideTransparency 配置复制保留。
5. 所有启动链接，包括旧 `?guidanceEditor=1`，都经过新登录/序章/目录；外部快捷链接不再直达独立编辑模式。

继续排除：服务器认证、世界事件推送/同步、多世界创建与管理、存档复制/分叉/迁移、新音乐/地图/剧情编辑器。AccessCode 仍留作 VERDICT-023 的未来世界访问机制，开发阶段目录无锁。

建议同步位置：stage-1 §4 阶段范围、启动流程说明、presentation 职责、账号级 director 补充说明和验收清单新增本批 10 项。**不需要修改 §6 矩阵单元或门禁允许边。**若未来引入正式 account/worldFolder 逻辑域，须重新裁定模块关系，不能从本轮目录配置推导新域已获授权。
