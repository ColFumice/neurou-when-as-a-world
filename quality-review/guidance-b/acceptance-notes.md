# B 步独立验收

运行 `node quality-review/guidance-b/acceptance.cjs`，结果保存为同目录 `results.json`。不改 A 步旧证据、源码、docs、名库或参照文件。

此脚本验证严格谱面加载；Polyline 内部真实转折必须由 Tap 或 Hold 起点接线；Drag 不单独构成转折；节点按距离及 ID 确定性规范化；零默认 Tap 键；单线多节点与三种判定对象混合。

Drag 验收使用节点到达前的 Down 与到达后的 Up 时间戳，故即使渲染帧跳过到达点也必须正确。到达时 Down 有效，到达时 Up 为未按住。固定绑定键独立于判定点经过的网格。无输入、到达后才按下都记一次 Miss。

Hold 验收覆盖提前按住、恰在起点按下、起点缺键、中途松开、尾端前/恰尾端/尾端后松开，以及失败后重新按下不能补救。起点缺键或中途松开会锁定不可恢复的失败，但档位和分数保持未决直至尾端，再一次记 Miss；成功亦只在尾端记一次 Perfect，不按帧计分。`holdActive` 按几何起尾区间描述；未结算时 `disappearAtMs` 为 null，尾端结算后等于尾端媒体时间。失败锁定后剩余粗线和白框仍保留到尾端才开始放大淡出；即使媒体提前结束，也不能在失败锁定时提前完成并回收完整区间。折线 Hold 剩余段按逻辑弧长裁剪，同一时刻的多个尾端反馈按节点 ID 确定性排序。

Tap 候选验证时间差、目标时间、节点 ID 的排序；B 仍明确拒绝多线，因此引导线 ID 层恒等，不能声称已验收跨线选择。一次 Down 最多消费一个 Tap；Drag / Hold 的自主到达检查不占 Tap 输入消费，粗帧可一次结算多条自主对象。

生命周期验收包括暂停冻结路径、判定和淡出媒体时间，暂停 Up 只释放守卫并锁定活动 Hold 中断，恢复不在冻结边界提前计分，尾端再结算 Miss；退出重入清空各节点和按住状态，全部对象已决且媒体结束方可完成，异常媒体独立超时，真实 T6 七秒链路授予入口，director 恰好写一条完成记录。

输入集成部分仅 stub `cc.Component` 与原生事件总线，运行真实 InputCollector、FrameDriver 和 DirectorSession。此证据不冒充 Creator 视觉或分辨率验证。

媒体结束后停钟接线另由 TypeScript AST 提取完整真实 `SceneBuilder.update`、`readVideoTimeMs`、`onFrameRefresh`、`teardownChart` 方法及使用的真实常量执行。只替代图形节点与原生播放器控制、资源装配，不替代时钟选择、结束回退、判定或导演。原生媒体时钟固定 4000ms、结束标志为 true，失败 Hold 仍由实际 update 的独立帧时长推进到 5000ms 尾端；暂停 1000ms 不补算；中途退出和重入通过真实回收接线清掉 fallback；最终 director 只追加一次完成记录。这是实际方法单元接线验收，仍不声称完整 Creator 引擎预览。
