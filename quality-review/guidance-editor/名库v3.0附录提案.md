# 交给 PROTOCOL → Trae：名库 v3.0 附录提案

新增领域名待正式追认并由 Trae 写入名库；实施者不修改 docs/NAMEBOOK.md。复用 GuidanceChart、GuidanceLine、GuidanceNode、HeadNode、TapNode、DragNode、HoldNode、NodePath、GuidancePosition、GuidanceLineRuntime、GuidanceChartRuntime、getGuidanceSnapshots、ChartPremiere、KeyboardPadLayout、LineEraseEffect 和 AudioOutputClock，不重命名。

| 新名称 | 归属 | 含义 / 冻结建议 |
| --- | --- | --- |
| NoteColor | editor | sRGB uint8 的 r/g/b 三通道，不关联 TrailColor |
| MidiNoteEvent | editor | 已换算媒体绝对毫秒、位置及颜色的源事件，禁用单字 Event |
| ChartSourceData | editor | schema 1 的上游版本化源快照，provenance 为 Mock / Midi |
| GuidanceVisualData | editor | schema 1 颜色伴随 JSON，只含 chartId 和节点颜色关联 |
| EditorSelection | editor | 源事件节点类型 / Head / Hold 尾端选择 |
| EditorHistory | editor | 有界选择修订链及 cursor，独立于玩法账本 |
| GuidanceEditorDocument | editor | schema 1 可恢复草稿，包含源、选择、历史、媒体引用 |
| GuidanceEditorSession | editor | 草稿控制器与隔离预览协调者 |
| GuidanceEditorReader | editor | 表现层可持有的只读接口 |
| GuidanceEditorIntent | editor | 编辑、导入、预览生命周期意图联合 |
| GuidanceEditorPort | editor | 仅提交编辑意图的接口 |
| TimedGuidanceLine | chart | v3 无 speed、具有绝对时间表的线；旧 GuidanceLine 保留 |
| GuidanceNodeTiming | chart | 普通节点 targetTimeMs，Hold 专有 endTargetTimeMs |
| GuidanceTimeAnchor | chart | pathDistance / targetTimeMs 的分段插值锚点 |
| GuidanceEditorView | presentation | 游戏内 Cocos 浏览器编辑器 UI |
| GuidanceEditorBuilder | assets/scripts | 独立编辑器模式组合根 |

新增公开函数/接口成员一并追认：parseNoteColor、parseChartSourceData、parseGuidanceVisualData、getLineTimeAnchors、guidanceDistanceAtTime、guidanceNodeTime、getDocument、getPreview、getPreviewData、getLayout、exportChart、submitEditorIntent、bindEditor、bindNodeColors。

已存在方法名称如 getLayout 若在其他域同名，不表示修改原职责；本表限定接收者 GuidanceEditorReader / GuidanceEditorSession。getPreviewData 是 chart/visual 只读文件数据，不暴露 preview 的写方法；getPreview 返回 ChartPremiereReader。

新增字段追认：sourceId、sourceRevision、provenance、mappingVersion、mediaDurationMs、trackId、lineId、timeMs、position、color、pitch、drumType、velocity、endTimeMs、emphasis、documentId、source、selection、history、heads、holdEndEventId、entries、before、after、cursor、media、videoPath、audioPath、timing、nodeId、targetTimeMs、endTargetTimeMs。其他同名既有字段复用，不改原语义。

新增意图判别值：LoadSource、LoadDraft、LoadPreview、SetKind、SetHead、SetHoldEnd、SetMedia、Undo、Redo、StartPreview、StopPreview、Seek、Advance、Strike、Pause。预览模式 Manual / Rehearsal；来源序列化 Midi，在 UI 显示 MIDI。

私有平台适配接口 EditorDirectoryHandle 仅用于浏览器目录导出，不是玩法领域实体；不建议纳入世界名库。GridPosition 不新增，复用 GuidancePosition。UndoStack / EditorDraft 不新增，分别统一为 EditorHistory / GuidanceEditorDocument。
