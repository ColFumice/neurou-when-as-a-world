## Cocos 真实链路证据

使用实际 Creator 3.8.8 编译预览，不是 HTML 假图或逻辑测试截图。DOM UI 执行导入、类型选择、撤销/恢复、下载；Electron will-download 将两个真实文件写入“编辑器/导出/引导线”，再经真实文件选择器读取。预览实例为实际 ChartPremiere / GuidanceChartRuntime / GuidanceLineRuntime，节点图形由实际 Cocos LineEraseEffect / Graphics 渲染，媒体来自实际 12 秒视频与 AudioOutputClock。手动模式使用正常 DOM 键盘边沿；只在错误测试中模拟文件权限拒绝/视频时长不匹配，没有修改判定、计分或媒体时钟。

两个分辨率均记录 UI 重开后的 localStorage 草稿恢复（含 3 项历史）、实际 JSON 重新加载、两线运行、Hold 暂停冻结、完整自动试听、完整手动演奏、缺键 Miss、Seek 重建与重入归零；无 renderer error。场景中无 gameplay FrameDriver/InputCollector，组合根不连接 director/ledger，因此完成、停止、Seek 均不写账本。

| 分辨率 | 自动试听 | 手动模式键盘演奏 | 实际视频帧样本 | 最大原始帧/输出时钟差 |
| --- | --- | --- | --- | --- |
| 1920x1080 | P6 G2 M0，800 分，Completed | P8 G0 M0，800 分，Completed | 795 | 19.153 ms（≤30ms） |
| 2560x1440 | P6 G2 M0，800 分，Completed | P8 G0 M0，800 分，Completed | 796 | 17.890 ms（≤30ms） |

计分及档位在两档手动演奏结果相同；精确同时间戳输入的分辨率独立重放见逻辑验收 15。自动试听在帧推进时生成输入，跨运行输入时间可以不同，不能将其自动输入当成相同时间戳比较；早一轮错误比较档位的失败记录保留在 creator-preview-earlier-comparison-failure.json，最终比较口径修正为手动模式加精确重放。真实完成时间位于视频结束后的下一帧，不要求两档 finishedAtMs 逐位相等。

音画检查以 requestVideoFrameCallback 的 mediaTime 与原始输出时钟差作为 30ms 门槛；不是声卡到屏幕的外部硬件延迟测量。expectedDisplayTime 外推诊断在 2560×1440 首帧（mediaTime=0）存在延迟回调离群点，原始数据完整保留，不宣称该诊断全程通过门槛。

## 遗留与待追认

- Trae 更新依赖矩阵真源及门禁登记后重跑依赖检查；在此之前不能宣称三门禁全部通过。
- 新名称及 schema v3 附录待 PROTOCOL 正式追认；附录不是名库已更新的声明。v3 七项时间语义已在本轮裁定明确，没有新架构阻断需停工。
- UI 使用 Creator 浏览器预览模式/DOM 文件 API；本轮未交付原生打包平台的编辑器。启动入口依赖已开启的 Creator 预览服务。
- 草稿实际落点是浏览器 localStorage，磁盘草稿备份需下载保存；本地媒体文件只记引用名，重开需重新选择。重导入源是新草稿，不提供跨 sourceRevision 的选择/历史自动合并。
- 文件夹 API 的双文件写入不是原子事务；单文件成功后另一失败会提示已写数量并要求重新成对导出。本轮覆盖首文件权限拒绝，未承诺断电事务恢复。默认多文件下载需浏览器允许。
- 颜色按 chartId+nodeId 匹配，不含摘要；应保留同次导出文件成对使用。旧 A/B/C 游戏入口未自动接颜色伴随文件；新编辑器重新加载预览已接入可选颜色。
- 本轮未在 gameplay director 入口替换成 v3 新谱面来重新验证 AC-20/21 实际写账本；编辑器预览按裁定零账本，旧导演链路由 B/C 回归及历史已验收证据保留。
