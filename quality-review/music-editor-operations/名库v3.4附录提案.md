# 名库 v3.4 附录提案：音乐编辑器批量操作

交 PROTOCOL → Trae。本批只写此提案，不修改 docs/NAMEBOOK.md。本提案承接 v3.3 音频编辑器与 VERDICT-191～195；实现声明及精确行号以本批新增命名清单 / new-names.json 为准，UI 私有词形不提升为跨域逻辑实体。

| 名称 / 判别值 | 归属与语义 |
|---|---|
| DeleteNotes | MusicEditorIntent.kind 及 MusicEditorHistory entry.label；通过全项目唯一 noteIds 一次删除选定集合，可跨轨 |
| MoveNotes | MusicEditorIntent.kind 及历史 label；统一 deltaTick / deltaPitch 一次移动选定集合，保留轨道与其他音符字段 |
| PasteNotes | MusicEditorIntent.kind 及历史 label；将新 NoteDefinition 集合一次加入指定 trackId |
| noteIds | 批量删除/移动的只读安全、唯一、已有 ID 数组；不是 UI 可变 Set 的直接暴露 |
| deltaTick / deltaPitch | 安全整数时间/半音增量，整体校验不自动 clamp |
| selectedNoteIds | MusicEditorView 私有 Set；全项目多选状态，不序列化、不进撤销历史 |
| anchorNoteId | MusicEditorView 私有范围选择锚点；按 clicked track 的 tick/ID 排序定义 Shift 范围 |
| clipboard | MusicEditorView 私有已复制音符快照，仅本编辑器内存；不用作系统剪贴板、工程或账本字段 |
| pointer / drag / box / ghost 相关实际声明 | UI 手势与绘制状态；完整词形由实现 AST 清单追认，不定义新逻辑领域类型 |

新增意图结构：

```ts
| { readonly kind: 'DeleteNotes'; readonly noteIds: readonly string[] }
| { readonly kind: 'MoveNotes'; readonly noteIds: readonly string[];
    readonly deltaTick: number; readonly deltaPitch: number }
| { readonly kind: 'PasteNotes'; readonly trackId: string;
    readonly notes: readonly NoteDefinition[] }
```

实际创作会话仍为 MusicEditorSession，公开只读/提交接口仍为 MusicEditorReader / MusicEditorPort / MusicEditorIntent。MusicEditorDocument、MusicEditorHistory、MusicProjectData、TrackDefinition、NoteDefinition 的原字段不变；MusicEditorHistory.label 在旧 AddNote / ChangeNote / DeleteNote / SetTempo 外增加上述三值。旧 API、ChartSourceData / MidiNoteEvent / NoteColor、MusicEditorBuilder 及目录 ID 不改。

selection、anchor、clipboard、drag 等 UI 内存不得出现在 schema1。运行实例继续 Session / Runtime，界面继续 View / Panel，UI选中继续 Selection / Focus；不新增裸 Event、UndoStack、GridPosition、Window界面名或音轨版 WorldMeter。单选是 selectedNoteIds 的一个成员，不建立与集合矛盾的第二份逻辑选择真源。

依赖边没有变化：musicEditor→constants/chart 为 A、→editor 为 type R；presentation→musicEditor 为 type R+I（门禁 I）；逻辑零cc。Trae只追加本批判别值、字段语义及实际新增词形，按 VERDICT-191～195 更新操作验收，不扩展模块矩阵权限。
