# 名库 v3.3 附录提案（交 PROTOCOL → Trae 落盘）

本轮不修改 docs/NAMEBOOK.md。本提案基于 v3.2，新增 VERDICT-180～190；公共名在本批范围冻结，共享名库追认待 PROTOCOL。完整新增实现声明及所在行由 new-names.json / 新增命名清单.md 提供。

| 名称 | 归属、语义 |
| --- | --- |
| musicEditor | 独立音乐创作纯逻辑模块，零cc |
| MusicProjectData | schema1音乐工程；不是引导线输入 |
| TrackDefinition / NoteDefinition | 音轨及音符定义，稳定ID、显式位置、时间基准为tick |
| TempoPoint / MusicTimeSignature | tempo分段点与拍号；PPQ基准是四分音符 |
| MusicEditorDocument / MusicEditorHistory | 含版本、工程快照、revision和100项有界撤销历史的草稿 |
| MusicEditorSession | 草稿唯一状态维护者 |
| MusicEditorReader / MusicEditorPort / MusicEditorIntent | 只读面、意图提交端、用户操作联合 |
| ChartSourceBuilder / buildChartSource | 音乐工程→冻结ChartSourceData的转换层/函数 |
| MusicPlaybackNote | 换算为绝对毫秒的只读音符试听信息 |
| MusicEditorView / MusicPreviewAudio | presentation音乐工作区/简易离线PCM试听适配 |
| MusicEditorBuilder | 音乐与引导线会话的独立组合根 |
| WavetableDefinition / GridDefinition | 后续音色/网格创作定义的预留提案；本批不建立类型/schema/实现 |

复用 ChartSourceData、MidiNoteEvent、NoteColor、GuidancePosition、KeyboardPadLayout、FolderPresentationTheme；不新增裸Event、GridPosition、音轨版WorldMeter或TrailColor映射。原MusicEditor / RgbWavetableEditor / GridEditor / MidiTrackEditor入口ID保持，仅可用性更新。

Trae同步：将 VERDICT-180～190 插入裁定记录；添加实际公共接口与字段；预留项明确标为未实现，不承诺本批提供RGB/网格/标准MIDI文件或实时音频引擎。

本批实际序列化字段与接口如下，省略项不得由调用方暗中补入：

| 类型 | schema1 字段 / 接口 |
| --- | --- |
| MusicProjectData | schemaVersion=1、projectId、title、ppq、tempoMap、timeSignature、durationTicks、layoutVersion、aspectRatio、mappingVersion、tracks |
| TrackDefinition | id、title、lineId、offsetMs、color、notes |
| NoteDefinition | id、tick、durationTicks、pitch、velocity、position；position复用GuidancePosition，color复用NoteColor |
| TempoPoint | tick、bpm；tempoMap首项tick=0，时点唯一 |
| MusicTimeSignature | numerator、denominator；分母取1/2/4/8/16/32且可表示为整数tick |
| MusicEditorDocument | schemaVersion=1、documentId、project、history、revision |
| MusicEditorHistory | entries、cursor；entry为label/before/after，最多100项 |
| MusicPlaybackNote | id、trackId、timeMs、endTimeMs、pitch、velocity |
| MusicEditorReader | getDocument、getLayout、getDurationMs、getTickAtTimeMs、getPlaybackNotes、exportSource |
| MusicEditorPort | submitMusicEditorIntent |
| MusicEditorIntent.kind | LoadProject、LoadDraft、AddNote、ChangeNote、DeleteNote、SetTempo、Undo、Redo |

公共纯函数：parseMusicProjectData、createDefaultMusicProject、parseMusicEditorDocument、buildChartSource、tickToTimeMs、timeMsToTick、musicProjectDurationMs、musicMeasureTicks、midiPitchToFrequency。模块内部解析辅助函数及UI局部声明见完整AST清单，不将其提升为跨域契约。

单位与范围：tick为安全整数；ppq=1～32767；工程时长至多4096个四分音符；BPM=20～320；pitch/velocity=0～127；position为0～1无量纲UV；offsetMs和源时间为毫秒。SetTempo明确将tempoMap替换为常数BPM，Undo可恢复原tempoMap。ChangeNote替换整条音符定义且保持id。
