# 引导线编辑器

本目录对应当前 Neurou_official 工程。用 Creator 3.8.8 打开工程并开启浏览器预览，双击“打开引导线编辑器.cmd”。入口进入游戏内独立编辑器模式，不进入世界或写账本。

世界编辑器下保留完整分类目录；本轮只实现谱面编辑器/引导线编辑器。音乐、地图、剧情、路人、字幕和特殊事件目录只占位。

1. 加载 mock，或导入符合契约的 MIDI 输出 JSON。位置、时间与颜色由源数据决定。
2. 点击音符或右侧事件列表；选择 Tap、Drag 或 Hold。Hold 必须选择同线更晚的尾端。内部转折不能选 Drag；错误会阻止导出，不会自动改类型。
3. 撤销/重做修改。草稿自动保存于此浏览器；保存草稿可手动保存，下载草稿后放入“草稿/引导线”；导入草稿可跨浏览器恢复，包括历史。视频文件只保存文件名，恢复后需重新选择本地视频。
4. 使用演奏预览或明确标记的自动试听。Space 启动 Head；v3 以媒体绝对时间卡点，晚启动不顺延。暂停冻结，拖动时间轴会重建预览并回放已记录输入，未来输入分支丢弃。自动试听不代表玩家成绩。
5. 导出玩法 JSON 与颜色伴随 JSON；存入“导出/引导线”。默认浏览器下载到自己的下载目录，可手动移动；支持文件夹选择的浏览器可先选该输出目录。
6. 点击“加载导出谱面”，选择玩法 JSON，可同时选择颜色伴随 JSON，再点击演奏预览或自动试听。此时预览从加载文件创建独立实际运行时。修改类型、撤销/重做后返回当前草稿预览。v1/v2 仍按旧固定速度解释，v3 使用绝对卡点；颜色文件可省略。原 A/B/C 游戏入口未接入伴随颜色，加载玩法 JSON 单独演奏不显示颜色。

编辑器会严格验证数据，禁止手工拖点、改时间、绑定键或写入颜色到玩法数据。实时预览复用实际 ChartPremiere / GuidanceChartRuntime 与 LineEraseEffect；预览结果不写游戏账本。
